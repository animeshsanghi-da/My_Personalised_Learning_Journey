# Task Automation: File System Management with OS and Shutil

## Introduction
A significant portion of a Data Analyst's time can easily be consumed by manual, repetitive tasks—like downloading daily regional reports, moving them to specific folders, renaming them to match a standard format, or cleaning up a messy directory of mixed vendor files. Before you can even begin to analyse the data, it must be properly staged.

Python's built-in `os` and `shutil` libraries allow you to interact directly with your operating system, turning hours of manual drag-and-drop file management into a script that runs in milliseconds. 

---

## 1. The `os` Module: Navigating the File System
The `os` module allows Python to talk to your operating system. It is your primary tool for navigating directories, checking if paths exist, and reading directory contents.

### Core Functions
* **`os.getcwd()`**: Get the Current Working Directory.
* **`os.listdir(path)`**: List all files and folders in a specific path.
* **`os.path.join()`**: Intelligently joins paths so you don't have to worry about forward vs. backward slashes (`/` vs `\`).
* **`os.makedirs(path, exist_ok=True)`**: Creates a new folder. The `exist_ok=True` argument prevents errors if the folder already exists.

### Example: Basic Navigation
```python
import os

# 1. Check where the script is currently running
current_dir = os.getcwd()
print(f"Current Directory: {current_dir}")

# 2. Define a path for incoming business data
data_path = os.path.join("C:", "Users", "Animesh", "Shivpuri_Operations", "Raw_Data")

# 3. Create the directory safely if it doesn't exist
os.makedirs(data_path, exist_ok=True)

# 4. List all files currently in that folder
files_in_dir = os.listdir(data_path)
print(f"Files found: {files_in_dir}")
```

---

## 2. Advanced Navigation: `os.walk()`
When dealing with deep, nested folder structures (e.g., Years -> Months -> Days), `os.walk()` is an invaluable tool. It "walks" through a directory tree, looking inside every single subfolder recursively.

```python
# Search for all CSV files in a complex folder structure
target_directory = "C:/Users/Animesh/Sanghi_FNB/2025_Reports"

for folder_path, subfolders, filenames in os.walk(target_directory):
    for file in filenames:
        if file.endswith('.csv'):
            print(f"Found dataset: {os.path.join(folder_path, file)}")
```

## 3. The `shutil` Module: Moving and Copying
While `os` is great for navigating and creating folders, `shutil` (shell utilities) is the library you use for moving, copying, and deleting files.

### Core Functions
* **`shutil.copy(source, destination)`**: Copies a file to a new location.
* **`shutil.move(source, destination)`**: Moves a file (also used to rename a file while moving it).

### Example: Archiving Old Reports
```python
import shutil

source_file = "C:/Users/Animesh/Downloads/inventory_export_v1.csv"
destination_folder = "C:/Users/Animesh/Sanghi_FNB/Archive/"

# Ensure the destination exists
os.makedirs(destination_folder, exist_ok=True)

# Move the file (removes it from Downloads)
shutil.move(source_file, destination_folder)
print("File successfully archived.")
```

## 4. Practical Application 1: Bulk Renaming
Data often comes in with terrible naming conventions (e.g., `report_final_final_2.csv`). You can use `os.rename()` to standardize hundreds of files instantly.

```python
import os

folder_path = "C:/Users/Animesh/Shivpuri_Operations/Daily_Sales"

for filename in os.listdir(folder_path):
    # Only target messy Excel files
    if filename.startswith("report_") and filename.endswith(".xlsx"):
        old_file_path = os.path.join(folder_path, filename)
        
        # Create a new, clean name (e.g., removing the 'report_' prefix)
        new_filename = filename.replace("report_", "Shivpuri_Sales_")
        new_file_path = os.path.join(folder_path, new_filename)
        
        # Execute the rename
        os.rename(old_file_path, new_file_path)
        print(f"Renamed: {filename} -> {new_filename}")
```

## 5. Practical Application 2: Organizing a Messy Directory Dynamically
This is a classic Data Analyst automation task. Imagine a "Downloads" folder cluttered with CSVs, Excel files, Images, and PDFs. This script dynamically sorts them into properly named subfolders based on their file extensions.

```python
import os
import shutil

# Target directory to clean up
messy_dir = "C:/Users/Animesh/Downloads/Raw_Extracts"

# Define a mapping dictionary of folder names to file extensions
extension_map = {
    "Data_Files": ['.csv', '.json', '.xml'],
    "Excel_Reports": ['.xls', '.xlsx', '.xlsm'],
    "Documents": ['.pdf', '.docx', '.txt'],
    "Images": ['.png', '.jpg', '.jpeg']
}

def organize_directory(directory):
    for filename in os.listdir(directory):
        file_path = os.path.join(directory, filename)
        
        # Skip directories, only process files
        if os.path.isdir(file_path):
            continue
            
        # Extract the file extension
        _, file_extension = os.path.splitext(filename)
        file_extension = file_extension.lower()
        
        # Find the appropriate folder category for this extension
        assigned_folder = "Others" # Default fallback
        for folder_name, extensions in extension_map.items():
            if file_extension in extensions:
                assigned_folder = folder_name
                break
                
        # Create the category folder if it doesn't exist
        category_path = os.path.join(directory, assigned_folder)
        os.makedirs(category_path, exist_ok=True)
        
        # Move the file into its new home
        shutil.move(file_path, os.path.join(category_path, filename))
        print(f"Moved {filename} to {assigned_folder}/")

# Run the automation
organize_directory(messy_dir)
print("Directory cleanup complete!")
```
