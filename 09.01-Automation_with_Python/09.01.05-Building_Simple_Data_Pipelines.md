# Capstone: Building an End-to-End Data Pipeline

## Introduction
Throughout this module, we have explored individual automation components: interacting with the operating system, formatting Excel files, sending emails, and scheduling tasks. In a real-world business environment, these pieces rarely exist in isolation. Data Analysts frequently build **Data Pipelines** to connect these independent steps into a single, seamless, and autonomous workflow. 

This capstone integrates everything into a highly hireable skill: an automated ETL (Extract, Transform, Load) pipeline that runs independently on your machine (or a server), processes raw business data, generates a polished report, and distributes it to stakeholders.

---

## The Business Scenario
Imagine managing daily operational data for a regional distribution network covering routes between Indore and Shivpuri. Every night, a raw CSV file containing hundreds of transaction records is dumped into a folder. 

Your objective is to build a Python script in VS Code that:
1. **Extracts** the raw CSV data.
2. **Transforms** it using `pandas` to calculate total revenue and top-performing categories.
3. **Loads** the processed data into a formatted Excel report using `openpyxl`.
4. **Emails** the generated report to the regional manager.
5. **Schedules** this entire process to run autonomously every morning at 7:00 AM.

## Step 1: Setting Up the Environment

## Step 2: The Data Processing Function (ETL)

This function handles the core analytical workload. It reads the raw data, applies business logic, and saves the output.

``` python
def process_daily_sales():
    print("Starting data processing...")
    raw_data_path = 'data/raw_daily_sales.csv'
    output_report_path = 'reports/Daily_Sales_Summary.xlsx'
    
    # 1. Extract
    if not os.path.exists(raw_data_path):
        print("Raw data file not found. Pipeline aborted.")
        return None
        
    df = pd.read_csv(raw_data_path)
    
    # 2. Transform
    # Clean missing values
    df.dropna(subset=['Revenue', 'Category'], inplace=True)
    
    # Aggregate data: Total Revenue by Category
    summary_df = df.groupby('Category', as_index=False)['Revenue'].sum()
    summary_df = summary_df.sort_values(by='Revenue', ascending=False)
    
    # 3. Load (Export to Excel)
    os.makedirs('reports', exist_ok=True)
    
    # Using pandas ExcelWriter with openpyxl engine for clean formatting
    with pd.ExcelWriter(output_report_path, engine='openpyxl') as writer:
        summary_df.to_excel(writer, sheet_name='Revenue_Summary', index=False)
        df.to_excel(writer, sheet_name='Raw_Data', index=False)
        
    print(f"Report successfully generated at: {output_report_path}")
    return output_report_path
```

## Step 3: The Distribution Function (Email)

Once the report is generated, this function securely logs into an SMTP server, constructs the email body, attaches the Excel file, and dispatches it.

``` python
def send_report_email(attachment_path):
    print("Preparing to send email...")
    
    # Configuration (In production, use Environment Variables for security)
    sender_email = "animeshsanghi.da@gmail.com"
    sender_password = "your_app_specific_password_here" 
    recipient_email = "manager@business.com"
    
    # Construct the Email
    msg = MIMEMultipart()
    msg['From'] = sender_email
    msg['To'] = recipient_email
    msg['Subject'] = "Automated Daily Sales & Revenue Report"
    
    body = "Hello Team,\n\nPlease find attached the automated sales summary for yesterday's operations.\n\nBest Regards,\nData Analytics Team"
    msg.attach(MIMEText(body, 'plain'))
    
    # Attach the Excel File
    try:
        with open(attachment_path, "rb") as attachment:
            part = MIMEBase("application", "octet-stream")
            part.set_payload(attachment.read())
        
        encoders.encode_base64(part)
        part.add_header(
            "Content-Disposition",
            f"attachment; filename= {os.path.basename(attachment_path)}",
        )
        msg.attach(part)
        
        # Connect to Server and Send
        server = smtplib.SMTP('smtp.gmail.com', 587)
        server.starttls()
        server.login(sender_email, sender_password)
        server.send_message(msg)
        server.quit()
        
        print("Email dispatched successfully.")
    except Exception as e:
        print(f"Failed to send email: {e}")
```

## Step 4: The Orchestrator and Scheduler

Finally, we create a master function that calls the ETL and Email functions in sequence. We then use the `schedule` library to keep the script running in the background, executing the master function at our desired time.

``` python
def daily_pipeline_job():
    print(f"--- Pipeline Triggered at {time.ctime()} ---")
    
    # Step A: Process Data
    report_file = process_daily_sales()
    
    # Step B: Distribute Data (if report was generated)
    if report_file:
        send_report_email(report_file)
        
    print("--- Pipeline Execution Complete ---\n")

# Schedule the job to run every day at 07:00 AM
schedule.every().day.at("07:00").do(daily_pipeline_job)

if __name__ == "__main__":
    print("Automation Service Started. Waiting for scheduled time...")
    
    # Infinite loop to keep the script alive and checking the time
    while True:
        schedule.run_pending()
        time.sleep(60) # Wait 60 seconds before checking the schedule again
```
