## Introduction
In a Business Intelligence or Data Analyst role, generating insights is only half the job; delivering them to stakeholders on time is just as critical. Manually attaching Excel reports or dashboards to emails every morning is inefficient. By leveraging Python’s built-in `smtplib` and `email` modules, you can fully automate the distribution of your analytical reports, ensuring stakeholders across different regions receive timely updates without manual intervention.

This module covers configuring SMTP servers, constructing MIME (Multipurpose Internet Mail Extensions) messages, and programmatically attaching files like generated Excel reports or CSVs.

---

## Key Concepts
* **SMTP (Simple Mail Transfer Protocol):** The standard protocol for sending emails across the internet. Python handles this via `smtplib`.
* **MIME (Multipurpose Internet Mail Extensions):** While standard emails only support plain text, MIME allows you to send HTML, images, and attachments (like `.xlsx` or `.pdf` files).
* **App Passwords:** For security, email providers require a 16-character "App Password" rather than your standard account password when authenticating via scripts.
* **Environment Variables:** Credentials should never be hardcoded in your script. Always use environment variables or `.env` files for security.

## 1. Setting Up the Email Structure
To send an email with an attachment, we use a `MIMEMultipart` object. This acts as a container where we can attach the text body and the file separately.

### Example Scenario:
Assume you have a daily automated script that processes data for Sanghi Food and Beverage, generating a report comparing sales and inventory between the Indore and Shivpuri locations. We need to email this report (`daily_sales_report.xlsx`) to management.

``` python
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.base import MIMEBase
from email import encoders
import os

# 1. Define Email Credentials and Meta Data
# Best practice: Fetch these from environment variables
SENDER_EMAIL = "animeshsanghi.da@gmail.com"
SENDER_PASSWORD = os.getenv("EMAIL_APP_PASSWORD") # Never hardcode this!
RECEIVER_EMAIL = "management@example.com"

SUBJECT = "Automated Daily Sales Report - Indore & Shivpuri Branches"
BODY = """
Hello Team,

Please find attached the automated daily sales and performance report for our regional branches. 

If you have any questions regarding the metrics, please let me know.

Best regards,
Data Analytics Team
"""
```

---

## 2. Constructing the Message and Attaching Files
Once the metadata is defined, we assemble the MIME message and read the file in binary mode to attach it.

``` python
# 2. Initialize the MIME Multipart object
msg = MIMEMultipart()
msg['From'] = SENDER_EMAIL
msg['To'] = RECEIVER_EMAIL
msg['Subject'] = SUBJECT

# Attach the plain text body to the email
msg.attach(MIMEText(BODY, 'plain'))

# 3. Define the file to attach
filename = "daily_sales_report.xlsx"
filepath = f"C:/Reports/{filename}" # Update with your actual local path

# Open the file in binary read mode ('rb')
try:
    with open(filepath, "rb") as attachment:
        # Create a MIMEBase object
        part = MIMEBase('application', 'octet-stream')
        part.set_payload(attachment.read())
        
        # Encode the payload into Base64 (required for email transmission)
        encoders.encode_base64(part)
        
        # Add header so the email client knows it's an attachment
        part.add_header(
            'Content-Disposition',
            f'attachment; filename= {filename}'
        )
        
        # Attach the file to the main message
        msg.attach(part)
        print(f"Successfully attached {filename}")
        
except FileNotFoundError:
    print(f"Error: The file {filename} was not found. Please check your data pipeline output.")
```

---

## 3. Sending the Email via SMTP
To send the email, we establish a secure connection with the Gmail SMTP server using port 587 (TLS).

``` python
# 4. Connect to SMTP server and send the email
try:
    # Gmail's SMTP server and TLS port
    server = smtplib.SMTP('smtp.gmail.com', 587)
    
    # Start TLS (Transport Layer Security) for encryption
    server.starttls()
    
    # Login to the server
    server.login(SENDER_EMAIL, SENDER_PASSWORD)
    
    # Convert the multipart message to a string and send
    text = msg.as_string()
    server.sendmail(SENDER_EMAIL, RECEIVER_EMAIL, text)
    
    print("Automated email sent successfully!")
    
except smtplib.SMTPAuthenticationError:
    print("Failed to authenticate. Check your email and App Password.")
except Exception as e:
    print(f"An error occurred: {e}")
finally:
    # Always quit the server to free up resources
    server.quit()
```

## Pro-Tips for Data Analysts
1. **HTML Email Bodies:** Instead of plain text, you can send HTML emails. If you process data with Pandas in VS Code or Jupyter Lab, you can use `df.to_html()` to embed a clean preview table directly into the email body! Just change `MIMEText(BODY, 'plain')` to `MIMEText(html_body, 'html')`.
2. **Integration with OS/Shutil:** Use the techniques from the `os` module to automatically locate the newest generated file in your directory and dynamically pass its path to this email script.
3. **Error Logging:** If this runs continuously on a scheduled pipeline, use Python's `logging` module to record successes or failures instead of `print()` statements, ensuring you can review the history if an email fails to send.
