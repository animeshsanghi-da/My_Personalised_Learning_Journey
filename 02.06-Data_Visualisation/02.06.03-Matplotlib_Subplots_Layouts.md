# Matplotlib: Subplots & Layouts

## Overview
When performing Exploratory Data Analysis (EDA) or building dashboards, plotting a single chart is often insufficient. You frequently need to compare multiple variables, view different distributions side-by-side, or show the relationship between various features simultaneously. **Matplotlib** provides powerful layout managers, primarily through the creation of **Subplots**, to arrange multiple plots within a single image or window.

## The Anatomy of a Matplotlib Layout
To master subplots, you must understand Matplotlib's Object-Oriented hierarchy:
* **Figure (`fig`):** The overall window or page that everything is drawn on. It is the top-level container that can hold one or more Axes.
* **Axes (`ax`):** A single plot or chart within the Figure. An Axes object contains the actual data, labels, ticks, and titles. A Figure can have multiple Axes, arranged in a grid.

---

## Subplot Layout Methods
Matplotlib offers several distinct ways to organize your visualizations depending on the complexity of your dashboard:
1. **Basic Grids (`plt.subplots(rows, cols)`):** Standard uniform grid layout returning an array of axes.
2. **Semantic Mosaic (`plt.subplot_mosaic()`):** Intuitive layout design using text-based ASCII maps (e.g., `[['header', 'header'], ['left', 'right']]`).
3. **Custom Span Grids (`GridSpec`):** Flexible layout manager allowing individual plots to span multiple uneven rows or columns.
4. **Inset Axes (`ax.inset_axes()`):** Embeds a mini-chart inside a larger parent plot frame.
5. **Shared Axis Overlays (`ax.twinx()` / `ax.twiny()`):** Overlays two datasets on the same plot area sharing a single X or Y axis.
6. **Hierarchical Layouts (`fig.subfigures()`):** Divides a single figure canvas into nested logical groups, each containing independent subplot grids.

## 1. Basic Grids (`plt.subplots`)
The most efficient and modern way to create multiple plots is using the `plt.subplots()` function. It creates a Figure and a grid of Axes all at once, returning them as a tuple.

### 1D Grid (1 Row, Multiple Columns)
When you create a 1D grid, the `axes` object is returned as a 1D NumPy array.

```python
import matplotlib.pyplot as plt
import numpy as np

# Sample Data
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

# Create a figure with 1 row and 2 columns
fig, axes = plt.subplots(nrows=1, ncols=2, figsize=(10, 4))

# Plot on the first subplot (index 0)
axes[0].plot(x, y1, color='blue')
axes[0].set_title('Sine Wave')
axes[0].set_xlabel('X-axis')
axes[0].set_ylabel('Amplitude')

# Plot on the second subplot (index 1)
axes[1].plot(x, y2, color='red')
axes[1].set_title('Cosine Wave')
axes[1].set_xlabel('X-axis')

# Automatically adjust spacing to prevent overlapping labels
plt.tight_layout()
plt.show()
```
OR
```python
# Create a figure with 1 row and 2 columns
fig, (ax1, ax2) = plt.subplots(nrows=1, ncols=2, figsize=(10, 4))

# Plot on the first subplot (index 0)
ax1.plot(x, y1, color='blue')
ax1.set_title('Sine Wave')
ax1.set_xlabel('X-axis')
ax1.set_ylabel('Amplitude')

# Plot on the second subplot (index 1)
ax2.plot(x, y2, color='red')
ax2.set_title('Cosine Wave')
ax2.set_xlabel('X-axis')

# Automatically adjust spacing to prevent overlapping labels
plt.tight_layout()
plt.show()
```

**When to Use Which**
- **Use `fig, (ax1, ax2)` when:** 
    - You are creating a fixed layout with only **2 or 3 subplots**.
    - Each plot represents a completely different chart type (e.g., `ax_bar` and `ax_line`).
    - You want immediate, clear variable names without relying on zero-indexed numbers (`axes[0]`, `axes[1]`).
- **Use `fig, axes` when:** 
    - You are generating subplots dynamically inside a **`for` loop**.
    - You have a **2D grid** (e.g., `nrows=2, ncols=2`), where `axes` becomes a 2D matrix (`axes[row, col]`).
    - The number of columns/rows might change depending on input data.

### 2D Grid (Multiple Rows and Columns)
When creating a 2D grid (e.g., 2x2), the `axes` object is returned as a 2D NumPy array. You access individual plots using matrix indexing `[row, column]`.

```python
# Create a 2x2 grid of subplots
fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))
# OR
# fig, ((ax1, ax2), (ax3, ax4)) = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))
# OR
# fig, axes = plt.subplots(nrows=2, ncols=2, figsize=(10, 8))
# ax1, ax2, ax3, ax4 = axes.flatten()  # Converts shape (2,2) -> (4,)

# Top-Left [0, 0]
axes[0, 0].plot(x, y1, 'b-')
axes[0, 0].set_title('Top Left: Sine')

# Top-Right [0, 1]
axes[0, 1].plot(x, y2, 'r--')
axes[0, 1].set_title('Top Right: Cosine')

# Bottom-Left [1, 0]
axes[1, 0].plot(x, -y1, 'g-.')
axes[1, 0].set_title('Bottom Left: Negative Sine')

# Bottom-Right [1, 1]
axes[1, 1].plot(x, -y2, 'm:')
axes[1, 1].set_title('Bottom Right: Negative Cosine')

plt.tight_layout()
plt.show()
```

## 2. Semantic Mosaic (`plt.subplot_mosaic`)
For complex dashboards, manually calculating grid coordinates can be confusing. `subplot_mosaic` lets you design your layout visually using lists of strings. 

``` python
# Design the layout visually using variable names
layout = [
    ['header', 'header'],
    ['left',   'right' ]
]

# ax_dict gives you a dictionary of Axes mapped to your names!
fig, ax_dict = plt.subplot_mosaic(layout, figsize=(10, 6))

ax_dict['header'].plot(x, y1, color='purple')
ax_dict['header'].set_title('Main Header Plot (Spans Both Columns)')

ax_dict['left'].plot(x, y2, color='green')
ax_dict['left'].set_title('Left Panel')

ax_dict['right'].plot(x, -y1, color='orange')
ax_dict['right'].set_title('Right Panel')

plt.tight_layout()
plt.show()
```

## 3. Custom Span Grids (`GridSpec`)
While `plt.subplots()` creates evenly sized grids, `GridSpec` allows you to create complex layouts where some plots span multiple rows or columns (e.g., a dashboard layout).

``` python
import matplotlib.gridspec as gridspec

fig = plt.figure(figsize=(10, 6))

# Define a 2x2 grid
gs = gridspec.GridSpec(2, 2)

# Ax1 spans the entire first row
ax1 = fig.add_subplot(gs[0, :])
ax1.plot(x, y1)
ax1.set_title('Spans entirely across the top')

# Ax2 and Ax3 share the bottom row
ax2 = fig.add_subplot(gs[1, 0])
ax2.plot(x, y2)
ax2.set_title('Bottom Left')

ax3 = fig.add_subplot(gs[1, 1])
ax3.plot(x, -y2)
ax3.set_title('Bottom Right')

plt.tight_layout()
plt.show()
```

## 4. Shared Axis Overlays (`ax.twinx`)
When you want to plot two metrics with vastly different scales on the same chart (like Revenue vs. Profit Margin), you overlay them using `twinx()` (for a shared X-axis and dual Y-axes).

``` python
fig, ax1 = plt.subplots(figsize=(8, 4))

# Primary Axis (Left)
ax1.bar(['Q1', 'Q2', 'Q3', 'Q4'], [50000, 60000, 55000, 80000], color='skyblue')
ax1.set_ylabel('Total Revenue ($)', color='blue', fontweight='bold')
ax1.tick_params(axis='y', labelcolor='blue')

# Secondary Axis (Right)
ax2 = ax1.twinx()
ax2.plot(['Q1', 'Q2', 'Q3', 'Q4'], [10, 15, 12, 22], color='red', marker='o', linewidth=2)
ax2.set_ylabel('Profit Margin (%)', color='red', fontweight='bold')
ax2.tick_params(axis='y', labelcolor='red')

plt.title('Revenue vs Profit Margin')
plt.show()
```

## 5. Inset Axes (`ax.inset_axes`)
When you need to "zoom in" on a specific part of a plot, or display a mini-chart (like a map minimap) inside your main chart.

``` python
fig, ax = plt.subplots(figsize=(8, 5))

# Main plot
ax.plot(x, y1, label='Sine Wave')
ax.legend(loc='upper right')

# Create an inset axes [x0, y0, width, height] as fractions of the parent plot
ax_inset = ax.inset_axes([0.1, 0.1, 0.35, 0.35])
ax_inset.plot(x[:20], y1[:20], color='red')  # Plot just the first 20 points
ax_inset.set_title('Zoomed View')
ax_inset.set_xticks([]) # Hide ticks for a cleaner look

plt.show()
```

## 6. Hierarchical Layouts (`fig.subfigures`)
If your layout is highly complex and you need completely separated clusters of plots inside one window, you can partition the Figure into "Subfigures" before making subplots.

``` python
fig = plt.figure(constrained_layout=True, figsize=(10, 5))

# Split the main figure into left and right halves
subfigs = fig.subfigures(1, 2)

# Left half gets a 2x1 grid
subfigs[0].suptitle('Left Cluster (2x1)')
axs_left = subfigs[0].subplots(2, 1)
axs_left[0].plot(x, y1)
axs_left[1].plot(x, y2)

# Right half gets a single large plot
subfigs[1].suptitle('Right Cluster (Single)')
axs_right = subfigs[1].subplots(1, 1)
axs_right.scatter(x, y1, color='orange')

plt.show()
```

## 7. Layout Optimization Techniques

### `plt.tight_layout()`
When creating multiple subplots, the labels, titles, and tick marks of adjacent plots often overlap. Calling `plt.tight_layout()` right before `plt.show()` automatically adjusts the padding between and around the subplots to fit beautifully within the Figure area.

### Sharing Axes (`sharex`, `sharey`)
If your subplots have the same scale or represent the same units, sharing axes makes the Visualisation cleaner and easier to compare, as it removes redundant tick labels.

```python
# Create 3 stacked plots that share the same X-axis
fig, axes = plt.subplots(nrows=3, ncols=1, figsize=(8, 6), sharex=True)

axes[0].plot(x, y1, color='blue')
axes[0].set_ylabel('Sine')

axes[1].plot(x, y2, color='red')
axes[1].set_ylabel('Cosine')

axes[2].plot(x, y1 + y2, color='purple')
axes[2].set_ylabel('Sine + Cosine')
axes[2].set_xlabel('Time (s)') # Only the bottom plot needs the X-label now

plt.tight_layout()
plt.show()
```
