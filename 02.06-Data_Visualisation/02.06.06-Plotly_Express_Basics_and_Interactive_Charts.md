# Plotly Express: Transitioning to Interactive Visualisations

## Introduction
Static visualisations created with Matplotlib and Seaborn are excellent for initial exploratory data analysis and static PDF reports. However, in modern business environments, stakeholders expect interactivity. They want to hover over a data point to see the exact revenue, zoom in on a specific Q3 timeframe, or pan across different product categories—similar to the experience they get in Power BI or Tableau.

Plotly is the industry standard for bridging this gap in Python. Specifically, **Plotly Express (`px`)** provides a high-level, extremely concise API for creating interactive, publication-quality figures. When running these in your VS Code or Jupyter Lab environments, the charts render natively with full interactive capabilities out of the box.

---

## 1. Setting Up Plotly Express

Plotly Express is built-in with the main `plotly` library. If it isn't installed in your active Anaconda environment, you can install it via the terminal:

``` bash
pip install plotly pandas
```

Import it into your notebook alongside Pandas:

``` python
import pandas as pd
import plotly.express as px
```

## 2. The Interactive Scatter Plot (Correlation & Clustering)
Scatter plots are fundamental for business intelligence when analysing correlations (e.g., Marketing Spend vs. Customer Acquisition). Plotly makes it easy to add extra dimensions using colour, size, and hover tooltips.

``` python
# Simulating a business dataset (e.g., E-commerce customer data)
df_customers = pd.DataFrame({
    'Customer_ID': ['C001', 'C002', 'C003', 'C004', 'C005'],
    'Total_Spend': [250, 800, 450, 1200, 300],
    'Items_Purchased': [2, 10, 4, 15, 3],
    'Customer_Segment': ['Bronze', 'Gold', 'Silver', 'Gold', 'Bronze'],
    'Region': ['North', 'South', 'East', 'West', 'North']
})

# Creating the interactive scatter plot
fig = px.scatter(
    df_customers, 
    x='Items_Purchased', 
    y='Total_Spend',
    color='Customer_Segment',       # Automatically colours by category
    size='Total_Spend',             # Bubble size relative to spend
    hover_data=['Customer_ID', 'Region'], # Adds rich data to the hover tooltip
    title='Customer Spend Analysis: Volume vs. Value'
)

# Render the interactive chart
fig.show()
```

**Business Impact:** Notice how `hover_data` packs more insights into the chart without cluttering the visual space. A manager can spot an outlier and immediately hover to see exactly which `Customer_ID` and `Region` is driving that metric.

## 3. The Interactive Line Chart (Time Series Analysis)
Time series data is ubiquitous in business operations. Plotly's line charts come with built-in abilities to highlight specific traces and isolate trends.

``` python
# Simulating monthly revenue data
df_sales = pd.DataFrame({
    'Date': pd.date_range(start='2025-01-01', periods=6, freq='ME'),
    'Electronics_Rev': [15000, 18000, 17500, 22000, 24000, 23000],
    'Apparel_Rev': [8000, 9500, 11000, 10500, 13000, 15000]
})

# Melting the dataframe for easier Plotly ingestion (Tidy Data format)
df_melted = df_sales.melt(id_vars='Date', var_name='Category', value_name='Revenue')

fig = px.line(
    df_melted, 
    x='Date', 
    y='Revenue', 
    color='Category',
    markers=True, # Adds dots at each data point
    title='Monthly Revenue Trends by Category'
)

# Customising the layout for a cleaner look
fig.update_layout(
    xaxis_title='End of Month',
    yaxis_title='Revenue (INR)',
    hovermode='x unified' # Shows a single vertical tooltip for all categories at a given timestamp
)

fig.show()
```

**Interactive Features to Test:** * **Zooming:** Click and drag a rectangle over the chart to zoom into a specific month.
* **Panning:** Use the toolbar at the top right to pan across the timeline.
* **Isolation:** Double-click on 'Apparel_Rev' in the legend to isolate that line, hiding everything else.

## 4. The Interactive Bar Chart (Categorical Comparisons)
Bar charts are the workhorses of data analysis. Plotly handles both grouped and stacked bar charts effortlessly.

``` python
df_inventory = pd.DataFrame({
    'Warehouse': ['Indore', 'Bengaluru', 'Pune'],
    'In_Stock': [450, 1200, 800],
    'In_Transit': [50, 200, 150]
})

fig = px.bar(
    df_inventory, 
    x='Warehouse', 
    y=['In_Stock', 'In_Transit'], 
    title='Current Inventory Status by Location',
    barmode='group', # Change to 'stack' for a stacked bar chart
    text_auto=True   # Automatically adds data labels to the bars
)

fig.update_layout(
    yaxis_title='Unit Count',
    legend_title='Inventory Status'
)

fig.show()
```

## 5. Exporting for Stakeholders
A major advantage of Plotly is the ability to export these interactive charts as standalone HTML files. You do not need a server to share them; you can simply email the file or upload it to a shared drive.

``` python
# Save the figure as an interactive webpage
fig.write_html("inventory_status_dashboard.html")
```

Anyone opening this HTML file in Chrome or Edge will have full access to the hover, zoom, and pan capabilities, regardless of whether they have Python installed.
