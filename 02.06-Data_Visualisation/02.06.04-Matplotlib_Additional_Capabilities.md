# Matplotlib: Additional Capabilities

## Overview
While Matplotlib is widely known for static 2D charts, it is actually a full-featured visualization engine. Beyond basic lines and bars, Matplotlib natively supports 3D rendering, frame-by-frame animations, interactive widgets, user event handling, and publication-quality mathematical typography. 

These advanced capabilities allow you to transform static reports into dynamic, interactive data applications.

---

## 1. 3D Visualizations (`mplot3d`)
Matplotlib includes a built-in 3D toolkit called `mplot3d`. By simply changing the projection of an axes object to `3d`, you can create 3D surfaces, wireframes, and 3D scatter plots.

### When to use:
* Visualizing multi-variable optimization problems (e.g., loss functions in Machine Learning).
* Mapping geospatial elevations or complex topographical surfaces.

``` python
import matplotlib.pyplot as plt
import numpy as np

# Set up the figure and 3D axis
fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection='3d')

# Generate data
x = np.linspace(-5, 5, 50)
y = np.linspace(-5, 5, 50)
X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

# Plot a 3D surface
surface = ax.plot_surface(X, Y, Z, cmap='viridis', edgecolor='none')
fig.colorbar(surface, ax=ax, shrink=0.5, aspect=10)

ax.set_title('3D Surface Plot')
plt.show()
```

## 2. Animations (`matplotlib.animation`)
Instead of displaying a final static chart, Matplotlib can render data sequentially frame-by-frame. This is done using `FuncAnimation` (which updates a function over time) or `ArtistAnimation` (which plays a list of pre-rendered frames).

### When to use:
* Showing how a distribution changes over time.
* Visualizing the step-by-step progress of an algorithm.

``` python
import matplotlib.pyplot as plt
import numpy as np
from matplotlib.animation import FuncAnimation

fig, ax = plt.subplots()
xdata, ydata = [], []
ln, = plt.plot([], [], 'r-', animated=True)

ax.set_xlim(0, 2*np.pi)
ax.set_ylim(-1.5, 1.5)

# Function to initialize the background
def init():
    ln.set_data([], [])
    return ln,

# Function to update the frame
def update(frame):
    xdata.append(frame)
    ydata.append(np.sin(frame))
    ln.set_data(xdata, ydata)
    return ln,

# Create the animation
ani = FuncAnimation(fig, update, frames=np.linspace(0, 2*np.pi, 60),
                    init_func=init, blit=True)

# Note: To view this in a standard IDE, you might need to save it as an MP4 or GIF
# ani.save('sine_wave.gif', writer='imagemagick')
plt.title('Animated Sine Wave')
plt.show()
```

## 3. Interactive GUI Widgets (`matplotlib.widgets`)
You do not need external libraries like Streamlit or Dash to create basic interactivity. Matplotlib has native GUI controls like `Slider`, `Button`, `CheckButtons`, and `TextBox` that you can embed directly into the chart window.

### When to use:
* Allowing users to tweak parameters (e.g., frequencies, thresholds) and instantly see the visual impact.

``` python
import matplotlib.pyplot as plt
import numpy as np
from matplotlib.widgets import Slider

fig, ax = plt.subplots(figsize=(8, 5))
plt.subplots_adjust(bottom=0.25) # Make room for the slider

t = np.linspace(0.0, 1.0, 1000)
f0 = 3 # Initial frequency
l, = plt.plot(t, np.sin(2 * np.pi * f0 * t), lw=2)
ax.set_ylim(-1.1, 1.1)

# Define slider axis and create the slider
ax_freq = plt.axes([0.25, 0.1, 0.65, 0.03])
freq_slider = Slider(
    ax=ax_freq, label='Frequency', valmin=0.1, valmax=30.0, valinit=f0
)

# Function to execute when the slider changes
def update(val):
    l.set_ydata(np.sin(2 * np.pi * freq_slider.val * t))
    fig.canvas.draw_idle()

freq_slider.on_changed(update)

plt.show()
```

## 4. Event Handling (`mpl_connect`)
Matplotlib can listen to keyboard presses, mouse clicks, and hover events natively. You bind these events to custom Python functions using `mpl_connect`.

### When to use:
* Building custom data annotation tools.
* Clicking a data point to print its exact coordinates or underlying database ID to the console.

``` python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [4, 5, 6], 'bo-')
ax.set_title('Click anywhere on the plot!')

# Callback function for a mouse click
def onclick(event):
    if event.inaxes:
        print(f"Data Coordinates: X={event.xdata:.2f}, Y={event.ydata:.2f}")
        # Add a red dot where the user clicked
        ax.plot(event.xdata, event.ydata, 'ro')
        fig.canvas.draw()

# Bind the event to the figure canvas
cid = fig.canvas.mpl_connect('button_press_event', onclick)

plt.show()
```

## 5. Styling & Theme Engine (`plt.style` / `rcParams`)
Matplotlib provides extensive control over aesthetics. You can apply global preset themes or granularly override default properties (like font sizes, grid lines, and colors) via `matplotlib.rcParams`.

### Global Themes
Using `plt.style.use()` changes the look of all subsequent plots. Popular themes include `'ggplot'` (mimics R's ggplot2), `'seaborn'` (classic seaborn aesthetics), and `'dark_background'` (great for presentations).

``` python
import matplotlib.pyplot as plt
import numpy as np

# Apply a global theme
plt.style.use('dark_background')

plt.figure(figsize=(6, 4))
plt.plot(np.random.randn(50).cumsum(), color='cyan', linewidth=2)
plt.title('Dark Background Theme')
plt.grid(color='gray', linestyle='--', alpha=0.5)
plt.show()

# Reset to default style later if needed
# plt.style.use('default')
```

### Custom `rcParams`
If you want to enforce a strict corporate branding guideline across all charts without passing arguments every time:

``` python
import matplotlib as mpl

# Globally change default settings
mpl.rcParams['lines.linewidth'] = 3
mpl.rcParams['font.family'] = 'sans-serif'
mpl.rcParams['axes.facecolor'] = '#f4f4f4'
mpl.rcParams['axes.titlesize'] = 18
plt.rcParams['axes.titleweight'] = 'bold'
plt.rcParams['axes.labelsize'] = 11
plt.rcParams['xtick.labelsize'] = 10
plt.rcParams['ytick.labelsize'] = 10
plt.rcParams['figure.titlesize'] = 16
```

## 6. Mathematical Annotation and Text 
Matplotlib includes an internal LaTeX parser for high-quality mathematical typography. By using raw strings (`r'...'`) and enclosing equations in `$`, you can render complex formulas in titles, labels, or text. Furthermore, `ax.annotate()` provides an easy way to point directional arrows at specific data features.

### When to use:
* Highlighting local maximums, minimums, or structural breaks in data.
* Displaying the statistical formula used to generate a distribution.

``` python
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 5, 100)
y = np.exp(-x) * np.cos(2 * np.pi * x)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(x, y, color='purple')

# 1. LaTeX Mathematical Annotation in the title
ax.set_title(r"Damped Oscillator: $f(t) = e^{-t} \cos(2\pi t)$", fontsize=14)

# 2. Directional Arrow Annotation
ax.annotate('Local Maximum', xy=(1, np.exp(-1)), xytext=(2, 0.6),
            arrowprops=dict(facecolor='black', shrink=0.05, width=1.5, headwidth=8),
            fontsize=11)

plt.grid(True)
plt.show()
```
