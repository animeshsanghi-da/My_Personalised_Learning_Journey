# Data Visualisation with Matplotlib: Standard Plots

## Overview
**[Matplotlib](https://matplotlib.org)** is the foundational plotting library in Python for 2D graphics. It is highly customizable and serves as the engine under the hood for many other Visualisation libraries (like Pandas plotting and Seaborn). The `matplotlib.pyplot` module provides a state-based interface similar to MATLAB, which is perfect for creating quick, standard Visualisations like Line, Bar, Pie, and Scatter plots.

Data Visualisation is a critical step in the Data Analytics Lifecycle (the "Analyse" and "Share" phases) to discover patterns, identify outliers, and present findings to stakeholders effectively. 

Matplotlib provides a comprehensive suite of visual tools, layout engines, and interactive modules for static, animated, and interactive data visualization. Have a look to the [official cheatsheets](../99.99-Shared_Utilities/matplotlib_cheatsheets.pdf), and Handouts ([Beginner](../99.99-Shared_Utilities/matplotlib_handout-beginner.pdf), [Intermediate](../99.99-Shared_Utilities/matplotlib_handout-intermediate.pdf), and [Tips](../99.99-Shared_Utilities/matplotlib_handout-tips.pdf)).

## 1. Primary Plot Types
Before we dive into the code for specific charts, here is a high-level overview of the [types of visualizations](https://matplotlib.org/stable/plot_types/index.html) you can create using Matplotlib's extensive suite:

- Relational & Trend Plots:
```
plt.plot()                ----> line charts
plt.scatter()             ----> scatter plots
plt.step()                ----> step plots
plt.stem()                ----> lollipop charts
```

- Categorical & Discrete:
```
plt.bar() / plt.barh()    ----> bar charts
plt.pie()                 ----> pie chart
plt.stackplot()           ----> stacked area charts
```

- Distribution & Statistical:
```
plt.hist()                ----> histogram
plt.boxplot()             ----> box plot
plt.violinplot()          ----> violin plot
plt.ecdf()                ----> empirical cumulative distribution
```

- 2D Density & Matrix Plots:
```
plt.imshow()              ----> heatmaps/images
plt.pcolormesh() / plt.matshow()
                          ----> matrix grids
plt.hexbin()              ----> hexagonal binning
plt.contour() / plt.contourf()
                          ----> contour lines/filled contours
```

- Vector & Field Plots:
```
plt.quiver()              ----> vector arrows
plt.streamplot()          ----> streamlines/field lines
```

- Polar & Spatial:
```
plt.polar() or projection='polar'
                         ----> radar charts and polar coordinates
```

Check out the [use cases for these charts](../99.99-Shared_Utilities/BI_charts_use.md), and explore the code for each specific chart [here](../99.99-Shared_Utilities/matplotlib_charts.ipynb).

## 2. Setting Up Matplotlib
Before creating any plots, you need to import the library. The industry standard alias is `plt`.

``` python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Optional: Set a clean style for all plots
plt.style.use('ggplot')
```

## 3. Line Plots (The Basics)
While not explicitly in the title, the Line Plot is the default behavior of Matplotlib and the best starting point. It is best used for **time-series data** or tracking continuous changes over time.

### When to use:
* Tracking stock prices over a month.
* Monitoring daily temperature changes.

``` python
# Data
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May']
revenue = [25000, 32000, 28000, 41000, 39000]

# Creating the plot
plt.plot(months, revenue, marker='o', color='b', linestyle='--', linewidth=2)

# Customizing the plot
plt.title('Monthly Revenue Tracking')
plt.xlabel('Month')
plt.ylabel('Revenue (in USD)')
plt.grid(True)

# Displaying the plot
plt.show()
```

## 4. Bar Plots (`plt.bar`)
Bar plots represent categorical data with rectangular bars with lengths proportional to the values they represent. 

### When to use:
* Comparing quantities of different categories (e.g., Sales by Region).
* Showing rankings (e.g., Top 5 best-selling products).

### Theoretical Concept:
* **Vertical Bar Chart:** Best when categories have short names (e.g., Months, Departments).
* **Horizontal Bar Chart (`plt.barh`):** Best when category labels are long and would overlap on the x-axis.

``` python
# Data
categories = ['Electronics', 'Clothing', 'Home', 'Books', 'Toys']
sales = [15000, 8500, 12000, 4000, 9500]

# Creating a vertical bar chart
plt.figure(figsize=(8, 5))  # Set figure size
plt.bar(categories, sales, color='skyblue', edgecolor='black')

# Adding text labels on top of the bars
for i in range(len(categories)):
    plt.text(i, sales[i] + 500, str(sales[i]), ha='center')

plt.title('Sales by Product Category')
plt.xlabel('Category')
plt.ylabel('Total Sales ($)')
plt.show()
```

## 5. Pie Charts (`plt.pie`)
Pie charts show the proportional distribution of items within a single category. The entire pie represents 100%.

### When to use:
* Showing market share.
* Visualizing the breakdown of a budget.

### Best Practices:
* Do not use a pie chart if you have more than 5-6 categories (it becomes unreadable).
* Use the `explode` parameter to highlight a specific slice.
* Use `autopct` to automatically calculate and display percentages.

``` python
# Data
labels = ['Rent', 'Food', 'Transport', 'Utilities', 'Entertainment']
expenses = [1200, 400, 150, 200, 300]
colors = ['#ff9999','#66b3ff','#99ff99','#ffcc99', '#c2c2f0']

# Explode the 1st slice (Rent) to make it stand out
explode = (0.1, 0, 0, 0, 0)  

# Creating the pie chart
plt.figure(figsize=(6, 6))
plt.pie(expenses, explode=explode, labels=labels, colors=colors, 
        autopct='%1.1f%%', shadow=True, startangle=140)

# Ensure the pie is drawn as a perfect circle
plt.axis('equal') 
plt.title('Monthly Expense Breakdown')
plt.show()
```

## 6. Stack Plots (`plt.stackplot`)
While pie charts provide a snapshot of parts making up a whole at a single point in time, **Stack Plots** (or area charts) allow you to visualize how those parts change over time, stacked on top of one another.

### When to use:
- Tracking the distribution of tasks by team members over a project timeline. 
- Visualizing website traffic sources (Organic, Direct, Social) over a week.

``` Python
# Data: Tracking how a student spends their day over a week
days = [1, 2, 3, 4, 5, 6, 7]
studying = [3, 4, 3, 5, 4, 3, 4]
playing = [2, 2, 1, 1, 2, 3, 2]
watching_tv = [2, 1, 2, 2, 1, 1, 1]
sleeping = [5, 5, 6, 5, 6, 5, 5]

labels = ['Studying', 'Playing', 'Watching TV', 'Sleeping']
colors = ['skyblue', 'lightgreen', 'gold', 'lightcoral']

# Creating the stack plot
plt.figure(figsize=(10, 6))
plt.stackplot(days, studying, playing, watching_tv, sleeping, 
              labels=labels, colors=colors, alpha=0.8)

# Customizing
plt.legend(loc='upper left')
plt.title('Weekly Activity Tracker')
plt.xlabel('Day of the Week')
plt.ylabel('Hours Spent')
plt.grid(True)
plt.show()
```

## 7. Histograms (`plt.hist`)
A histogram visualizes the distribution of a numerical dataset by grouping continuous data into ranges called **bins**.

### When to use:
- Understanding the age distribution of a customer base. 
- Checking if test scores or salaries are normally distributed, and detecting extreme outliers.

``` Python
import numpy as np

# Data: Ages of viewers
ages = [15, 22, 25, 25, 27, 30, 32, 35, 38, 40, 45, 48, 50, 55, 60]
bins = [10, 20, 30, 40, 50, 60, 70] # Custom bin edges

# Creating the histogram
# edgecolor adds borders to the bars for visual clarity
plt.hist(ages, bins=bins, edgecolor='black', color='mediumpurple')

# Adding a vertical reference line for the mean average
mean_age = np.mean(ages)
plt.axvline(mean_age, color='red', linestyle='--', linewidth=2, label=f'Mean Age ({mean_age:.1f})')

# Customizing
plt.title('Age Distribution of Viewers')
plt.xlabel('Age Group')
plt.ylabel('Frequency')
plt.legend()
plt.show()
```

## 8. Scatter Plots (`plt.scatter`)
Scatter plots map individual data points on an X and Y axis to show the relationship (correlation) between two numerical variables.

### When to use:
- Analyzing if more study hours lead to higher exam scores. 
- Finding clustering patterns or correlations in raw data.

### Advanced Features (Colors, Sizes, and Colormaps)
You can dynamically adjust the size (`s`) and color (`c`) of the data points to add third and fourth dimensions to your visual.

``` Python
# Data
study_hours = [1, 2, 3, 4, 5, 6, 7, 8, 9]
exam_scores = [40, 45, 50, 55, 60, 65, 75, 85, 90]

# Size of points scales with the score
sizes = [score * 3 for score in exam_scores] 

# Creating the scatter plot using a colormap (cmap)
# The color intensity will map to the exam score
plt.scatter(study_hours, exam_scores, s=sizes, c=exam_scores, cmap='viridis', alpha=0.8)

# Adding a colorbar to explain the gradient
plt.colorbar(label='Score Intensity')

# Annotating a specific outlier or point of interest
plt.annotate('Top Performer', xy=(9, 90), xytext=(7, 80),
             arrowprops=dict(facecolor='black', arrowstyle='->'))

plt.title('Impact of Study Hours on Exam Scores')
plt.xlabel('Study Hours')
plt.ylabel('Exam Score')
plt.grid(True)
plt.show()
```

## 9. Subplots (`plt.subplots`)
When comparing different datasets or aspects of the same data, placing multiple plots side-by-side or in a grid is vastly superior to generating separate images.

The `plt.subplots()` function is the cleanest, most object-oriented way to generate these grids. It returns a `Figure` object (the whole canvas) and an array of `Axes` objects (the individual plots).

### When to use:
- Building multi-chart dashboards for a presentation. 
- Comparing raw data alongside cleaned data visually.

``` Python
# Data
x = [1, 2, 3, 4, 5]
y_linear = [i * 2 for i in x]
y_squared = [i ** 2 for i in x]

# Create a figure with 1 row and 2 columns
# figsize=(width, height) in inches
fig, axs = plt.subplots(1, 2, figsize=(10, 4))

# Plotting on the first subplot (index 0)
axs[0].plot(x, y_linear, color='blue', marker='o')
axs[0].set_title('Linear Growth (x * 2)')
axs[0].set_xlabel('X Axis')
axs[0].set_ylabel('Y Axis')

# Plotting on the second subplot (index 1)
axs[1].plot(x, y_squared, color='red', marker='s')
axs[1].set_title('Exponential Growth (x squared)')
axs[1].set_xlabel('X Axis')

# Add a main title for the entire figure
fig.suptitle('Growth Rate Comparison', fontsize=14)

# Automatically adjust spacing to prevent labels from overlapping
fig.tight_layout()
plt.show()
```

## 10. General Customization Checklist
Whenever you create a plot in Matplotlib, ensure you tick these boxes for maximum readability:
1. `plt.title()`: Does the plot have a clear, descriptive title?
2. `plt.xlabel()` & `plt.ylabel()`: Are the axes labeled? Do they include units (e.g., "$", "Years", "Kg")?
3. `plt.legend()`: If there are multiple lines or categories, is there a legend explaining what the colors mean?
4. `plt.figure(figsize=(x, y))`: Is the aspect ratio appropriate for the data?
