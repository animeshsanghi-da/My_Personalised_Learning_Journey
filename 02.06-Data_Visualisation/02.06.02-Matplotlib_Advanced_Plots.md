# Matplotlib: Advanced & Specialized Plots

## Overview
While standard plots (Lines, Bars, and Scatters) cover 80% of daily Data Analytics tasks, there are times when your data demands a more specialized visual approach. Whether you are dealing with massive datasets that cause scatter-plot overlap, visualizing vector fields, or mapping distributions in granular detail, Matplotlib's advanced plot types give you the precision tools needed for the job.

This guide covers the remaining specialized visualizations, breaking them down into Relational, Statistical, 2D Density, Vector, and Polar plots.

---

## 1. Advanced Relational Plots

### Step Plots (`plt.step`)
A step plot is similar to a line plot, but instead of connecting points with the shortest diagonal line, it uses horizontal and vertical lines to form a step-like progression.

### When to use:
* Visualizing changes that happen abruptly rather than gradually (e.g., tax brackets, interest rate hikes, or inventory levels).

``` python
import matplotlib.pyplot as plt
import numpy as np

# Data: Bank interest rate changes over 6 quarters
quarters = np.array([1, 2, 3, 4, 5, 6])
rates = np.array([2.5, 2.5, 2.75, 3.0, 3.0, 3.25])

plt.figure(figsize=(8, 4))
# 'where="mid"' means the step occurs in the middle of the interval
plt.step(quarters, rates, where='mid', color='darkred', linewidth=2, marker='o')

plt.title('Central Bank Interest Rate Adjustments')
plt.xlabel('Quarter')
plt.ylabel('Interest Rate (%)')
plt.grid(True, linestyle='--', alpha=0.6)
plt.show()
```

### Lollipop Charts (`plt.stem`)
A stem plot (or lollipop chart) draws vertical lines from a baseline to the data point, placing a marker at the top. It is an excellent, cleaner alternative to a standard bar chart when you have many categories.

### When to use:
* Comparing many items where thick bars would look too cluttered.
* Highlighting deviations from a baseline (e.g., positive vs. negative growth).

``` python
# Data: Product sales growth vs previous year (some positive, some negative)
products = ['Prod A', 'Prod B', 'Prod C', 'Prod D', 'Prod E', 'Prod F']
growth = [12, -5, 8, 15, -2, 6]

plt.figure(figsize=(8, 4))
plt.stem(products, growth, basefmt="black", linefmt="gray", markerfmt="bo")

plt.title('Year-Over-Year Product Growth')
plt.ylabel('Growth (%)')
plt.show()
```

## 2. Advanced Statistical & Distribution Plots

### Box Plots (`plt.boxplot`)
Box plots visualize the 5-number summary of a dataset: Minimum, First Quartile (Q1), Median, Third Quartile (Q3), and Maximum, while explicitly flagging outliers.

### When to use:
* Comparing the distribution, spread, and outliers of numerical data across different categories (e.g., Salaries across different departments).

``` python
# Data: Test scores from three different classes
class_a = np.random.normal(70, 10, 100)
class_b = np.random.normal(80, 5, 100)
class_c = np.random.normal(60, 15, 100)

plt.figure(figsize=(8, 5))
plt.boxplot([class_a, class_b, class_c], labels=['Class A', 'Class B', 'Class C'], patch_artist=True)

plt.title('Exam Score Distributions by Class')
plt.ylabel('Scores')
plt.grid(axis='y', linestyle='--', alpha=0.7)
plt.show()
```

### Violin Plots (`plt.violinplot`)
A violin plot is a hybrid of a box plot and a kernel density plot. Instead of just showing summary statistics, it shows the full probability density of the data at different values (the "thicker" the violin, the more common the value).

### When to use:
* When you need to see if data is bimodal (has two peaks), which a box plot might hide.

``` python
plt.figure(figsize=(8, 5))
# showmeans=True displays the mean of the dataset
plt.violinplot([class_a, class_b, class_c], showmeans=True)

plt.xticks([1, 2, 3], ['Class A', 'Class B', 'Class C'])
plt.title('Exam Score Density (Violin Plot)')
plt.ylabel('Scores')
plt.show()
```

### Empirical Cumulative Distribution (`plt.ecdf`)
*Note: Available natively in Matplotlib 3.8+.* 
The ECDF plots all data points from smallest to largest against their cumulative probability.

### When to use:
* Answering questions like: "What percentage of employees make less than $75,000?"

``` python
# Data: 200 random salaries
salaries = np.random.normal(75000, 15000, 200)

plt.figure(figsize=(8, 4))
plt.ecdf(salaries, label='Salary Distribution')

plt.axhline(0.5, color='red', linestyle='--', label='Median (50th Percentile)')
plt.title('Cumulative Distribution of Salaries')
plt.xlabel('Salary ($)')
plt.ylabel('Proportion of Employees')
plt.legend()
plt.show()
```

## 3. 2D Density & Matrix Plots

### Hexagonal Binning (`plt.hexbin`)
When you have thousands of data points in a scatter plot, they overlap into a giant unreadable blob (called overplotting). `hexbin` divides the plot into hexagons and colors them based on how many points fall inside.

### When to use:
* Visualizing density in massive datasets with overlapping X/Y coordinates.

``` python
# Generating 10,000 overlapping data points
x = np.random.randn(10000)
y = np.random.randn(10000)

plt.figure(figsize=(8, 6))
# gridsize determines the number of hexagons. cmap sets the color scale.
hb = plt.hexbin(x, y, gridsize=30, cmap='inferno')
plt.colorbar(hb, label='Number of Points inside Hexagon')

plt.title('High-Density Scatter Data (Hexbin)')
plt.show()
```

### Image / Heatmap Grids (`plt.imshow`)
`imshow` displays data as an image or a 2D grid of colored pixels. It is the core engine for creating correlation heatmaps.

``` python
# Creating a 10x10 correlation matrix-like array
matrix_data = np.random.rand(10, 10)

plt.figure(figsize=(6, 6))
plt.imshow(matrix_data, cmap='coolwarm', interpolation='nearest')
plt.colorbar(label='Correlation Coefficient')
plt.title('Custom Heatmap Matrix')
plt.show()
```

### Contour Plots (`plt.contour` & `plt.contourf`)
Contour plots represent 3D data on a 2D surface using contour lines (like a topographical map). `contourf` fills the spaces between the lines with color.

``` python
# Creating a 2D grid
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y) # The "Height" or Z-axis

plt.figure(figsize=(8, 6))
# Filled contour
contour = plt.contourf(X, Y, Z, cmap='viridis')
plt.colorbar(contour, label='Elevation/Z-Value')

# Overlaying contour lines
plt.contour(X, Y, Z, colors='black', linewidths=0.5)
plt.title('Topographical Contour Plot')
plt.show()
```

## 4. Vector & Field Plots

### Quiver (Vector Arrows) & Streamplots
These plots are primarily used in physics, engineering, and meteorology to visualize vector fields (data that has both magnitude/strength and direction).

### When to use:
* Mapping wind direction and speed across a geographic grid.
* Visualizing magnetic or fluid flow dynamics.

``` python
# Data grid
Y, X = np.mgrid[-3:3:15j, -3:3:15j]
# U and V are the vector directions
U = -1 - X**2 + Y
V = 1 + X - Y**2

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))

# Quiver (Discrete Arrows)
ax1.quiver(X, Y, U, V, color='teal')
ax1.set_title('Quiver Plot (Vector Arrows)')

# Streamplot (Continuous Flow Lines)
speed = np.sqrt(U**2 + V**2)
ax2.streamplot(X, Y, U, V, color=speed, cmap='plasma', linewidth=1.5)
ax2.set_title('Streamplot (Flow Lines)')

plt.tight_layout()
plt.show()
```

## 5. Polar & Spatial Plots

### Polar Coordinates (`plt.polar`)
Instead of an X (horizontal) and Y (vertical) axis, polar plots use a radius (distance from the center) and an angle (degrees or radians). 

### When to use:
* Creating Radar/Spider charts to compare features of a single entity (e.g., comparing stats of two athletes).
* Visualizing cyclical data (e.g., average wind speeds by compass direction, or website traffic by hour of the day plotted on a 24-hour clock face).

``` python
# Data: Average metric by angle
angles = np.linspace(0, 2 * np.pi, 6, endpoint=False)
values = [4, 5, 3, 6, 2, 4]

# Close the loop so the shape connects back to the start
angles = np.concatenate((angles, [angles[0]]))
values = np.concatenate((values, [values[0]]))

# Set the projection to polar
plt.figure(figsize=(6, 6))
ax = plt.subplot(111, projection='polar')

# Plot lines and fill area
ax.plot(angles, values, color='purple', linewidth=2)
ax.fill(angles, values, color='purple', alpha=0.25)

# Set labels for the axes
ax.set_xticks(angles[:-1])
ax.set_xticklabels(['Speed', 'Power', 'Stamina', 'Agility', 'Strategy', 'Teamwork'])
plt.title('Athlete Skill Radar Chart', va='bottom')
plt.show()
```
