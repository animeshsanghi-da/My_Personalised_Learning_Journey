# Advanced Customisation with Plotly Graph Objects (GO)

## Introduction
While Plotly Express (`px`) is fantastic for rapid, exploratory data analysis, business stakeholders often have highly specific reporting requirements. Whether it is matching exact corporate branding, layering multiple chart types on a single plot, or building dual-axis visualisations to compare differing scales, Plotly Express can sometimes hit a wall. 

This is where **Plotly Graph Objects (`go`)** comes in. As a Business Intelligence Analyst, mastering `go` gives you absolute, granular control over every single pixel, trace, and layout property of your visualisations.

---

## 1. Plotly Express vs. Graph Objects
* **Plotly Express (`px`):** High-level wrapper. Best for quick standard charts (scatter, bar, line) directly from a Pandas DataFrame.
* **Graph Objects (`go`):** Low-level architectural framework. You build the chart piece by piece, adding "traces" (individual layers of data) and customising the "layout".

---

## 2. The Anatomy of a Graph Object
A Graph Object figure is essentially a large, nested dictionary containing two main components:
1. **Data:** A list of traces (e.g., `go.Scatter`, `go.Bar`).
2. **Layout:** The styling instructions for the axes, title, background, and legends.

``` python
import plotly.graph_objects as go

# Instantiating an empty figure
fig = go.Figure()

# Adding a layer (trace)
fig.add_trace(go.Bar(x=['A', 'B', 'C'], y=[10, 20, 15]))

# Customising the layout
fig.update_layout(title="Simple GO Bar Chart")
fig.show()
```

## 3. Applied Business Scenario: The Dual-Axis Chart
One of the most common requests in BI roles is comparing two metrics with completely different scales. 

Let's apply this to the **Olist E-Commerce dataset**. Imagine we want to visualise **Total Monthly Revenue** (in millions) alongside the **Average Delivery Time** (in days) on the same chart to see if higher sales volume negatively impacts logistics.

``` python
import plotly.graph_objects as go
from plotly.subplots import make_subplots
import pandas as pd

# 1. Create a figure with a secondary y-axis
fig = make_subplots(specs=[[{"secondary_y": True}]])

# 2. Add the First Trace (Revenue - Bar Chart)
fig.add_trace(
    go.Bar(
        x=['Jan', 'Feb', 'Mar', 'Apr', 'May'],
        y=[1.2, 1.5, 1.1, 1.8, 2.1], # Revenue in Millions
        name="Total Revenue (M$)",
        marker_color="#2c3e50" # Corporate Blue
    ),
    secondary_y=False, # Left Y-Axis
)

# 3. Add the Second Trace (Delivery Time - Line Chart)
fig.add_trace(
    go.Scatter(
        x=['Jan', 'Feb', 'Mar', 'Apr', 'May'],
        y=[12.5, 14.2, 11.8, 16.5, 18.1], # Delivery Days
        name="Avg Delivery (Days)",
        mode="lines+markers",
        line=dict(color="#e74c3c", width=3), # Alert Red
        marker=dict(size=8)
    ),
    secondary_y=True, # Right Y-Axis
)

# 4. Update Layout for Professional Presentation
fig.update_layout(
    title_text="Olist: Revenue vs. Delivery Time Turnaround",
    plot_bgcolor="white",
    hovermode="x unified", # Shows both metrics when hovering over a month
    legend=dict(orientation="h", yanchor="bottom", y=1.02, xanchor="right", x=1)
)

# 5. Format Axes
fig.update_yaxes(title_text="Revenue (Millions $)", showgrid=True, gridcolor="lightgrey", secondary_y=False)
fig.update_yaxes(title_text="Delivery Time (Days)", showgrid=False, secondary_y=True)

fig.show()
```

## 4. Granular Customisations for Impact
To elevate an analysis from standard to exceptional, you need to guide the stakeholder's eye to the insights.

### A. Annotations
Annotations allow you to point out specific anomalies or events directly on the canvas.

``` python
fig.add_annotation(
    x="May",
    y=18.1,
    yref="y2", # Align to secondary y-axis
    text="Logistics Bottleneck During Peak Sales",
    showarrow=True,
    arrowhead=1,
    arrowcolor="black",
    bgcolor="yellow",
    font=dict(color="black", size=12)
)
```

### B. Advanced Hover Templates
Default tooltips can sometimes be messy. `hovertemplate` allows you to format exactly what the user sees, integrating HTML for highly professional tooltips.

``` python
fig.add_trace(
    go.Bar(
        x=df['Month'],
        y=df['Revenue'],
        hovertemplate="<b>%{x}</b><br><br>Revenue: R$ %{y:,.2f}<extra></extra>" 
        # <extra></extra> hides the secondary trace name box
    )
)
```

---

## 5. Pro-Tips for Data Analysts
1. **Always use `plot_bgcolor="white"`:** The default Plotly background is a light blue/grey. Setting it to white with subtle gridlines instantly makes it look like a premium BI tool export.
2. **Standardise Colours:** Create a dictionary of brand colours in your Python script and pass them into `marker_color`.
3. **Template Saving:** Once you build a beautiful layout in `go`, you can save it as a custom Plotly template to apply globally across all your future notebooks.
