## 2. Core Concepts: Streamlit + Plotly
Streamlit reads and executes your Python script from top to bottom every time a user interacts with a widget. To display a Plotly figure, you simply create the figure as you normally would in a notebook, and then pass it to Streamlit's `st.plotly_chart()` function.

### The Standard Workflow:
1. **Load Data:** Import your dataset (crucially, using `st.cache_data` for performance).
2. **Create Widgets:** Add interactive UI elements like dropdowns or sliders (`st.selectbox`, `st.slider`).
3. **Filter Data:** Use the inputs from those widgets to filter your Pandas DataFrame dynamically.
4. **Build Plotly Chart:** Create a Plotly Express or Graph Objects figure using the newly filtered data.
5. **Render:** Display it on the app using `st.plotly_chart(fig)`.

## 3. End-to-End Dashboard Example
Let's build a functional, interactive dashboard. We will use a mock sales dataset, but the logic applies perfectly to massive datasets like your Olist E-commerce data.

Create a new Python file named `app.py` in VS Code and paste the following code:

``` python
import streamlit as st
import pandas as pd
import plotly.express as px

# 1. Page Configuration (Must be the first Streamlit command)
st.set_page_config(page_title="Sales Dashboard", layout="wide")
st.title("Interactive Sales & Revenue Dashboard 📊")

# 2. Load Data 
# @st.cache_data prevents reloading the data every time a user clicks a button
@st.cache_data
def load_data():
    data = pd.DataFrame({
        'Month': ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        'Region': ['North', 'North', 'North', 'North', 'North', 'North', 'South', 'South', 'South', 'South', 'South', 'South'],
        'Sales': [15000, 18000, 22000, 19000, 25000, 27000, 12000, 14000, 18000, 16000, 21000, 23000],
        'Profit': [1500, 1800, 2100, 1850, 2600, 2800, 1100, 1300, 1600, 1500, 2000, 2200]
    })
    return data

df = load_data()

# 3. Sidebar for User Inputs
st.sidebar.header("Filter Options")
selected_region = st.sidebar.selectbox(
    "Select a Region:", 
    options=["All"] + list(df['Region'].unique())
)

# 4. Filter the DataFrame based on user selection
if selected_region != "All":
    filtered_df = df[df['Region'] == selected_region]
else:
    filtered_df = df

# 5. Layout with Columns
col1, col2 = st.columns(2)

# 6. Build and Display Plotly Charts
with col1:
    st.subheader("Sales by Month")
    # Plotly Express Bar Chart
    fig_sales = px.bar(
        filtered_df, 
        x='Month', 
        y='Sales', 
        color='Region',
        barmode='group',
        title=f"Sales Data ({selected_region} Region)"
    )
    # Render in Streamlit (use_container_width ensures it fits the column)
    st.plotly_chart(fig_sales, use_container_width=True)

with col2:
    st.subheader("Profit Trend")
    # Plotly Express Line Chart
    fig_profit = px.line(
        filtered_df, 
        x='Month', 
        y='Profit', 
        color='Region',
        markers=True,
        title="Monthly Profit Margins"
    )
    st.plotly_chart(fig_profit, use_container_width=True)

# 7. Display Raw Data (Optional, great for stakeholder transparency)
st.divider()
if st.checkbox("Show Raw Data"):
    st.dataframe(filtered_df, use_container_width=True)
```

### How to Run Your Dashboard:
Open your terminal in VS Code, navigate to the folder containing your `app.py` file, and execute:

``` bash
streamlit run app.py
```

This will spin up a local development web server and automatically open your new interactive dashboard in your default web browser. As you change the code in VS Code and hit save, you can click "Always Rerun" in the browser to see updates instantly.

---

## 4. Best Practices for Business Dashboards
* **Leverage `@st.cache_data`:** Always cache your data loading and heavy preprocessing functions. You do not want Streamlit re-reading a massive CSV or querying a SQL database every time a user simply moves a slider.
* **`use_container_width=True`:** Always pass this argument to `st.plotly_chart()`. It ensures your Plotly charts are responsive and automatically resize to fit Streamlit's columns and the user's specific screen size.
* **Avoid Clutter:** Don't overload a single page with a dozen charts. Use `st.tabs()` to separate different analytical views (e.g., "Financials" vs "Customer Demographics") or use `st.sidebar` to keep controls tucked away neatly.
