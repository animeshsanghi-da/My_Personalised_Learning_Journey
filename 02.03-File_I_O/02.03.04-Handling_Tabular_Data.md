# Handling Tabular Data: CSV and Excel Files

## Overview
As a Data Analyst or Software Developer, you will spend a massive amount of time working with tabular data. While plain text and JSON are great, business data usually lives in spreadsheets. Python provides built-in modules for simple CSV tasks, but for heavy lifting, the external library `pandas` is the industry standard.

---

## 1. The Built-in `csv` Module
Python comes with a built-in `csv` module that handles basic reading and writing without needing to install external libraries.

### Reading a CSV
Use `csv.reader` to iterate through rows. Remember to use the `with` statement!

```python
import csv

# Reading a CSV file
with open("sales_data.csv", "r") as file:
    csv_reader = csv.reader(file)
    header = next(csv_reader)  # Extract the header row first
    print("Columns:", header)
    
    for row in csv_reader:
        print(row) # Each row is returned as a list of strings
```

### Writing a CSV
Use `csv.writer` to output lists of data into a CSV format. Use `newline=''` in the `open()` function to prevent extra blank lines in Windows.

```python
import csv

data_to_write = [
    ["Employee_ID", "Name", "Department"],
    [101, "Animesh", "Data"],
    [102, "Sarah", "Engineering"]
]

with open("employees.csv", "w", newline='') as file:
    csv_writer = csv.writer(file)
    csv_writer.writerows(data_to_write) # Writes all rows at once
```

## 2. The Data Analyst's Standard: `pandas`
While the `csv` module is fine for simple scripts, `pandas` is the ultimate tool for tabular data. It loads data into a **DataFrame** (a 2D table), making it incredibly easy to manipulate, filter, and export.

*Note: You must install pandas first using `pip install pandas`.*

### Reading CSV and Excel Files
Pandas makes reading files a one-line operation. Note that reading Excel files requires the `openpyxl` engine under the hood (`pip install openpyxl`).

```python
import pandas as pd

# Read a CSV file into a DataFrame
df_csv = pd.read_csv("sales_data.csv")

# Read a specific sheet from an Excel file
df_excel = pd.read_excel("financials.xlsx", sheet_name="Q1_Revenue")

# Display the first 5 rows
print(df_csv.head())
```

### Writing to CSV and Excel
Once you have processed your DataFrame, writing it back to a file is just as easy.

```python
import pandas as pd

# Assume 'df' is a DataFrame we just cleaned and filtered
# Write to CSV (index=False prevents Pandas from writing row numbers as a column)
df.to_csv("cleaned_sales.csv", index=False)

# Write to Excel
df.to_excel("final_report.xlsx", index=False, sheet_name="Summary")
```

---

## Summary & Best Practices
1.  **Use `csv` for lightweight scripts:** If you just need to append a quick log to a CSV and don't want heavy dependencies, the built-in module is perfect.
2.  **Use `pandas` for analytics:** If you need to filter, aggregate, or clean the data, immediately reach for `pandas`. 
3.  **Mind the `index=False`:** When exporting with pandas, always consider if you need the row numbers saved. Usually, you don't.
