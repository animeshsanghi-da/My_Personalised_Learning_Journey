# Database Connectivity: Reading and Writing with MySQL

## Overview
While CSV and JSON files are great for moving data around, enterprise data permanently resides in Relational Databases like MySQL. To build data pipelines, automate reports, or feed web applications, Python needs to talk directly to these databases. 

We can connect to MySQL using the official `mysql-connector-python` library, and we can also use `pandas` combined with `SQLAlchemy` for seamless analytics workflows.

---

## 1. Setting Up the Connection
First, install the required driver: `pip install mysql-connector-python`.

To communicate with a MySQL database, you need to establish a **connection** using your credentials (host, user, password, and database name) and then create a **cursor** object to execute SQL commands.

```python
import mysql.connector

# 1. Establish the connection
db_connection = mysql.connector.connect(
    host="localhost",
    user="root",
    password="your_password",
    database="company_db"
)

# 2. Create a cursor to interact with the database
cursor = db_connection.cursor()
print("Successfully connected to the database!")
```

---

## 2. Reading Data (Executing SELECT)
To fetch data, you execute a `SELECT` query via the cursor, and then retrieve the results using `.fetchall()` or `.fetchone()`.

```python
# Write the SQL query
query = "SELECT employee_id, first_name, department FROM employees WHERE active = 1"

# Execute the query
cursor.execute(query)

# Fetch all rows returned by the query
records = cursor.fetchall()

# Iterate through the results
for row in records:
    print(f"ID: {row[0]}, Name: {row[1]}, Dept: {row[2]}")
```

---

## 3. Writing Data (Executing INSERT)
Writing data requires you to be careful about SQL Injection. Always use **parameterized queries** (using `%s` as placeholders) instead of f-strings.

Whenever you modify the database (INSERT, UPDATE, DELETE), you **must** call `.commit()` on the connection to save the changes permanently.

```python
# The query with %s placeholders
insert_query = "INSERT INTO employees (first_name, department, active) VALUES (%s, %s, %s)"

# The data tuple to insert
new_employee = ("Animesh", "Data Analytics", 1)

# Execute and commit
cursor.execute(insert_query, new_employee)
db_connection.commit()

print(f"{cursor.rowcount} record(s) inserted successfully.")
```

### Closing the Connection
Just like files, database connections consume resources. Always close the cursor and connection when done.
```python
cursor.close()
db_connection.close()
```

---

## 4. The Pandas Way (Best for Analytics)
If you are doing Data Analytics, looping through rows with cursors is tedious. Instead, you can use `pandas` to run a SQL query and dump the results directly into a DataFrame! 

*(Requires: `pip install sqlalchemy pymysql`)*

```python
import pandas as pd
from sqlalchemy import create_engine

# Create an SQLAlchemy engine (the connection string format: dialect+driver://username:password@host/database)
engine = create_engine("mysql+pymysql://root:your_password@localhost/company_db")

# Read directly into a DataFrame
query = "SELECT * FROM sales_data WHERE year = 2023"
df = pd.read_sql(query, engine)

print(df.head())

# Write a DataFrame directly to a new MySQL table
df.to_sql(name='sales_backup_2023', con=engine, if_exists='replace', index=False)
```

---
## Summary & Best Practices
1.  **Commit your changes:** When writing data via cursors, nothing is saved until you run `connection.commit()`.
2.  **Prevent SQL Injection:** Never use f-strings or string concatenation for SQL queries. Always use `%s` placeholders.
3.  **Use Pandas for Analytics:** If your end goal is to Analyse the data or clean it, bypass cursors entirely and use `pd.read_sql()` to get your data straight into a DataFrame.
