# File System Operations: OS & Shutil for Data Analysts

## Overview
As a Data Analyst, your automated data pipelines must often interact directly with your operating system—creating directory structures, checking for incoming raw `.csv` downloads, batch-renaming files, moving processed reports to archive folders, and safely deleting temporary logs. 

Python provides two essential modules for this:
* **`os`**: Low-level module for operating system interactions, directory creation, path manipulation, and environment navigation.
* **`shutil`**: High-level module built for complex file operations like copying, moving, archiving, and recursive directory tree removal.

---

## 1. Navigating and Inspecting Directories (`os`)

Before reading or writing data, your script needs to inspect where it is executing and what files exist in the target directory.

``` python
import os

# 1. Get current working directory (PWD equivalent)
current_dir = os.getcwd()
print(f"Current Working Directory: {current_dir}")

# 2. List all files and folders in a directory
files = os.listdir(".")  # "." represents the current directory
print("Files in directory:", files)

# Filter listing specifically for data files
csv_files = [f for f in os.listdir(".") if f.endswith(".csv")]
print("CSV files found:", csv_files)

# 3. Change working directory
# os.chdir("data/raw")
```

## 3. Platform-Independent Path Manipulation (`os.path`)

File paths vary across operating systems (Windows uses backslashes `\`, while Linux/macOS use forward slashes `/`). Using hardcoded path strings will break your code across different environments. `os.path` resolves this seamlessly.

``` python
import os

# 1. Safely join path components for any Operating System
file_path = os.path.join("data", "raw", "sales_q1_2026.csv")
print("Joined Path:", file_path) 
# Windows Output: data\raw\sales_q1_2026.csv
# Linux/Mac Output: data/raw/sales_q1_2026.csv

# 2. Check existence of files or directories
print("Path exists?", os.path.exists(file_path))
print("Is it a file?", os.path.isfile(file_path))
print("Is it a directory?", os.path.isdir("data/raw"))

# 3. Separate directory name and filename
dir_name, file_name = os.path.split(file_path)
print(f"Directory: {dir_name} | File: {file_name}")

# 4. Separate file name and extension
file_base, ext = os.path.splitext(file_name)
print(f"Base Name: {file_base} | Extension: {ext}")

# 5. Get file size in bytes
# size_in_bytes = os.path.getsize(file_path)
```

## 5. End-to-End Data Analyst Workflow: Automated File Ingestion

Here is a practical, real-world example of how a Data Analyst uses `os` and `shutil` to automate raw download sorting before passing files to Pandas.

``` python
import os
import shutil
import pandas as pd

def organize_and_load_downloads(download_dir="downloads", raw_data_dir="data/raw"):
    """
    Automates scanning a downloads directory for CSVs, moves them to 
    the project's raw data folder, and loads them into Pandas DataFrames.
    """
    # Step 1: Ensure directory structure exists
    os.makedirs(raw_data_dir, exist_ok=True)
    
    # Step 2: Scan for all CSV files
    if not os.path.exists(download_dir):
        print(f"Directory '{download_dir}' does not exist.")
        return
        
    for file_name in os.listdir(download_dir):
        if file_name.endswith(".csv"):
            source_path = os.path.join(download_dir, file_name)
            destination_path = os.path.join(raw_data_dir, file_name)
            
            # Step 3: Move file to project workspace
            shutil.move(source_path, destination_path)
            print(f"Moved: {file_name} -> {raw_data_dir}/")
            
            # Step 4: Verify file size and process
            if os.path.getsize(destination_path) > 0:
                df = pd.read_csv(destination_path)
                print(f"Successfully loaded {file_name} with shape: {df.shape}")
            else:
                print(f"Warning: {file_name} is empty.")

# Execute workflow
# organize_and_load_downloads()
```

## Summary Cheat Sheet

| Task | `os` Module | `shutil` Module |
| :--- | :--- | :--- |
| **Get Current Dir** | `os.getcwd()` | - |
| **List Directory** | `os.listdir(path)` | - |
| **Create Directory** | `os.mkdir()` / `os.makedirs()` | - |
| **Check Existence** | `os.path.exists(path)` | - |
| **Join Paths** | `os.path.join(p1, p2)` | - |
| **Delete File** | `os.remove(file)` | - |
| **Delete Empty Dir** | `os.rmdir(dir)` | - |
| **Delete Non-Empty Dir** | - | `shutil.rmtree(dir)` |
| **Copy File** | - | `shutil.copy(src, dst)` |
| **Move / Rename** | `os.rename(old, new)` | `shutil.move(src, dst)` |
