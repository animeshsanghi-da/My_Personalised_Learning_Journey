# Programmatic Prompting with Python

## Introduction
Up until now, we have treated Prompt Engineering as a manual task—typing instructions into a web interface to get a response. However, as an aspiring Data/BI Analyst, your goal is automation. 

Programmatic prompting bridges the gap between your Python programming skills (OOP, File I/O, Pandas) and Generative AI. By using APIs (Application Programming Interfaces), you can call Large Language Models (LLMs) like Gemini directly from your VS Code or Jupyter Lab environments. This allows you to integrate AI directly into your data pipelines, automating tasks like data summarisation, sentiment analysis, or even dynamically debugging your MySQL ETL scripts.

## 2. Your First API Call
Let us build a simple script to test our connection. This is the foundation for embedding AI into larger applications.

``` python
import os
import google.generativeai as genai
from dotenv import load_dotenv

# Load environment variables securely
load_dotenv()
api_key = os.getenv("GEMINI_API_KEY")

# Configure the API
genai.configure(api_key=api_key)

# Initialize the model
model = genai.GenerativeModel('gemini-1.5-pro')

# Construct the prompt
prompt = """
You are an expert Data Analyst. 
Explain the difference between a LEFT JOIN and an INNER JOIN in MySQL. 
Keep the explanation under 3 sentences.
"""

# Call the API
response = model.generate_content(prompt)

print(response.text)
```

## 3. Integrating LLMs into a Pandas Data Pipeline
Where programmatic prompting truly shines is in processing large datasets. Suppose you have a dataset of customer reviews and you need to classify their sentiment. Writing a traditional algorithm for this is complex, but passing the data to an LLM via Python makes it incredibly simple.

### Example: Automating Data Categorisation
``` python
import pandas as pd
import google.generativeai as genai
import time

# 1. Load your dataset (Simulated here)
data = {
    'Review_ID': [101, 102, 103],
    'Feedback': [
        "The healthcare portal is incredibly slow when uploading records.",
        "Loved the new dashboard update, very intuitive!",
        "The system crashed while I was exporting the CSV file."
    ]
}
df = pd.DataFrame(data)

# 2. Define a function to classify text using the LLM
def classify_sentiment(text):
    prompt = f"""
    Analyse the following user feedback and classify the sentiment as POSITIVE, NEGATIVE, or NEUTRAL.
    Return ONLY the classification word, nothing else.
    
    Feedback: "{text}"
    """
    try:
        response = model.generate_content(prompt)
        # Adding a small sleep to avoid hitting API rate limits
        time.sleep(1) 
        return response.text.strip()
    except Exception as e:
        return "ERROR"

# 3. Apply the function to your DataFrame
df['Sentiment'] = df['Feedback'].apply(classify_sentiment)

print(df)
```

## 4. Advanced: Dynamic Error Handling in ETL Scripts
In your healthcare ETL algorithms, you might encounter dirty data that fails to insert into MySQL. You can use programmatic prompting to dynamically evaluate the error and suggest a fix.

``` python
def handle_etl_error(sql_query, error_message):
    prompt = f"""
    You are an expert MySQL database administrator.
    My Python script attempted to execute the following query:
    {sql_query}
    
    It resulted in this error:
    {error_message}
    
    Analyse the error and provide the corrected SQL query. Do not provide explanations, only the corrected SQL code.
    """
    response = model.generate_content(prompt)
    return response.text
```
