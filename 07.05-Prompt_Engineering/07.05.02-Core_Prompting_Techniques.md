# Core Prompting Techniques for Data Analytics

## Introduction
Interacting with Large Language Models (LLMs) to write Python scripts, debug Pandas DataFrames, or generate complex MySQL queries requires structured logic. Just as an ETL pipeline processes data methodically, a well-engineered prompt guides the AI to the correct output. This module explores three foundational frameworks: Zero-Shot, Few-Shot, and Chain-of-Thought (CoT) prompting, which are essential for breaking down complex analytical problems.

---

## 1. Zero-Shot Prompting
Zero-shot prompting involves giving the LLM a task without providing any prior examples or context regarding the desired output format. You are relying entirely on the model's pre-trained knowledge base.

**Best For:** Simple definitions, basic syntax generation, or broad data summarisation.

**Data Analytics Example:**
``` sql
Write a MySQL query to select all patient records from the 'healthcare_admissions' table where the triage status is 'Critical'.
```

**The limitation:** While fast, zero-shot prompts often fail when applied to highly specific, multi-relational database schemas or intricate algorithm logic, simply because the model lacks the necessary constraints to know exactly what you want.

---

## 2. Few-Shot Prompting
Few-shot prompting provides the model with a few examples (shots) of the input-output mapping you expect. This establishes a clear pattern, ensuring the AI matches your coding style, specific syntax rules, or data cleaning standardisations.

**Best For:** Formatting data, standardising outputs, ensuring regional spelling conventions (e.g., using "Analyse" instead of "Analyze"), or generating queries tailored to a very specific table structure.

**Data Analytics Example:**
``` text
Convert the following raw date strings into standard YYYY-MM-DD format for MySQL ingestion.

Raw: 12th Jan 2024
Formatted: 2024-01-12

Raw: 05/02/2025 (assuming DD/MM/YYYY)
Formatted: 2025-02-05

Raw: March 15 2026
Formatted:
```

By providing examples, you eliminate ambiguity. This drastically reduces the time spent manually reformatting AI-generated code in VS Code or Jupyter Lab.

---

## 3. Chain-of-Thought (CoT) Prompting
Chain-of-Thought is arguably the most powerful technique for a Data Analyst. Instead of asking for the final answer immediately, you instruct the model to break down its reasoning step-by-step. This mirrors the structured 6-stage data process (Ask, Prepare, Process, Analyse, Share, Act) by forcing logical, transparent progression.

**Best For:** Complex ETL algorithms, advanced statistical calculations (like Linear Regression modelling using Scikit-learn), and multi-table SQL joins.

**Data Analytics Example:**
``` python
Task: Write a Python script using Pandas to calculate the rolling 7-day average of hospital admissions.

Instructions: Let's think step-by-step.
1. First, load the raw dataset and ensure the 'admission_date' column is converted to a proper datetime object.
2. Second, sort the DataFrame chronologically by the date.
3. Third, set the date column as the index of the DataFrame.
4. Fourth, apply the rolling() function with a 7-day window and calculate the mean.
5. Finally, reset the index and return the cleaned, aggregated DataFrame.
```

By enforcing a step-by-step methodology, CoT prevents the model from hallucinating complex logic. It forces the AI to "show its work," making it significantly easier for you to audit, debug, and implement the resulting script.

---

## Summary
Mastering these three techniques transforms an LLM from a simple text generator into a highly capable Data Analytics assistant. Zero-shot provides speed for basic queries, Few-shot ensures pattern recognition and formatting consistency, and Chain-of-Thought provides the rigorous logic required for complex problem-solving.
