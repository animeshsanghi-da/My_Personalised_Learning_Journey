# Displaying Text and Markdown
Text functions are used to structure your web app, providing titles, narrative insights, and markdown explanations for your stakeholders.

---
## 1. Displaying Title `st.title()`
The **`st.title`** widget displays text in a large, bold header font, typically used for the main title of a Streamlit web application.

**Standard Syntax**
```python
# The largest text, usually used exactly once at the top of your app.
st.title(body, anchor=None, *, help=None)
```

**Parameter Breakdown**
- **`body`**: The string text to display. It supports GitHub-flavored Markdown, emojis, and inline colored text.
- **`anchor`**: An optional string to use as a custom HTML anchor link. If omitted, Streamlit automatically generates a slugified ID based on the text (e.g., `#my-app-title`). If set to `False`, the title will not display a hoverable anchor link icon.
- **`*`**: Indicates that all subsequent arguments must be passed as keyword-only arguments.
- **`help`**: An optional string tooltip. When provided, a small question mark icon appears next to the title, revealing this text on hover.

**Complete Implementation Example**
This script shows how to implement titles using formatting, custom anchors, tooltips, and dynamic coloring:
```python
import streamlit as st

# Example 1: Standard title with Markdown formatting and emoji shortcodes
st.title("🚀 Markdown-Powered Title")

# Example 2: Title with dynamic inline text coloring
st.title("Analysis of :blue[Financial Data] and :green[Growth Trends]")

# Example 3: Advanced title featuring a custom anchor link and hover tooltip
st.title(
    body="Customized Report Header", 
    anchor="custom-report-section", 
    help="This is the primary summary dashboard for executive review."
)
```

## 2. Displaying Headers and Subheaders
Used to visually divide your app into logical sections.

### A. Displaying Header `st.header()`
The **`st.header`** widget displays text in a bold, medium-sized heading font. It is typically used to separate different sections of a page or app layout, ranking just below `st.title` in visual hierarchy.

**Standard Syntax**
```python
st.header(body, anchor=None, *, help=None, divider=False)
```

Parameter Breakdown
- **`body`**: The string text to display. It supports GitHub-flavored Markdown, emojis, and inline text coloring.
- **`anchor`**: An optional string to use as a custom HTML anchor link. If omitted, Streamlit automatically generates a slugified ID based on the text. If set to `False`, the header will not show a hoverable link icon.
- **`help`**: An optional string tooltip. When provided, a small question mark icon appears next to the header, revealing this text on hover.
- **`divider`**: A boolean flag (`True` or `False`) or a string color. If `True`, it draws a horizontal line under the header. You can also specify a color string (e.g., `"blue"`) to change the divider line's color.

**Complete Implementation Example**
This script demonstrates various ways to render section headers, use dividers, and format inline colors:
```python
import streamlit as st

# Example 1: Standard header with Markdown formatting and a default divider line
st.header("📊 Data Metrics Overview", divider=True)

# Example 2: Header with a custom colored divider line
st.header("📈 Financial Forecasts", divider="orange")

# Example 3: Header with a hover tooltip and an inline colored phrase
st.header(
    body="System Performance: :green[Operational]",
    help="This section monitors live hardware load and API latency.",
    anchor="perf-metrics"
)
```

### B. Displaying Subheader `st.subheader()`
The **`st.subheader`** widget displays text in a bold, small-to-medium heading font. It ranks just below `st.header` in visual hierarchy and is perfect for labeling minor sub-sections, charts, or individual input controls within your dashboard layout.

**Standard Syntax**
```python
st.subheader(body, anchor=None, *, help=None, divider=False)
```

**Parameter Breakdown**
- **`body`**: The string text to display. It supports GitHub-flavored Markdown text, emojis, and inline text coloring.
- **`anchor`**: An optional string for a custom HTML anchor link. If left out, Streamlit automatically generates a slugified ID from the text. If set to `False`, the hoverable link icon is disabled.
- **`help`**: An optional string tooltip. If provided, a small question mark icon appears next to the subheader, revealing this text on hover.
- **`divider`**: A boolean flag (`True` or `False`) or a string color. Set to `True` to draw a line underneath the text, or pass a valid color name string to customize the divider line color. You can use: `"blue"`, `"green"`, `"orange"`, `"red"`, `"violet"`, `"gray"`, or `"grey"`.

**Complete Implementation Example**
This script demonstrates how to render subheaders with dividers, inline styling, and custom tooltips:
```python
import streamlit as st

# Example 1: Standard subheader with an emoji and default divider line
st.subheader("📋 Regional Sales Breakdown", divider=True)

# Example 2: Subheader with a custom colored divider line
st.subheader("💡 Key Takeaways", divider="violet")

# Example 3: Subheader with inline coloring and a hover tooltip
st.subheader(
    body="Model Accuracy: :blue[94.2%]",
    help="Calculated using the latest validation dataset.",
    anchor="model-accuracy-stats"
)
```

## 3. Writing Paragraphs `st.write()`
The **`st.write`** widget is Streamlit's  **"Swiss Army Knife"** for displaying content. It acts as a smart wrapper that automatically detects the data type of whatever you pass into it and renders it in the best possible format.

**Standard Syntax**
```python
# This command automatically formats whatever you pass it (text, tables, charts).
# It is your go-to command for standard paragraph text.
st.write(*args, unsafe_allow_html=False)
```

**Parameter Breakdown**
- **`*args`**: One or more arguments of any data type. You can pass strings, dataframes, charts, metrics, or multiple objects separated by commas.
- **`unsafe_allow_html`**: A boolean flag (`True` or `False`). Set to `True` if you explicitly want to render raw HTML strings. _Note: Use with caution to prevent cross-site scripting (XSS) risks._

**How `st.write` Formats Different Inputs**
Because `st.write` relies on type inspection, it automatically redirects your data to more specific Streamlit commands behind the scenes:
1. **Strings**: Renders as Markdown text (similar to `st.markdown`).
2. **DataFrames / Series**: Renders as an interactive table (similar to `st.dataframe`).
3. **Matplotlib / Altair / Plotly / Bokeh Charts**: Renders the actual interactive visual plot (similar to `st.pyplot`, `st.altair_chart`, etc.).
4. **Dictionaries / Lists**: Renders as an interactive, syntax-highlighted tree structure (similar to `st.json`).
5. **Errors / Exceptions**: Renders a formatted error message box (similar to `st.exception`).

**Complete Implementation Example**
This script demonstrates how `st.write` adapts to multiple data types in a single call or across separate lines:
```python
import streamlit as st
import pandas as pd
import numpy as np

# Example 1: Printing basic text, emojis, and inline math markdown
st.write("Hello **World**! 🚀 This is standard text with inline math: $E=mc^2$")

# Example 2: Passing a complex Python object (renders as an interactive JSON tree)
metadata = {"app_version": "2.4.1", "status": "active", "tags": ["prod", "cloud"]}
st.write(metadata)

# Example 3: Passing a Pandas DataFrame (renders as an interactive data table)
df = pd.DataFrame(np.random.randn(3, 3), columns=["A", "B", "C"])
st.write(df)

# Example 4: Passing multiple mixed objects at the exact same time
st.write("Here is a label string:", df, "and here is the app metadata:", metadata)
```

## 4. Markdown `st.markdown()`
The **`st.markdown`** widget displays text formatted with GitHub-flavored Markdown [1, 2]. It is the primary tool for rendering paragraphs, bold/italic text, links, lists, inline code, blockquotes, and custom colored text [1, 2].

**Standard Syntax**
```python
# Highly versatile for rich text formatting like bolding, italics, links, and lists.
st.markdown(body, unsafe_allow_html=False, *, help=None)
```

**Parameter Breakdown**
- **`body`**: The string text to display [1, 2]. Supports Markdown syntax, LaTeX equations, emojis, and inline color tags [1, 2].
- **`unsafe_allow_html`**: A boolean flag (`True` or `False`) [1, 2]. Set to `True` to enable raw HTML rendering (disabled by default for XSS safety) [1, 2].
- **`help`**: An optional string tooltip. Adds a small hoverable question mark icon next to the element [1, 2].

**Complete Implementation Example**
This script demonstrates formatting tricks, bullet points, math equations, and colored blocks:
```python
import streamlit as st

# Example 1: Standard rich text formatting
st.markdown("This is **bold** text, *italics*, and a [hyperlink](https://streamlit.io).")

# Example 2: Lists, blockquotes, and inline code snippets
st.markdown("""
### Task List
*   [x] Clean the raw dataset
*   [ ] Train the ML model

> **Note:** Use `pip install streamlit` to set up your local development environment.
""")

# Example 3: Mathematical LaTeX blocks
st.markdown("The standard normal distribution function is: $$f(x) = \\frac{1}{\\sigma\\sqrt{2\\pi}} e^{-\\frac{1}{2}\\left(\\frac{x-\\mu}{\\sigma}\\right)^2}$$")

# Example 4: Text coloring and hover help tooltips
st.markdown(
    body="System Alert: :red[Critical Error] detected in pipeline. Please check :orange[Logs].",
    help="Click on the logs tab in the sidebar to review the stack trace."
)
```

**Supported Text Formatting Guide**

| Visual Style    | Markdown Syntax Syntax               | Result Sample                     |
| --------------- | ------------------------------------ | --------------------------------- |
| **Headers**     | `# Header 1` up to `###### Header 6` | Scaled typography titles          |
| **Dividers**    | `---` on a blank line                | A clean horizontal separator line |
| **Coloring**    | `:blue[Text]` or `:red[Text]`        | Colored specific words inline     |
| **Inline Math** | `$E=mc^2$`                           | LaTeX formula inline with text    |

## 5. Fixed-Width Text (Monospace) `st.text()`
In Streamlit, `st.text` is used to display fixed-width, preformatted text. It ignores Markdown formatting (such as asterisks) and renders raw strings exactly as they are typed, using a monospaced font.

**Basic Syntax**
```python
st.text(body, *, help=None)
```

Parameter Breakdown
- **`body`** (`str`): The string text you want to render. It displays raw text using a monospaced font and explicitly ignores Markdown.
- **`help`** (`str` or `None`): An optional tooltip string. When provided, a small question mark icon appears next to the text, displaying the tooltip upon hover. Defaults to `None`.

Example
```python
import streamlit as st

# Passing parameters by position and keyword
st.text("This is the body content", help="This is the tooltip text")
```
