# Displaying Data and Visualisations

As a Data Analyst or Business Intelligence professional, your primary goal is to communicate insights clearly. While printing output in a Jupyter Notebook is fine for exploration, Streamlit allows you to present data and visualisations in a polished, interactive web format that stakeholders can actually use.

In this module, we will explore how to render tabular data (Pandas) and charts (Matplotlib, Seaborn, and Plotly) directly into your Streamlit application.

---

## 1. Displaying Tabular Data (Pandas DataFrames)

Streamlit is built to work seamlessly with Pandas. There are three primary ways to display your tabular data, each serving a different business use case.

### A. The Interactive DataFrame: `st.dataframe()`
This is your go-to function for large datasets (like the Olist E-Commerce data). It renders an interactive table where stakeholders can scroll, sort columns, and adjust column widths.

**Core Syntax**
```python
st.dataframe(
	data,
    width=None,
    height=None,
    use_container_width=False,
    hide_index=None,
    column_order=None,
    column_config=None
)
```

**Key Parameters**
* **`data`**: The object to display. It supports various formats including `pandas.DataFrame`, `pandas.Series`, `numpy.ndarray`, `list`, `dict`, and even `polars.DataFrame`.
* **`width & height`**: Specified in pixels. If `None`, Streamlit automatically calculates the size based on the content.
* **`use_container_width`**: If set to `True`, the dataframe expands to fill the entire width of its parent container.
* **`hide_index`**: A boolean to show or hide the index column(s). If `None`, it is determined automatically based on the data.
* **`column_order`**: An optional list or tuple of column names to specify the order in which they appear and which columns are visible.
* **`column_config`**: A dictionary used to customize column titles, visibility, and types (e.g., using st.column_config for sparklines or checkboxes).

**Interactive Selection** (New Feature)
You can now capture user interaction by using the on_select parameter:
* **`on_select`**: Set to `"rerun"` to allow users to select rows or columns. The function will then return a dictionary containing the selection state.
* **`selection_mode`**: Controls what can be selected, such as `"single-row"`, `"multi-row"`, or `"multi-column"`.

**Example**: Custom Styling
You can also pass a pandas Styler object to highlight specific data points.python# Highlighting the maximum value in each column
```python
st.dataframe(df.style.highlight_max(axis=0))
```

**Practical Example**
```python
import streamlit as st
import pandas as pd

st.subheader("Interactive DataFrame")

# Creating dummy business dataframe
df = pd.DataFrame({
    "Region": ["North", "South", "East", "West"],
    "Revenue": [50000, 45000, 60000, 75000],
    "Growth_Rate": [0.05, 0.02, 0.08, 0.12]
})

# Displaying the dataframe dynamically
st.dataframe(df, use_container_width=True)
```

### B. The Editable DataFrame: `st.data_editor()`
If you want to allow users to tweak assumptions (e.g., for a financial forecasting model), use `st.data_editor()`. It allows users to edit the data directly on the web page, and it returns the updated dataframe back to your Python script!

**Standard Syntax**
```python
edited_df = st.data_editor(
    data, 
    *, 
    width=None, 
    height=None, 
    use_container_width=False, 
    hide_index=None, 
    column_order=None, 
    column_config=None, 
    num_rows="fixed", 
    disabled=False, 
    key=None, 
    on_change=None, 
    args=None, 
    kwargs=None
)
```

**Parameter Breakdown**
- **`data`**: The input data structure to edit (e.g., Pandas DataFrame, NumPy array, list, dict).
- **`use_container_width`**: Set to `True` to stretch the editor to fill its parent layout container.
- **`hide_index`**: Set to `True` to conceal the dataframe index/row numbers.
- **`column_order`**: A list/tuple of strings specifying which columns to display and in what exact order (e.g., `["col2", "col1"]`).
- **`column_config`**: A dictionary map to configure interactive column UI behaviors using `st.column_config` API objects.
- **`num_rows`**: Choose `"fixed"` (default) to only allow editing cell values, or `"dynamic"` to allow users to add and delete rows.
- **`disabled`**: Controls edit permissions. Set to `True` to lock the whole table, or pass a list of column names (e.g., `["id", "date"]`) to make specific columns read-only.
- **`key`**: An optional string identifier used to save state and extract granular change records via `st.session_state`. 

**Example**
```python
# Editable Data Input
edited_df = st.data_editor(df)

# You can now use edited_df in subsequent calculations
st.write(f"Adjusted West Revenue: {edited_df.iloc[3]['Revenue']}")
```

**Complete Implementation Example**
This script highlights how to pass configuration options, apply targeted input rules, toggle row alterations, and handle the output data:
```python
import streamlit as st
import pandas as pd

# 1. Sample data setup
initial_data = pd.DataFrame([
    {"item": "Laptop", "quantity": 5, "available": True},
    {"item": "Monitor", "quantity": 12, "available": True},
    {"item": "Mouse", "quantity": 0, "available": False},
])

# 2. Render and configure the interactive data editor
edited_df = st.data_editor(
    initial_data,
    use_container_width=True,
    hide_index=True,
    num_rows="dynamic",                 # Allows adding/deleting rows
    disabled=["item"],                  # Prevent editing the item names
    column_config={
        "quantity": st.column_config.NumberColumn(
            "Stock Level",
            help="Current warehouse inventory count",
            min_value=0,
            max_value=100,
            step=1,
            format="%d units"
        ),
        "available": st.column_config.CheckboxColumn(
            "In Stock?"
        )
    }
)

# 3. Use the updated dataframe downstream
st.subheader("Live Output Data")
st.write(edited_df)
```

**Accessing Granular Edits (Session State)**
Instead of processing the entire returned dataframe, you can inspect the specific changes via `st.session_state` by pairing a `key` parameter with the widget: 
```python
import streamlit as st
import pandas as pd

df = pd.DataFrame([{"name": "Alice", "role": "Admin"}, {"name": "Bob", "role": "User"}])

# Providing a unique key exposes delta changes to st.session_state
st.data_editor(df, key="user_table")

if "user_table" in st.session_state:
    changes = st.session_state["user_table"]
    # Contains 3 distinct dictionaries: 'edited_rows', 'added_rows', and 'deleted_rows'
    st.json(changes) 
```

### C. The Static Table: `st.table()`
Best used for small summary tables or highly formatted pivot tables where you do not want the user to scroll or sort. It draws a clean, static HTML table.

**Standard Syntax**
```python
st.table(data=None)
```

**Parameter Breakdown**
- **`data`**: The input data structure to display. It accepts Pandas DataFrames, NumPy arrays, lists, tuples, dictionaries, or PyArrow tables.

**Examples**
```python
st.table(df)

st.table(df.describe())
```

### D. Business KPIs: `st.metric()`
For BI dashboards, you often need to show top-level KPIs (Key Performance Indicators) before diving into the granular data. (Covered deeply in [08.02.04](08.02.06-UI_Layouts_and_Page_Design.md))

```python
st.subheader("Dashboard KPIs")
col1, col2, col3 = st.columns(3) # Creating a 3-column layout

col1.metric(label="Total Revenue", value="$230,000", delta="$15,000")
col2.metric(label="Top Region", value="West", delta="12% Growth")
col3.metric(label="Active Users", value="1,432", delta="-42", delta_color="inverse")
```

## 2. Displaying JSON Data: `st.json()`
The **`st.json`** widget in Streamlit displays a pretty-printed, interactive string or object in JSON format with collapsible nodes.

**Standard Syntax**
```python
st.json(body, *, expanded=True)
```

**Parameter Breakdown**
- **`body`**: The object or string to be displayed. It accepts Python dictionaries, lists, strings, integers, floats, booleans, or valid raw JSON strings.
- **`expanded`**: A boolean flag (`True` or `False`) that controls whether the JSON tree structure is expanded or collapsed by default when the page loads.

**Complete Implementation Example**
This script demonstrates how to display both a native Python dictionary and a raw JSON string using the expanding controls:
```python
import streamlit as st

# Example 1: Passing a native Python dictionary (Expanded by default)
user_profile = {
    "user_id": 10293,
    "active": True,
    "info": {
        "name": "Jane Doe",
        "email": "jane.doe@example.com"
    },
    "roles": ["Admin", "Developer"]
}

st.subheader("User Profile Metadata")
st.json(user_profile)

# Example 2: Passing a raw JSON string (Collapsed by default)
raw_json_string = '{"status": "success", "data": {"items_processed": 42}}'

st.subheader("Collapsed API Response")
st.json(raw_json_string, expanded=False)
```

**Key Behaviors to Note**
- **Syntax Highlighting**: Elements like keys, strings, booleans, and numbers are color-coded automatically.
- **Interactivity**: Users can click the arrow icons in the UI to collapse or expand individual nested objects or lists.
- **String Parsing**: If you pass a valid raw JSON string, Streamlit automatically parses and converts it into a clean tree structure. Invalid JSON strings will be rendered as plain text.

## 3. Integrating Static Visualisations (Matplotlib & Seaborn)

You already know how to build rigorous statistical plots using Matplotlib and Seaborn. Streamlit can easily render these using `st.pyplot()`.

**Important Best Practice:** In Jupyter, you might just type `plt.show()`. In Streamlit, you must explicitly create figure and axes objects (`fig, ax = plt.subplots()`) and pass the `fig` to Streamlit. This prevents memory leaks and overlapping charts when multiple users access your app.

```python
import matplotlib.pyplot as plt
import seaborn as sns

st.subheader("Seaborn Statistical Visualisation")

# 1. Create the Figure and Axes objects
fig, ax = plt.subplots(figsize=(8, 4))

# 2. Build the plot, passing the 'ax' object
sns.barplot(data=df, x="Region", y="Revenue", palette="Blues_d", ax=ax)
ax.set_title("Revenue by Region (FY25)")
ax.set_ylabel("Revenue ($)")

# 3. Pass the explicit figure object to Streamlit
st.pyplot(fig)
```

## 4. Adding Interactive Charts (Plotly)

While Seaborn is excellent for static reports, web dashboards thrive on interactivity. Plotly Express is the industry standard for interactive web plotting. Users can hover over data points to see exact values, zoom in on clusters, and pan across time series.

Streamlit supports Plotly natively via `st.plotly_chart()`.

```python
import plotly.express as px

st.subheader("Interactive Plotly Visualisation")

# Create an interactive scatter plot
fig_plotly = px.scatter(
    df, 
    x="Revenue", 
    y="Growth_Rate", 
    color="Region",
    size="Revenue",
    hover_name="Region",
    title="Revenue vs. Growth Rate Analysis",
    template="plotly_white"
)

# Render in Streamlit
st.plotly_chart(fig_plotly, use_container_width=True)
```

## 5. Native Streamlit Charts (Quick Prototyping)

If you are in a rush and do not want to configure Matplotlib or Plotly, Streamlit has basic built-in charting functions that work directly on Pandas DataFrames. These are great for quick prototyping but lack the deep customisation of Plotly.

```python
st.subheader("Native Streamlit Line Chart")
# Streamlit charts automatically use the DataFrame index for the X-axis
df_indexed = df.set_index("Region")
st.line_chart(df_indexed["Revenue"])
```

---

## Summary of the Visualisation Stack
1. **Pandas natively:** Use `st.dataframe()` for exploration and `st.metric()` for BI KPIs.
2. **Matplotlib/Seaborn:** Best for complex statistical plotting. Always use `fig, ax = plt.subplots()` and `st.pyplot(fig)`.
3. **Plotly:** The best choice for interactive web dashboards. Use `st.plotly_chart(fig)`.
