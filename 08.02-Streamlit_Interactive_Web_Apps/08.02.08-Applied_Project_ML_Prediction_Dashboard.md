# Best Practice: Applied Projects & ML Prediction Dashboards

## Introduction
Building a predictive model in a Jupyter Notebook is a great technical achievement, but raw code is rarely useful to business stakeholders. As a Data Analyst or Business Intelligence professional, your goal is to make data actionable. This module covers how to wrap a pre-trained Scikit-Learn model into an interactive Streamlit web app, allowing end-users to adjust parameters and generate live predictions without seeing a single line of code.

## The Deployment Workflow
Deploying a Machine Learning model in Streamlit involves three distinct phases:
1. **Serialization:** Saving your trained model (and any data scalers/encoders) using `joblib` or `pickle`.
2. **User Interface (UI) Construction:** Creating input widgets (sliders, dropdowns) for the user to define the feature set.
3. **Inference & Execution:** Loading the model, passing the user inputs as a structured DataFrame, and displaying the prediction results beautifully.

## Step 2: Setting up the Streamlit App (`app.py`)
Create a new Python file named `app.py`. This single script will act as your frontend UI and your backend inference engine.

### 2.1 Importing Libraries and Loading the Model
We must use Streamlit's caching mechanism. If we don't, Streamlit will reload the heavy model file every single time the user clicks a button or moves a slider, causing severe lag.

``` python
import streamlit as st
import pandas as pd
import joblib

# Page Configuration
st.set_page_config(page_title="Customer Spend Predictor", layout="centered")

# Load the model with caching to improve performance
@st.cache_resource
def load_model():
    return joblib.load('customer_spend_model.joblib')

model = load_model()
```

### 2.2 Designing the User Input Architecture
Use Streamlit's sidebar or columns to gather inputs. It is crucial that the names, data types, and order of these inputs perfectly match the features your model was trained on.

``` python
st.title("📊 Customer Spend Prediction App")
st.markdown("Adjust the customer parameters below to predict their annual spend.")

st.sidebar.header("Customer Profiles")

def user_input_features():
    # Define interactive widgets for user input
    age = st.sidebar.slider("Age", 18, 80, 35)
    income = st.sidebar.number_input("Annual Income ($)", min_value=15000, max_value=200000, value=60000)
    visits = st.sidebar.slider("Website Visits (per month)", 0, 50, 10)
    
    # Store inputs in a dictionary
    data = {
        'age': age,
        'annual_income': income,
        'website_visits': visits
    }
    
    # Convert to a Pandas DataFrame (Scikit-Learn expects a 2D array/DataFrame)
    features = pd.DataFrame(data, index=[0])
    return features

# Capture the user inputs into a DataFrame
input_df = user_input_features()
```

### 2.3 Displaying Inputs and Making Live Predictions
Finally, display the selected parameters for transparency, and use a button to trigger the prediction. We use `st.metric` for a clean, professional KPI display.

``` python
st.subheader("Selected Customer Parameters")
st.write(input_df) # Displays the dataframe to the user

# Add a predict button to trigger inference
if st.button("Predict Spend"):
    # Run inference using the loaded model
    prediction = model.predict(input_df)
    
    # Format the output
    predicted_value = round(prediction[0], 2)
    
    st.subheader("Prediction Result")
    st.metric(label="Estimated Annual Spend", value=f"${predicted_value:,.2f}")
    
    # Add business logic based on the prediction
    if predicted_value > 1000:
        st.success("High-Value Customer Identified! Initiate VIP marketing protocol.")
    else:
        st.info("Standard Customer. Continue regular engagement.")
```

## Key Best Practices for ML Dashboards

1. **Feature Alignment (The #1 Error):** The most common error when deploying Scikit-Learn models is a mismatch between the columns in `input_df` and the columns the model was trained on. Ensure exact spelling and order.
2. **Handling Categorical Variables:** If your model uses encoded categorical variables (e.g., One-Hot Encoding), your Streamlit app must capture the category via `st.selectbox` and apply the *exact same* encoding logic or pipeline before calling `.predict()`.
3. **Applying Scalers:** If you used `StandardScaler` or `MinMaxScaler` during training, you must save the scaler object using `joblib`, load it into Streamlit, and apply `scaler.transform(input_df)` before making the prediction.
4. **Visualisation Context:** Don't just show a single number. Use `matplotlib`, `seaborn`, or `plotly` alongside the prediction to show how this customer's predicted behaviour compares to historical averages in your dataset.
