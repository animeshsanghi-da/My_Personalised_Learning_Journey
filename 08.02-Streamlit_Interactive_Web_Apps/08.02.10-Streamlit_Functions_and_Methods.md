# Streamlit for Data Science: Comprehensive Functions & Methods

## Overview
Streamlit is a powerful, open-source Python framework that allows Data Analysts and Scientists to transform complex data scripts into interactive, shareable web applications in minutes. This comprehensive reference guide covers every essential function and method utilized in Streamlit. Understanding these tools ensures that no aspect of dashboard development—from UI layout to performance caching—is left behind.

*This is a comprehensive revision of all functions and methods that are used in streamlit.*

---

## 1. Displaying Text
Text functions are used to structure your web app, providing titles, narrative insights, and markdown explanations for your stakeholders.

``` python
import streamlit as st

st.title("Data Analytics Dashboard")       # Main title of the app
st.header("1. Sales Overview")             # Large section header
st.subheader("Q3 Performance")             # Smaller sub-section header
st.markdown("**Bold Text** and *Italics*") # Renders markdown formatted text
st.text("Raw text goes here.")             # Displays fixed-width, unformatted text
st.caption("Footnotes or small text.")     # Small text for captions or source citations
st.write("Displays almost anything!")      # The "Swiss Army Knife", formats dynamically
st.latex(r"y = mx + c")                    # Renders mathematical equations using LaTeX
```

## 2. Displaying Data
As a Data Analyst, tabular data forms the core of your application. Streamlit provides several robust methods to display DataFrames securely and interactively.

``` python
import pandas as pd

# Simulating data ingestion
df = pd.DataFrame({
    'Name': ['Animesh', 'Rohan'], 
    'Role': ['Data Analyst', 'Data Scientist']
})

st.dataframe(df)                  # Displays an interactive table (sortable, scrollable)
st.data_editor(df)                # Displays an editable dataframe where users can alter values
st.table(df)                      # Displays a static, non-interactive table
```

```python
st.json({"status": "success", "rows": 500}) # Renders JSON payloads beautifully
```

### st.metric:
Displays a key performance indicator (KPI)
**Basic Syntax & Parameters**
```python
st.metric(label, value, delta=None, delta_color="normal", help=None)
```
- **`label`:** A string header/title for the metric.
- **`value`**: The main data being tracked (number or string).
- **`delta`**: The difference from a previous value (e.g., previous month or year).
- **`delta_color`**: Controls the color of the delta. `"normal"` makes positive values green and negative values red. `"inverse"` makes positive values red and negative ones green. `"off"` removes the color entirely.
- **`help`**: Displays an optional tooltip question mark next to the label.
**Usage Example**
```python
st.metric("Total Revenue", "$50K", "12%", "inverse")
```
**Best Practices**
Use `st.metric()` alongside `st.columns()` to place multiple metric cards side-by-side.
```python
col1, col2, col3 = st.columns(3)
col1.metric("Revenue", "$5M", "+10%")
col2.metric("Profit", "$1.2M", "+5%")
col3.metric("Churn", "2.1%", "-0.2%")
```

## 3. Data Visualisation & Charts
Visualisations breathe life into data. Streamlit supports native charts as well as seamless integrations with your favorite libraries like Matplotlib, Seaborn, and Plotly.

``` python
import numpy as np

chart_data = pd.DataFrame(np.random.randn(20, 3), columns=['A', 'B', 'C'])

# Native Streamlit Charts
st.line_chart(chart_data)         # Renders an interactive line chart
st.bar_chart(chart_data)          # Renders an interactive bar chart
st.area_chart(chart_data)         # Renders an interactive area chart
st.map(pd.DataFrame({'lat': [28.6139], 'lon': [77.2090]})) # Renders data points on a map
```

## 4. Input Widgets (User Interaction)
Widgets are the engine of interactivity, allowing users to filter data and tweak model parameters dynamically.

``` python
# Buttons and Actions
if st.button("Run ML Pipeline"):
    st.write("Execution complete!")
st.download_button("Download Data", data="csv_data", file_name="cleaned_data.csv") 

# Selection Widgets
is_active = st.checkbox("Show Active Users Only")              # Boolean checkbox
gender = st.radio("Select Gender", ["Male", "Female"])         # Single-choice radio buttons
department = st.selectbox("Department", ["HR", "IT", "Data"])  # Dropdown menu
skills = st.multiselect("Skills", ["Python", "SQL", "Tableau"])# Multiple selection dropdown
age = st.slider("Select Age", min_value=18, max_value=65)      # Numeric slider
level = st.select_slider("Experience", options=["Junior", "Mid", "Senior"]) # Categorical slider

# Text and Number Inputs
name = st.text_input("Enter Analyst Name", "Animesh")          # Single-line text input
bio = st.text_area("Write Analysis Notes")                     # Multi-line text input
salary = st.number_input("Expected Salary", min_value=0)       # Numeric input field
date = st.date_input("Start Date")                             # Calendar date picker
time = st.time_input("Meeting Time")                           # Time picker

# Advanced Inputs
uploaded_file = st.file_uploader("Upload CSV", type="csv")     # Drag-and-drop file uploader
picture = st.camera_input("Take a picture")                    # Captures image from webcam
color = st.color_picker("Pick a theme color", "#00f900")       # Hex color picker
```

## 5. Layout and Containers
A professional dashboard must be well-structured. These functions organize your widgets and visuals logically across the screen.

``` python
# Sidebar
st.sidebar.header("Global Filters")
user_filter = st.sidebar.slider("Threshold")   # Places a slider in the collapsible left sidebar

# Columns
col1, col2, col3 = st.columns(3)               # Divides the page into 3 vertical columns
col1.metric("Revenue", "$10K")
col2.metric("Expenses", "$4K")
col3.metric("Profit", "$6K")

# Tabs
tab1, tab2 = st.tabs(["Data View", "Chart View"])
tab1.dataframe(df)
tab2.line_chart(chart_data)

# Expanders and Containers
with st.expander("See Methodology Details"):   # Collapsible panel for extra information
    st.write("We used K-Means clustering algorithm...")

with st.container():                           # Groups multiple elements together logically
    st.write("Grouped Element 1")
    st.write("Grouped Element 2")

placeholder = st.empty()                       # Creates an empty block to be filled/overwritten later
placeholder.text("Loading initial dataset...")
```

## 6. Status Elements & Control Flow
Inform users about the state of their requests, especially when dealing with heavy machine learning computations or large SQL queries.

``` python
# Progress and Loading
import time
with st.spinner("Training Predictive Model... Please wait."):
    time.sleep(2)  # Simulating a heavy ML process

progress_bar = st.progress(0)
for i in range(100):
    progress_bar.progress(i + 1)

# Status Messages
st.success("Data imported successfully!")         # Green success banner
st.error("Failed to connect to MySQL database.")  # Red error banner
st.warning("Outliers detected in the dataset.")   # Yellow warning banner
st.info("Remember to clear cache before re-running.") # Blue informational banner
st.exception(RuntimeError("Pipeline crashed!"))   # Formats and displays an exception traceback

# Control Flow
st.stop()                                         # Halts execution immediately (useful for validation fails)
# st.rerun()                                      # Forces the script to rerun from top to bottom
```

## 7. Caching & Performance Optimization
Data Science applications often process millions of rows or load massive predictive models. Caching prevents Streamlit from rerunning heavy functions every time the user interacts with a widget.

``` python
# 1. Cache Data: Used for functions that return data (DataFrames, CSVs, API responses)
@st.cache_data
def load_data():
    return pd.read_csv("massive_dataset.csv")

df = load_data() # Will only read from disk once until parameters change

# 2. Cache Resource: Used for global resources like ML Models or Database Connections
@st.cache_resource
def load_ml_model():
    import joblib
    return joblib.load("random_forest_model.joblib")

model = load_ml_model() # Loads the model into memory once across all reruns
```

## 8. Session State Management
Because Streamlit runs the script from top-to-bottom on every click, it naturally forgets variable states. `st.session_state` allows you to remember data across reruns.

``` python
# Initialize a session state variable
if 'click_count' not in st.session_state:
    st.session_state['click_count'] = 0

# Create a button that updates the state
if st.button("Trigger Workflow"):
    st.session_state['click_count'] += 1

st.write(f"Workflow triggered {st.session_state['click_count']} times.")

# Forms: Batching inputs together so they don't trigger reruns until submitted
with st.form("my_form"):
    st.write("Filter Dataset")
    slider_val = st.slider("Select Confidence Threshold")
    checkbox_val = st.checkbox("Remove Nulls")
    
    # Every form must have a submit button
    submitted = st.form_submit_button("Apply Filters")
    if submitted:
        st.write("Filters applied securely! Processing data...")
```
