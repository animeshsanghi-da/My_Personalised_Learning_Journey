# Time Series Decomposition: Uncovering the Anatomy of Sales Cycles

## Introduction
When looking at a raw line chart of daily orders, it can be difficult to tell the true story. If sales dropped this week, is the business failing, or is it just the normal post-holiday slump? 

In Data Analytics, **Time Series Decomposition** is the process of breaking down a time-based dataset into its core underlying components. By isolating these components, you can separate the true long-term direction of the business from regular, repeating cycles and random anomalies. This is a critical skill for communicating accurate performance metrics to stakeholders.

---

## The Three Core Components

Every time series can be broken down into three distinct elements:

1. **Trend ($T_t$):** The overall, long-term direction of the data. Is the business generally growing or shrinking over months or years, ignoring the day-to-day bumps?
2. **Seasonality ($S_t$):** Short-term, repeating cycles. In e-commerce, this might be a weekly cycle (higher sales on weekends) or a yearly cycle (spikes in November/December).
3. **Residual / Noise ($R_t$):** The random, unpredictable variations left over after the trend and seasonality have been removed. Large residuals often indicate external anomalies (like a sudden marketing campaign going viral or a website outage).

### Additive vs. Multiplicative Models
Before running the code, you must decide how these components interact:
* **Additive Model:** $Y_t = T_t + S_t + R_t$
  * Use this when the seasonal variation remains relatively constant over time. (e.g., Sales always increase by about 500 units in December).
* **Multiplicative Model:** $Y_t = T_t \times S_t \times R_t$
  * Use this when the seasonal variation increases or decreases with the trend. (e.g., Sales always increase by 20% in December. As the business grows, that 20% spike becomes much larger in absolute volume).

## Applied Decomposition in Python

For this walkthrough, we will use the `statsmodels` library, which is the industry standard for statistical testing and time series analysis in Python. We will apply this to a structure similar to the Olist e-commerce dataset—analysing daily order volumes.

### 1. Preparing the Environment and Data
First, ensure your data is properly indexed with a `DatetimeIndex` and has a set frequency.

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from statsmodels.tsa.seasonal import seasonal_decompose

# Set visualisation style
sns.set_theme(style="darkgrid")

# Load data (assuming a prepared dataset like the Olist orders table)
df = pd.read_csv('daily_orders.csv', parse_dates=['order_purchase_date'])

# Set the datetime column as the index
df.set_index('order_purchase_date', inplace=True)

# Resample to ensure a strict daily frequency (fills missing days with 0)
daily_orders = df['order_count'].resample('D').sum()
```

### 2. Performing the Decomposition
We will use the `seasonal_decompose` function from `statsmodels`.

```python
# Perform the decomposition
# We use an additive model assuming the seasonal fluctuations are relatively stable
decomposition = seasonal_decompose(daily_orders, model='additive', period=7) 
# Note: period=7 is used to check for weekly seasonality in daily data. 
# Use period=365 for annual seasonality in daily data, or 12 for monthly data.

# Extract the individual components
trend = decomposition.trend
seasonal = decomposition.seasonal
residual = decomposition.resid
```

### 3. Visualising the Components
While `decomposition.plot()` exists, it creates very compressed, unappealing charts. As a Data Analyst, it is better to build a custom, professional layout using Matplotlib subplots to share with business leaders.

```python
fig, axes = plt.subplots(4, 1, figsize=(14, 10), sharex=True)

# 1. Plot Original Data
axes[0].plot(daily_orders, label='Original Data', color='blue')
axes[0].legend(loc='upper left')
axes[0].set_title('Time Series Decomposition of Daily Orders')
axes[0].set_ylabel('Orders')

# 2. Plot Trend
axes[1].plot(trend, label='Trend', color='orange')
axes[1].legend(loc='upper left')
axes[1].set_ylabel('Trend')

# 3. Plot Seasonality
axes[2].plot(seasonal, label='Seasonality', color='green')
axes[2].legend(loc='upper left')
axes[2].set_ylabel('Seasonality')

# 4. Plot Residuals (Noise)
axes[3].scatter(residual.index, residual, label='Residuals (Noise)', color='red', s=10)
axes[3].axhline(0, color='black', linestyle='--', alpha=0.5)
axes[3].legend(loc='upper left')
axes[3].set_ylabel('Residuals')

plt.tight_layout()
plt.show()
```

## Business Application: How to Interpret the Visualisation

When you present these findings in a business intelligence context, you translate the mathematical components into actionable insights:

1. **The Trend Line:** "Despite the volatile daily fluctuations in our e-commerce platform, the underlying trend shows a steady 15% growth trajectory over the last two quarters."
2. **The Seasonality:** "By isolating the seasonality, we can confirm a distinct weekly pattern: order volume consistently peaks on Tuesdays and hits a low on Saturdays. We should optimise our targeted marketing and server capacity for early-week traffic."
3. **The Residuals:** "Looking at the noise, we see a massive, unexplained spike on November 24th that deviates from both our trend and expected seasonality. This directly correlates with our Black Friday flash sale, proving the campaign's isolated impact."
