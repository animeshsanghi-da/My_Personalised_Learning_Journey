# Applied Time Series: Resampling, Rolling Metrics, and Shifts

## Introduction
When working with raw business data—whether it is daily e-commerce transactions from a dataset like Olist or timestamped healthcare ETL logs—the data is rarely at the exact frequency you need for executive reporting. Daily data is often too noisy, full of day-to-day variance that obscures the larger trend. 

In this module, we will explore three essential Pandas techniques to manipulate time series data:
1. **Resampling:** Changing the frequency of your data (e.g., Daily to Monthly).
2. **Rolling Metrics:** Smoothing out volatility to uncover true trends (e.g., 7-day moving averages).
3. **Shifts:** Calculating period-over-period growth (e.g., Month-over-Month revenue changes).

---

## 1. Resampling: Time-Based Aggregation

Think of resampling as a SQL `GROUP BY` statement, but explicitly designed for time and dates. If you have a DataFrame indexed by `datetime`, you can aggregate the data into new time buckets.

### The Business Case
Your ETL script dumps daily sales data, but the business intelligence dashboard requires a monthly revenue summary.

### Implementation
``` python
import pandas as pd
import numpy as np

# Simulating 90 days of daily transaction data
dates = pd.date_range(start="2025-01-01", periods=90, freq="D")
sales = np.random.randint(100, 500, size=(90))
df = pd.DataFrame({'Sales': sales}, index=dates)

# Resampling from Daily ('D') to Weekly ('W') and summing the sales
weekly_sales = df.resample('W').sum()

# Resampling to Monthly ('M') and finding the average daily sale per month
monthly_avg = df.resample('M').mean()

print(monthly_avg)
```

*Note: Common offset aliases include 'D' (Calendar Day), 'W' (Weekly), 'M' (Month End), and 'Q' (Quarter End).*

## 2. Rolling Metrics (Moving Averages)

Raw daily data is spiky. A weekend might always have lower sales, making a standard line chart look jagged and confusing. Rolling metrics (or moving averages) smooth out these short-term fluctuations to highlight longer-term trends.

### The Business Case
You need to analyse the true trajectory of user sign-ups or patient intakes without getting distracted by the weekend drops.

### Implementation
Using the `.rolling()` method in Pandas, you specify a "window" of time to perform an operation on.

``` python
# Calculate a 7-day moving average (rolling mean)
df['7_Day_MA'] = df['Sales'].rolling(window=7).mean()

# Calculate a 30-day rolling sum (total sales over the trailing 30 days)
df['30_Day_Trailing_Total'] = df['Sales'].rolling(window=30).sum()

# Notice that the first 6 rows for '7_Day_MA' will be NaN because 
# Pandas needs 7 days of historical data to calculate the first average.
print(df.head(10))
```

## 3. Shifts: Calculating Period-over-Period Growth

To measure business performance, you rarely look at an absolute number in isolation. You compare it to the past. Calculating Month-over-Month (MoM) or Year-over-Year (YoY) growth is a fundamental requirement for any Data Analyst.

### The Business Case
You need to calculate the percentage change in revenue from the previous month to include in a stakeholder presentation.

### Implementation
The `.shift()` function moves the data index up or down by a specified number of periods.

``` python
# Let's use our monthly aggregated data from earlier
monthly_revenue = df.resample('M').sum()

# Shift the data down by 1 period (so February's row now contains January's data)
monthly_revenue['Previous_Month_Sales'] = monthly_revenue['Sales'].shift(1)

# Calculate the absolute difference
monthly_revenue['MoM_Difference'] = monthly_revenue['Sales'] - monthly_revenue['Previous_Month_Sales']

# Calculate the Month-over-Month percentage growth
monthly_revenue['MoM_Growth_%'] = (monthly_revenue['MoM_Difference'] / monthly_revenue['Previous_Month_Sales']) * 100

print(monthly_revenue)
```

**Pro-Tip:** Pandas actually has a built-in method for percentage change that does this math for you in one step!
``` python
# The faster, cleaner way to calculate MoM growth:
monthly_revenue['Quick_MoM_%'] = monthly_revenue['Sales'].pct_change() * 100
```
