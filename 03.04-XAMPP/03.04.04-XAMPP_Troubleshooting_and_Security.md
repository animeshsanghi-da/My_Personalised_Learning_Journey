# XAMPP: Troubleshooting & Security for Data Pipelines

## Introduction
A robust local server environment is crucial when building and testing complex data workflows. When developing and testing scripts—such as a healthcare ETL and redistribution algorithm—environment instability or database connection failures can bring your progress to a halt. This module covers how to resolve common XAMPP roadblocks, secure your local database, and maintain a stable environment for your Python and SQL operations.

## 1. Resolving Port Conflicts
The most common issue when starting XAMPP is a port conflict. Services like Apache and MySQL require specific network ports to communicate.

### Apache (Port 80 and 443)
If Apache fails to start, another application (like Skype, VMWare, or Windows IIS) is likely using Port 80.
* **The Fix:** 1. Open the XAMPP Control Panel.
  2. Click **Config** next to Apache and select `httpd.conf`.
  3. Find the line `Listen 80` and change it to `Listen 8080`.
  4. Find `ServerName localhost:80` and change it to `ServerName localhost:8080`.
  5. Restart Apache. You will now access your local server via `http://localhost:8080`.

### MySQL (Port 3306)
If MySQL fails to start, you likely have a standalone version of MySQL already running on your machine, occupying the default port.
* **The Fix:**
  1. Click **Config** next to MySQL and select `my.ini`.
  2. Find all instances of `port=3306` and change them to `port=3307` (or another unused port).
  3. Restart MySQL.
  *Note: When you connect via Python, you must specify the new port in your connection string.*

```python
import mysql.connector

# Updating the connection script for a custom port
conn = mysql.connector.connect(
    host="localhost",
    user="root",
    password="", 
    database="healthcare_db",
    port=3307 # Specify the new port here
)
```

## 2. Securing the Default `root` User
By default, XAMPP installs MariaDB/MySQL with the username `root` and **no password**. While this is convenient for quick testing, it is a bad practice for data security.

### How to Set a Root Password:
1. Open XAMPP Control Panel and start Apache and MySQL.
2. Click **Admin** next to MySQL to open phpMyAdmin.
3. Go to the **User accounts** tab.
4. Locate the `root` user for `localhost` and click **Edit privileges**.
5. Click **Change password**, enter a secure password, and click **Go**.

### Updating Configuration:
Once the password is changed, phpMyAdmin might lose access.
1. Navigate to your XAMPP installation folder (e.g., `C:\xampp\phpMyAdmin`).
2. Open `config.inc.php` in VS Code or your preferred text editor.
3. Find the line: `$cfg['Servers'][$i]['password'] = '';`
4. Update it with your new password: `$cfg['Servers'][$i]['password'] = 'your_new_password';`
5. Ensure your Python ETL scripts are also updated to reflect this new password.

## 3. Maintaining Environment Stability

### Proper Shutdown Procedures
Never close the XAMPP Control Panel or shut down your computer without first stopping the Apache and MySQL services. Abrupt shutdowns can corrupt your database tables, leading to errors when you try to analyse your data the next day. Always click the **Stop** buttons in the Control Panel before exiting.

### Increasing File Upload Limits
When working with large datasets, you might need to import heavy CSV or SQL files directly into phpMyAdmin. By default, XAMPP limits uploads to 2MB.
1. Click **Config** next to Apache and open `php.ini`.
2. Search for `upload_max_filesize` and change it to `upload_max_filesize = 128M`.
3. Search for `post_max_size` and change it to `post_max_size = 128M`.
4. Restart Apache to apply the changes.

### IDE Integration
To streamline your workflow, you can manage your XAMPP MySQL database directly from VS Code.
1. Install an extension like **MySQL** or **Database Client** in VS Code.
2. Add a new connection using:
   * **Host:** localhost
   * **User:** root
   * **Password:** (The password you set in Section 2)
   * **Port:** 3306 (or your updated port)
   
This allows you to write Python scripts, run SQL queries, and manage your database all within a single environment.
