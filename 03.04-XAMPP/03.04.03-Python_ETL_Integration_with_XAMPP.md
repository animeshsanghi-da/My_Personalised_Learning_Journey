# Python ETL Integration with Local XAMPP MySQL

## Introduction
Building scalable data pipelines requires a robust connection between your analytical environment (Python) and your database. When developing and testing phase-based ETL (Extract, Transform, Load) algorithms—such as healthcare data redistribution scripts—a local XAMPP MySQL server provides a safe, high-speed sandbox before pushing to production.

This module covers the two primary methods for connecting Python to a local XAMPP database: 
1. **`mysql-connector-python`**: Best for raw SQL execution and database administration.
2. **`SQLAlchemy`**: The industry standard for Data Analysts and Scientists, seamlessly integrating with `pandas` for bulk data manipulation.

---

## 1. Environment Setup

Before writing the pipeline, ensure your local environment is ready. Whether you are scripting in VS Code or running interactive cells in Jupyter Lab via Anaconda, you will need the correct libraries.

Open your terminal or Anaconda Prompt and install the required packages:

``` bash
pip install mysql-connector-python sqlalchemy pandas pymysql
```

*Note: `pymysql` acts as the dialect driver that allows SQLAlchemy to communicate with MySQL.*

## 2. Method 1: Using `mysql-connector-python` (The Native Approach)

This approach is excellent for the "Extract" and "Load" phases when you need to execute specific Data Definition Language (DDL) or Data Manipulation Language (DML) queries, such as creating tables or triggering stored procedures.

### Example: Establishing a Connection and Creating a Database

``` python
import mysql.connector
from mysql.connector import Error

def create_server_connection(host_name, user_name, user_password):
    connection = None
    try:
        connection = mysql.connector.connect(
            host=host_name,
            user=user_name,
            passwd=user_password
        )
        print("MySQL Database connection successful")
    except Error as err:
        print(f"Error: '{err}'")
    return connection

# XAMPP default credentials: user is 'root', password is '' (blank)
connection = create_server_connection("localhost", "root", "")

# Creating a fresh database for our ETL pipeline
cursor = connection.cursor()
cursor.execute("CREATE DATABASE IF NOT EXISTS healthcare_etl_db;")
print("Database verified/created.")

# Always close the connection when done
if connection.is_connected():
    cursor.close()
    connection.close()
    print("MySQL connection is closed")
```

## 3. Method 2: Using SQLAlchemy & Pandas (The Data Science Approach)

For complex data manipulation—like cleaning missing values with NumPy and Pandas, or redistributing algorithm outputs—`SQLAlchemy` is the superior choice. It allows you to push entire DataFrames directly into your XAMPP MySQL database in a single line of code.

### Example: The ETL Pipeline

``` python
import pandas as pd
from sqlalchemy import create_engine
import numpy as np

# ---------------------------------------------------------
# PHASE 1: EXTRACT (Simulated)
# ---------------------------------------------------------
# Simulating a dataset extraction (e.g., from a CSV or API)
data = {
    'patient_id': [101, 102, 103, 104],
    'department': ['Cardiology', 'Neurology', 'Orthopedics', 'Cardiology'],
    'readmission_risk_score': [0.85, 0.42, np.nan, 0.91]
}
df = pd.DataFrame(data)

# ---------------------------------------------------------
# PHASE 2: TRANSFORM
# ---------------------------------------------------------
# Handling missing values and applying business logic
df['readmission_risk_score'] = df['readmission_risk_score'].fillna(df['readmission_risk_score'].mean())
df['high_risk_flag'] = np.where(df['readmission_risk_score'] > 0.80, True, False)

# ---------------------------------------------------------
# PHASE 3: LOAD (To XAMPP MySQL)
# ---------------------------------------------------------
# SQLAlchemy Connection String Format: dialect+driver://username:password@host:port/database
# XAMPP defaults to port 3306. 
engine = create_engine('mysql+pymysql://root:@localhost:3306/healthcare_etl_db')

try:
    # Push the DataFrame to SQL. 
    # if_exists='replace' drops the table before inserting new values. Use 'append' to add to existing data.
    df.to_sql(name='patient_risk_analysis', con=engine, if_exists='replace', index=False)
    print("Data successfully loaded into XAMPP MySQL database.")
except Exception as e:
    print(f"An error occurred during the Load phase: {e}")
```

## 4. Reading Data Back into Python

Once your data is processed and stored in XAMPP, you might need to pull it back into a Jupyter Lab environment for visualization (using Matplotlib or Seaborn) or to feed it into a Scikit-learn predictive model.

``` python
# Re-using the SQLAlchemy engine created above
query = "SELECT * FROM patient_risk_analysis WHERE high_risk_flag = 1"

# Load query results directly into a new pandas DataFrame
high_risk_patients_df = pd.read_sql(query, con=engine)

print(high_risk_patients_df.head())
```

## 5. Best Practices & Troubleshooting

* **Connection Pooling:** SQLAlchemy automatically handles connection pooling. This is highly efficient when your algorithm makes frequent, small database calls.
* **XAMPP Port Conflicts:** If your script fails to connect, ensure XAMPP's MySQL module is actually running on port 3306. Other local services sometimes hijack this port.
* **Security:** While the default XAMPP root user has no password (`""`), it is best practice to create a dedicated user with a strong password via phpMyAdmin before writing production-level scripts. Never hardcode passwords in your final GitHub repositories (e.g., use `.env` files).
