# Live BI Dashboards: DirectQuery Mode

When transitioning from traditional business operations to modern data strategy, relying on static data extracts becomes a massive bottleneck. If a stakeholder needs to analyse live regional sales or inventory levels, downloading and refreshing manual CSV files is no longer viable. 

This module covers how to connect enterprise BI tools (Tableau and Power BI) directly to cloud data warehouses like Google BigQuery. By leveraging **DirectQuery (Power BI)** or **Live Connection (Tableau)**, you push the computational heavy lifting to the cloud, ensuring your visualisations always reflect real-time data.

---

## 1. The Core Concept: Import vs. DirectQuery

Before connecting your tools, it is critical to understand the two primary ways BI platforms handle data.

### Data Import (Extract Mode)
* **How it works:** The BI tool downloads a snapshot of the data from the database into its own memory.
* **Pros:** Extremely fast dashboard performance because the data is stored locally.
* **Cons:** Data becomes stale immediately. Requires scheduled refreshes. It is also limited by the RAM of the machine or the BI service tier, making it difficult to scale when working with millions of rows.

### DirectQuery (Live Mode)
* **How it works:** The BI tool stores **no data**. Instead, it stores the database schema. Every time a user clicks a filter or loads a chart, the BI tool generates a SQL query and sends it directly to BigQuery. BigQuery processes the data and sends only the aggregated results back to the dashboard.
* **Pros:** Data is always real-time. Can handle petabytes of data because the cloud warehouse does the processing. 
* **Cons:** Dashboard performance depends entirely on the speed of the underlying database. Poorly optimised cloud tables will result in slow, expensive dashboards.

## 2. Connecting Power BI to BigQuery (DirectQuery)

Power BI handles cloud connections seamlessly, allowing you to build dynamic visualisations on top of large-scale datasets.

### Step-by-Step Setup:
1. Open Power BI Desktop.
2. Go to **Home** > **Get Data** > **More...**
3. Search for and select **Google BigQuery**, then click **Connect**.
4. Sign in with the Google account associated with your BigQuery project.
5. In the Navigator window, expand your project ID and dataset, then select the tables you want to analyse.
6. **Crucial Step:** When prompted for the Data Connectivity mode, select **DirectQuery** (do not select Import).
7. Click **Load**.

*Note: In DirectQuery mode, certain DAX (Data Analysis Expressions) functions are restricted because they cannot be translated into native SQL for BigQuery to execute.*

---

## 3. Connecting Tableau to BigQuery (Live Connection)

Tableau is highly optimised for cloud data and offers a native connector for Google BigQuery.

### Step-by-Step Setup:
1. Open Tableau Desktop.
2. Under the **Connect** pane on the left, navigate to **To a Server** > **More...** > **Google BigQuery**.
3. Authenticate via your web browser using your Google Cloud credentials.
4. Select your Billing Project, Dataset, and drag your desired tables into the data canvas.
5. In the top right corner of the Data Source tab, ensure the connection radio button is set to **Live** (instead of Extract).
6. Proceed to your worksheet to begin building visualisations.

## 4. Applying this to Large Datasets (e.g., Olist E-Commerce)

When working with comprehensive datasets containing 100,000+ rows, like the Brazilian E-Commerce data, DirectQuery changes how you approach dashboard design.

Instead of loading the entire raw orders table into Power BI or Tableau, you can query the exact metrics needed. When a user filters the dashboard to view "Delivery Times in São Paulo," the BI tool sends a highly specific query to BigQuery:

``` sql
-- What Tableau/Power BI sends to the cloud under the hood
SELECT 
    customer_state,
    AVG(delivery_days) AS avg_delivery_time
FROM 
    `your_project.olist_dataset.orders_joined`
WHERE 
    customer_state = 'SP'
GROUP BY 
    customer_state;
```

The dashboard only receives a few rows of aggregated results back, keeping the network payload incredibly light while delivering accurate, live insights.

## 5. Performance and Cost Optimisation in Live Mode

Because every click on a DirectQuery dashboard executes a query in BigQuery, you must protect your business from skyrocketing cloud costs.

* **Avoid 'Select All' Filters:** Defaulting a dashboard to show all data for all time forces massive queries. Set default filters (e.g., "Current Month") to restrict the initial data scanned.
* **Use Materialised Views:** If your dashboard heavily aggregates data (e.g., daily total sales), create a materialised view in BigQuery and connect your BI tool to that view rather than the raw transactional tables.
* **Enable BI Engine:** Google BigQuery offers a feature called **BI Engine**, an in-memory analysis service. It caches frequently accessed data, drastically accelerating Tableau and Power BI load times while simultaneously reducing query costs.

By mastering DirectQuery, you bridge the gap between raw data storage and strategic business intelligence, ensuring stakeholders always have access to the latest operational metrics.
