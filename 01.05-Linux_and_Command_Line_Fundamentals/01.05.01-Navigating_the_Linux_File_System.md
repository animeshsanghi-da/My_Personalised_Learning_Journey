# Linux and Command Line: Navigating the File System

## Introduction
While IDEs like VS Code and Jupyter Lab offer excellent graphical interfaces, interacting with cloud environments (like AWS EC2 or GCP Virtual Machines) requires command-line proficiency. As a Data Analyst, you will frequently need to navigate remote servers, organise massive datasets, and manage project environments purely through text. 

This module covers the foundational Linux commands required to maneuver through file systems seamlessly, ensuring your analytical workflows remain organised and secure.

---

## Core Navigation Commands

### 1. `pwd` (Print Working Directory)
When you log into a remote server or open a fresh terminal, there is no visual folder structure. `pwd` tells you your exact current location.

```bash
$ pwd
/home/animeshsanghi-da/projects
```
*Analyst Application:* Always run this before executing data-deletion scripts to ensure you are in the correct environment.

### 2. `ls` (List)
The `ls` command displays the contents of your current directory. By itself, it just lists names, but data professionals rely on its flags to understand file sizes and permissions.

```bash
$ ls
notebooks  raw_data  processed_data  main.py

# Use -l (long format) and -h (human-readable sizes) for datasets
$ ls -lh
total 115M
drwxr-xr-x 2 animeshsanghi-da users 4.0K May 02 10:00 notebooks
-rw-r--r-- 1 animeshsanghi-da users 112M May 02 10:05 olist_customers.csv
-rw-r--r-- 1 animeshsanghi-da users 3.2M May 02 10:10 olist_geolocation.csv
```
*Analyst Application:* The `-lh` flag is crucial to verify if a dataset is small enough to load into Pandas directly or if it requires chunking.

### 3. `cd` (Change Directory)
Used to navigate between folders. You can use absolute paths (the full route from the root directory) or relative paths (the route from your current location).

```bash
# Move into a specific project folder
$ cd /home/animeshsanghi-da/projects/Olist_Analysis

# Go back up one directory level
$ cd ..

# Return directly to your home directory from anywhere
$ cd ~
```

### 4. `mkdir` (Make Directory)
Used to create new folders. A structured repository is vital for reproducibility.

```bash
# Create a single folder
$ mkdir model_outputs

# Create a nested directory structure all at once using -p
$ mkdir -p hr_attrition_project/data/raw
```
*Analyst Application:* Standardise your GitHub repositories by always creating `data`, `notebooks`, and `scripts` directories when starting a new analysis.

## File Manipulation Commands

### 5. `cp` (Copy)
Copies files or directories from one location to another. 

```bash
# Copy a dataset to create a backup before cleaning
$ cp olist_orders.csv olist_orders_backup.csv

# Copy an entire directory (requires the -r flag for recursive)
$ cp -r /home/animeshsanghi-da/raw_data /home/animeshsanghi-da/archive/
```
*Analyst Application:* Never overwrite raw data. Always `cp` the raw extract into a `processed` folder before applying Python or SQL transformations.

### 6. `mv` (Move / Rename)
The `mv` command serves two purposes: moving files between directories and renaming files.

```bash
# Rename a poorly named extract
$ mv export_12345.csv sales_q1_2026.csv

# Move a Python script into the scripts folder
$ mv etl_pipeline.py ./scripts/
```

### 7. `rm` (Remove)
Deletes files or directories. **Warning:** Linux does not have a "Recycle Bin." Once a file is removed via the command line, it is permanently gone.

```bash
# Delete a specific file
$ rm test_data.csv

# Delete a directory and all its contents (-r for recursive, -f to force without prompting)
$ rm -rf old_project_folder/
```
*Analyst Application:* Be extremely cautious with `rm -rf`, especially when handling irreplaceable client data or uncommitted code.

## Practical Analyst Workflow Example

Imagine you have just downloaded a large e-commerce dataset and need to set up your workspace:

```bash
# 1. Verify your location
$ pwd
/home/animeshsanghi-da/downloads

# 2. Create a structured project environment
$ mkdir -p ~/projects/ecommerce_analysis/data/raw

# 3. Move the downloaded CSV into the raw data folder
$ mv olist_full_dataset.csv ~/projects/ecommerce_analysis/data/raw/

# 4. Navigate into the new project folder
$ cd ~/projects/ecommerce_analysis/

# 5. Verify the file size before opening it in VS Code or Jupyter
$ ls -lh data/raw/
```

Mastering these basic commands allows you to handle server-side data extraction, pipeline configuration, and repository management with the speed and confidence expected in modern analytics roles.
