# Text Processing with Grep and Awk: Command-Line Data Extraction

## Introduction
While you might typically load a dataset into a Pandas DataFrame via Jupyter Lab or VS Code to analyse it, there are times when this approach fails. If you are connected to a remote cloud server (like an AWS EC2 instance) and need to inspect a 50GB server log or a massive raw CSV file, attempting to load it into memory will crash your system. 

This is where `grep` and `awk` become invaluable. These lightweight, blazing-fast command-line utilities allow you to search, filter, and perform column-based data manipulation on the fly, directly from the terminal, without ever opening Python or SQL.

---

## 1. `grep`: Searching for Patterns
The `grep` (Global Regular Expression Print) command is used to search text for specific patterns. Think of it as a highly optimized `Ctrl+F` for massive files.

### Basic Searching
To find every instance of a specific word in a file:
```bash
grep "failed" server_logs.txt
```

### Essential Flags for Data Analytics
* **`-i` (Ignore Case):** Makes the search case-insensitive.
  ```bash
  grep -i "error" server_logs.txt
  ```
* **`-c` (Count):** Instead of printing the lines, it outputs the total number of matching lines. Great for a quick frequency check.
  ```bash
  grep -c "São Paulo" olist_customers.csv
  ```
* **`-v` (Invert Match):** Prints everything *except* the lines that match the pattern. Useful for filtering out noise (like headers or successful transactions).
  ```bash
  grep -v "SUCCESS" transactions.csv
  ```
* **`-E` (Extended Regex):** Allows you to use complex regular expressions. For example, finding lines with either "Error" or "Warning":
  ```bash
  grep -E "Error|Warning" system_logs.txt
  ```

## 2. `awk`: Column-Based Data Manipulation
While `grep` filters rows, `awk` is a full programming language designed specifically for column-based text processing. By default, `awk` assumes columns are separated by whitespace, but you can easily configure it for CSVs.

### Extracting Specific Columns
If you have a CSV and only want to view the `customer_id` (column 1) and `price` (column 5):
```bash
awk -F',' '{print $1, $5}' olist_order_items.csv
```
*Note: The `-F','` flag tells `awk` that the Field separator is a comma.*

### Filtering with Conditions
You can apply logic directly within `awk` to filter rows based on column values. For example, printing the entire row (`$0`) only if the price in column 5 is greater than 100:
```bash
awk -F',' '$5 > 100 {print $0}' olist_order_items.csv
```

### On-the-Fly Aggregations
You can even use `awk` to perform quick math without spinning up Python. To calculate the total sum of all values in column 5:
```bash
awk -F',' '{sum += $5} END {print "Total Revenue:", sum}' olist_order_items.csv
```

---

## 3. Combining Tools with Pipes (`|`)
The true power of the command line lies in chaining these tools together using the pipe (`|`) operator. The output of one command becomes the input of the next.

### Real-World Example: Log Analysis Pipeline
Imagine you need to analyse a massive application log to find which IP addresses are generating the most "404 Not Found" errors. 

```bash
grep "404" access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -n 5
```

**How this pipeline works:**
1. `grep "404" access.log`: Filters the file for rows containing "404".
2. `awk '{print $1}'`: Extracts only the first column (assuming the IP address is column 1).
3. `sort`: Groups the identical IP addresses together.
4. `uniq -c`: Counts the unique occurrences of each IP.
5. `sort -nr`: Sorts the counts numerically (`-n`) and in reverse order (`-r`) so the highest counts are at the top.
6. `head -n 5`: Displays only the top 5 worst offenders.
