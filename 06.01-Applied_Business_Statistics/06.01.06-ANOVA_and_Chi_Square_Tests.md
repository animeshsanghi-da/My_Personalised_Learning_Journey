# ANOVA and Chi-Square Tests: Advanced Categorical Analysis

## Introduction
While standard T-tests and A/B tests are excellent for comparing two groups, business operations rarely fit into simple binary scenarios. When scaling operations or analysing market expansions, you frequently need to compare three or more groups, or assess the relationship between different categorical variables. 

This is where **ANOVA (Analysis of Variance)** and the **Chi-Square Test** become essential tools in your analytics stack. These tests allow you to rigorously analyse multi-segment data and confidently present statistically sound strategies to stakeholders.

---

## 1. ANOVA (Analysis of Variance)

**When to use it:** When you need to compare the means of a *continuous* variable across *three or more categorical groups*.

### The Business Context
Imagine you are evaluating the average monthly revenue for new branches in three different target cities: Indore, Bengaluru, and Pune. 
* **Null Hypothesis ($H_0$):** There is no significant difference in average revenue across the three cities.
* **Alternative Hypothesis ($H_a$):** At least one city's average revenue is significantly different from the others.

ANOVA calculates the **F-statistic**, which compares the variance *between* the groups to the variance *within* the groups. A high F-statistic and a low p-value (typically < 0.05) indicate that the group means are not all equal.

### Python Implementation: One-Way ANOVA

``` python
import pandas as pd
import scipy.stats as stats

# Simulated revenue data (in thousands) for three cities
data = {
    'Indore': [45, 48, 42, 50, 46],
    'Bengaluru': [65, 70, 68, 72, 69],
    'Pune': [55, 58, 54, 60, 57]
}
df = pd.DataFrame(data)

# Perform One-Way ANOVA
f_stat, p_value = stats.f_oneway(df['Indore'], df['Bengaluru'], df['Pune'])

print(f"F-Statistic: {f_stat:.2f}")
print(f"P-Value: {p_value:.5f}")

if p_value < 0.05:
    print("Conclusion: Reject the null hypothesis. There is a significant difference in revenue between the cities.")
else:
    print("Conclusion: Fail to reject the null hypothesis. No significant difference found.")
```

*Note: If ANOVA indicates a significant difference, you would typically follow up with a post-hoc test (like Tukey's HSD) to identify exactly which specific cities differ from each other.*

## 2. Chi-Square Test of Independence

**When to use it:** When you need to determine if there is a significant relationship between two *categorical* variables. It compares the *observed* frequencies in your data to the *expected* frequencies if the variables were completely independent.

### The Business Context
Suppose you are analysing merchant data for quick-service restaurants and want to know if the **Order Type** (Dine-in, Takeaway, Delivery via platforms like Zomato) is independent of the **Customer Satisfaction Rating** (High, Medium, Low).

* **Null Hypothesis ($H_0$):** Order Type and Satisfaction Rating are independent (one does not affect the other).
* **Alternative Hypothesis ($H_a$):** There is a dependency between Order Type and Satisfaction Rating.

### Python Implementation: Chi-Square Test

``` python
import pandas as pd
from scipy.stats import chi2_contingency

# Creating a contingency table of observed frequencies
# Columns: Dine-in, Takeaway, Delivery
# Rows: High Satisfaction, Medium Satisfaction, Low Satisfaction
contingency_table = [
    [50, 30, 20],  # High
    [20, 40, 30],  # Medium
    [10, 15, 45]   # Low
]

# Perform Chi-Square Test
chi2_stat, p_val, dof, expected = chi2_contingency(contingency_table)

print(f"Chi-Square Statistic: {chi2_stat:.2f}")
print(f"P-Value: {p_val:.5f}")

if p_val < 0.05:
    print("Conclusion: Reject the null hypothesis. Order type and satisfaction are dependent.")
else:
    print("Conclusion: Fail to reject the null hypothesis. Variables are independent.")
```

## 3. Interpreting Results for Stakeholders

When presenting these findings, the statistical jargon must be translated into business strategy:

* **Bad Communication:** "The ANOVA test yielded a p-value of 0.012, so we rejected the null hypothesis."
* **Good Communication:** "Our analysis confirms a statistically significant difference in revenue performance across our regional markets. Specifically, the data shows that the Bengaluru market is operating in a different tier than Pune and Indore, suggesting we should allocate targeted marketing budgets rather than a uniform national approach."

**Key Takeaway for Analysts:** Never rely solely on the p-value. Always pair it with descriptive statistics and data visualisation (like a Seaborn boxplot for ANOVA or a stacked bar chart for Chi-Square) to tell a complete, compelling story.
