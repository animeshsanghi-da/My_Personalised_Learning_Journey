## 4. Initial Quality Checks
Before diving into deeper statistical analysis and visualisation, we must understand the raw data structure, identify noise, and locate missing values.

```python
# Check data types and memory usage
orders_df.info()

# Calculate the exact percentage of missing values per column
missing_percentages = (orders_df.isnull().sum() / len(orders_df)) * 100
print("Missing Value Percentages:")
print(missing_percentages[missing_percentages > 0].sort_values(ascending=False))
```

## 5. Missing Value Imputation & Data Type Corrections
Timestamps in CSVs load as standard strings (`object` dtype). They must be converted to `datetime` objects to properly analyse time-series trends, delivery delays, and seasonal purchasing behaviour.

```python
# 1. Correcting Data Types (Converting to Datetime)
time_columns = [
    'order_purchase_timestamp',
    'order_approved_at',
    'order_delivered_carrier_date',
    'order_delivered_customer_date',
    'order_estimated_delivery_date'
]

for col in time_columns:
    orders_df[col] = pd.to_datetime(orders_df[col])

# 2. Contextual Handling of Missing Values
# For Olist, missing delivery dates often mean the order was canceled or is still in transit.
# Dropping them blindly introduces bias. We filter for 'delivered' status first.
delivered_orders = orders_df[orders_df['order_status'] == 'delivered'].copy()

# For missing approval times on delivered orders, we can impute using the purchase timestamp
# assuming instant approval for credit card automated systems.
delivered_orders['order_approved_at'] = delivered_orders['order_approved_at'].fillna(delivered_orders['order_purchase_timestamp'])

# Verify the transformations
print("\nPost-Cleaning Info:")
print(delivered_orders.info())
```
