# 06.02.02 - Statistical Summaries and Visualisation

## 1. Bridging the Gap: From Numbers to Narratives
After cleaning and structuring your data in the ingestion phase, the next step for any Business Intelligence or Data Analyst is to understand its underlying patterns. We begin with descriptive statistics using Pandas and NumPy, which provide a mathematical summary. However, raw numbers rarely tell the full story to non-technical stakeholders. We must transition these statistics into compelling visual narratives using Matplotlib and Seaborn.

## 2. Descriptive Statistics (The Mathematical Foundation)
Before plotting anything, we generate a statistical summary. This helps us spot extreme outliers, understand the central tendency (mean, median), and gauge the spread (standard deviation) of our numerical features.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Set visual aesthetic parameters for professional reporting
sns.set_theme(style="whitegrid", palette="muted")
plt.rcParams['figure.figsize'] = (10, 6)

# Assuming 'delivered_orders' and 'items_df' from the previous module are merged
# merged_df = pd.merge(delivered_orders, items_df, on='order_id', how='inner')

# 1. Generate descriptive statistics for numerical columns
numeric_summary = merged_df[['price', 'freight_value']].describe()
print("Statistical Summary of Pricing and Freight:")
display(numeric_summary)

# 2. Identify categorical distribution (e.g., top 5 product categories)
top_categories = merged_df['product_category_name'].value_counts().head(5)
print("\nTop 5 Product Categories by Volume:")
print(top_categories)
```

## 3. Univariate Analysis: Understanding Individual Features
Univariate analysis focuses on a single variable at a time. The goal is to analyse the distribution of data points. Are order values skewed? Do we have massive outliers in freight costs? 

```python
# Visualising the distribution of Order Prices using Seaborn
plt.figure(figsize=(12, 5))

# Subplot 1: Histogram to show frequency distribution
plt.subplot(1, 2, 1)
sns.histplot(merged_df['price'], bins=50, kde=True, color='skyblue')
plt.title('Distribution of Order Prices')
plt.xlabel('Price')
plt.ylabel('Frequency')

# Subplot 2: Boxplot to highlight outliers
plt.subplot(1, 2, 2)
sns.boxplot(x=merged_df['price'], color='lightgreen')
plt.title('Price Outliers')
plt.xlabel('Price')

plt.tight_layout()
plt.show()
```

## 4. Bivariate Analysis: Uncovering Relationships
Business problems are rarely one-dimensional. Bivariate analysis looks at two variables simultaneously to find correlations and relationships. For example, does a higher product price correlate with a higher freight cost? How do different regions perform?

```python
# 1. Scatter Plot: Price vs. Freight Value
plt.figure(figsize=(10, 6))
sns.scatterplot(data=merged_df, x='price', y='freight_value', alpha=0.4, color='coral')
plt.title('Relationship Between Product Price and Freight Value')
plt.xlabel('Product Price')
plt.ylabel('Freight Value')
plt.show()

# 2. Bar Chart: Average Price by Top Categories
plt.figure(figsize=(10, 6))
# Calculate mean price for the top categories we identified earlier
top_cat_data = merged_df[merged_df['product_category_name'].isin(top_categories.index)]
sns.barplot(data=top_cat_data, x='price', y='product_category_name', estimator=np.mean, errorbar=None)
plt.title('Average Order Price per Top Product Category')
plt.xlabel('Average Price')
plt.ylabel('Category')
plt.show()
```

## 5. Advanced Tip: Matrix Formulation for Downstream ML
While EDA focuses heavily on visual insights, keep your target ML models in mind. If you spot a strong linear relationship during this phase and plan to feed this directly into a Scikit-learn `LinearRegression` model, you might need to structure your features as 2D arrays or matrices. If explicit matrix operations are required in your pipeline, recall that using `np.asmatrix` (in NumPy 2.0+) ensures your mathematical formulations remain robust after `np.mat` deprecation.
