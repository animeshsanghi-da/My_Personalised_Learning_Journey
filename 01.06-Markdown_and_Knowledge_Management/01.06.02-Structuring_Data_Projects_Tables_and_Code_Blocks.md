# Structuring Data Projects: Tables and Code Blocks

When building a professional portfolio repository or documenting your work in tools like VS Code and Obsidian, plain text is not enough. You need to present your code clearly, define your datasets rigorously, and showcase your visualisations. 

This guide covers the specific Markdown syntax used most frequently in data analytics to achieve a clean, readable structure.

---

## 1. Multi-Language Code Snippets

In data analytics, you will constantly switch between querying databases and processing data. Markdown allows you to format and highlight code blocks specific to the language you are using.

To create a code block, use three backticks (`````) followed by the language name (e.g., `sql`, `python`).

### SQL Formatting
When documenting your ETL processes or database extractions, use the `sql` tag. This highlights keywords like `SELECT`, `FROM`, and `WHERE`.

```sql
-- Extracting recent orders for business review
SELECT 
    order_id, 
    customer_id, 
    order_status, 
    order_purchase_timestamp
FROM 
    olist_orders_dataset
WHERE 
    order_status = 'delivered'
ORDER BY 
    order_purchase_timestamp DESC
LIMIT 10;
```

### Python Formatting
When documenting your data cleaning or machine learning scripts, use the `python` tag. This is essential for showcasing your pandas, numpy, and scikit-learn workflows.

```python
import pandas as pd
import numpy as np

# Load the dataset
df = pd.read_csv('data/olist_orders_dataset.csv')

# Convert timestamp strings to datetime objects
df['order_purchase_timestamp'] = pd.to_datetime(df['order_purchase_timestamp'])

# Check for missing values before we analyse
print(df.isnull().sum())
```

*Note: For inline code (referencing a variable or function in the middle of a sentence, like `pd.DataFrame`), use a single backtick (`).*

## 2. Constructing Readable Markdown Tables (Data Dictionaries)

A Data Dictionary is a critical component of any end-to-end data project. It tells stakeholders and other analysts exactly what each column in your dataset represents. Markdown tables are the standard way to present this.

### Basic Table Syntax
Tables are created using pipes (`|`) to separate columns and hyphens (`-`) to create the header row.

```markdown
| Column Name | Data Type | Description |
|---|---|---|
| order_id | string | Unique identifier for the order. |
| customer_id | string | Key to the customer dataset. |
| order_status | string | Reference to the order status (e.g., delivered, shipped). |
| price | float | Item price in local currency. |
```

**Renders as:**

| Column Name | Data Type | Description |
|---|---|---|
| order_id | string | Unique identifier for the order. |
| customer_id | string | Key to the customer dataset. |
| order_status | string | Reference to the order status (e.g., delivered, shipped). |
| price | float | Item price in local currency. |

### Column Alignment
You can control the alignment of the text in your columns by adding colons (`:`) to the header separator.
* `:---` Left align (default)
* `:---:` Center align
* `---:` Right align (great for numeric data types)

```markdown
| Feature | Importance Score | Action Required |
|:---|---:|:---:|
| recency | 0.85 | Retain |
| frequency | 0.62 | Monitor |
```

## 3. Embedding Images of Visualisations

A data project is incomplete without visual proof of your findings. Whether it is a Seaborn correlation heatmap or a dashboard screenshot from Power BI or Tableau, embedding images directly into your Markdown narrative keeps the reader engaged.

### Image Syntax
The syntax for an image is nearly identical to a hyperlink, but it starts with an exclamation mark (`!`).

`![Alt Text](Path/To/Image.png)`

* **Alt Text:** A brief description of the image. This is important for accessibility and displays if the image link breaks.
* **Path:** The relative path to where the image is stored in your repository.

**Example:**
If you have a folder structure where your notebook is in the root and your charts are in a folder named `images`, you would embed your visualisations like this:

```markdown
### Sales Trend Visualisation

The following line chart demonstrates the month-over-month revenue growth across all primary regions.

![Monthly Revenue Trend 2025](../Images/monthly_revenue_trend.png)
```

*Pro-Tip for GitHub:* If you are hosting your portfolio at `https://github.com/animeshsanghi-da/your-repo`, using relative paths (`./images/chart.png`) ensures your visualisations load correctly for anyone viewing the repository online.
