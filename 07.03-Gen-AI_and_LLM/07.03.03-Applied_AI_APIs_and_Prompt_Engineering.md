## 1. Integrating AI APIs into the Data Pipeline

Accessing LLMs programmatically allows you to perform bulk text processing, data classification, and automated insight generation directly within your ETL pipelines.

### 1.1 Python API Setup (Gemini / OpenAI)
Using libraries like `requests` or official SDKs, you can pass data from a DataFrame directly to an LLM. This is particularly useful for tasks like classifying product reviews from an e-commerce database (e.g., Olist) or categorizing unstructured notes in a healthcare ETL script before pushing them to MySQL.

``` python
import pandas as pd
import google.generativeai as genai
import os

# Configure the API key securely
genai.configure(api_key=os.environ.get("GEMINI_API_KEY"))
model = genai.GenerativeModel('gemini-pro')

def classify_review(text):
    prompt = f"Classify the sentiment of this e-commerce review as Positive, Neutral, or Negative: '{text}'"
    response = model.generate_content(prompt)
    return response.text
```

### 1.2 Use Cases for API Integration
* **Data Enrichment:** Automatically extracting entities (names, locations, product codes) from unstructured text.
* **Data Cleaning:** Fixing formatting inconsistencies that are too complex for simple Regex operations.
* **Documentation:** Automatically generating docstrings or markdown summaries for your MySQL database schemas or Python scripts to be stored in your Obsidian knowledge base.

## 2. Prompt Engineering for Data Tasks

Prompt engineering is not just about talking to a chatbot; it is about writing precise, constrained instructions to generate robust code, complex SQL queries, or data visualisations.

### 2.1 The "Persona-Task-Context-Format" Framework
To get the best results, structure your prompts rigorously:
* **Persona:** "Act as an expert Data Analyst and Python developer."
* **Task:** "Write a Pandas script to handle missing values and merge two datasets."
* **Context:** "The data comes from a healthcare ETL process. Table A has patient IDs, Table B has diagnostic codes."
* **Format:** "Output only the executable Python code. Do not use deprecated syntax."

### 2.2 Accelerating Code Generation
You can use LLMs to generate boilerplate code for tedious tasks, freeing you to focus on logic and business value.
* **SQL:** "Write a MySQL query to calculate the 7-day rolling average of sales, partitioned by region."
* **Python/NumPy:** "Provide a script to convert a 2D array into a matrix format. Ensure you do not use the deprecated `np.mat` function, but rather modern alternatives like `np.asmatrix` or standard array operations."
* **BI Tools:** "Write a DAX measure for Power BI to calculate Year-over-Year growth, handling blank values gracefully."

## 3. AI-Assisted Exploratory Data Analysis (EDA)

Modern AI tools can act as a copilot during the EDA phase, helping you spot trends and write visualisation code faster.

### 3.1 Generating Visualisations
Instead of memorizing `Matplotlib` or `Seaborn` parameters, you can describe the exact chart you need:
* *Prompt Example:* "Generate Python code using Seaborn to plot a grouped bar chart showing average delivery times for e-commerce orders, segmented by customer state and product category. Apply a professional corporate color palette."

### 3.2 Explaining Complex Algorithms
When applying machine learning algorithms from `scikit-learn` (like Linear Regression for predictive analysis), you can use an LLM to explain the model's coefficients or feature importance scores in plain English. This output can then be directly integrated into your Tableau dashboards or presentation decks for non-technical stakeholders.

## 4. Best Practices & Security in Business

When deploying Applied AI in an enterprise environment, strict adherence to security protocols is mandatory.

* **Never Expose Sensitive Data:** Do not pass Personally Identifiable Information (PII), confidential business metrics, or proprietary healthcare data into public API endpoints unless using a secured, enterprise-tier instance.
* **Version Control AI Scripts:** Treat API integration scripts like any other production code. Store them securely, and commit them to your professional repositories (e.g., `https://github.com/animeshsanghi-da/`).
* **Validate AI Outputs:** LLMs can hallucinate logic. Always verify generated SQL against a test database and validate Pandas transformations by checking `.shape`, `.head()`, and `.info()` before pushing to production.
* **Manage API Costs:** Monitor token usage. When testing a script that calls an API per row on a 100,000-row dataset, test it on a 50-row sample first to avoid massive, unexpected billing charges.
