## Introduction
In the previous modules, we learned how to clean text and convert it into numbers using TF-IDF. Now, we are going to extract direct business value from that text. **Sentiment Analysis** (often called opinion mining) is the automated process of identifying the emotional tone behind a body of text. 

For data analysts and scientists, sentiment analysis is the bridge between qualitative human opinions and quantitative business metrics. Whether you are analyzing thousands of Amazon product reviews, monitoring Twitter (X) mentions of your brand, or reading customer support tickets, sentiment analysis allows you to measure customer satisfaction at scale without reading a single word manually.

---

## Core Concepts: Polarity and Subjectivity

When we analyze text using traditional, rule-based NLP libraries (like `TextBlob` or `VADER`), we generally extract two primary metrics:

### 1. Polarity
Polarity measures how positive or negative the text is. It is usually returned as a float value ranging from **-1.0 to 1.0**.
* **-1.0:** Highly Negative (e.g., "This product is an absolute disaster and a waste of money.")
* **0.0:** Neutral (e.g., "The package arrived on Tuesday.")
* **1.0:** Highly Positive (e.g., "I absolutely love this! Best purchase ever.")

### 2. Subjectivity
Subjectivity measures how factual or opinionated the text is. It ranges from **0.0 to 1.0**.
* **0.0:** Completely Objective / Factual (e.g., "The phone has a 6-inch screen and weighs 150 grams.")
* **1.0:** Completely Subjective / Opinion (e.g., "This is the most beautiful phone I have ever seen.")

*Business Tip:* Filtering by subjectivity is highly useful. If you want to know what features are broken, look for *objective* negative reviews. If you want to know how people *feel* about your brand, look for *subjective* reviews.

## Applied Business Use Case: Product Reviews

Let's look at how this is applied using Python. We will avoid complex neural networks here and use **TextBlob** and **VADER** (Valence Aware Dictionary and sEntiment Reasoner), which are industry-standard, lightweight tools specifically tuned for social media and customer reviews.

### Step 1: Basic Sentiment with TextBlob

```python
from textblob import TextBlob

# A sample customer review
review = "The battery life is decent, but the camera is absolutely terrible. I regret buying this."

# Create a TextBlob object
blob = TextBlob(review)

print(f"Polarity: {blob.sentiment.polarity}")
print(f"Subjectivity: {blob.sentiment.subjectivity}")
```

*Output:* Polarity might be around `-0.5` (Negative), and Subjectivity around `0.8` (Highly opinionated).

### Step 2: Handling Business Reality with VADER
TextBlob is great, but customers often use emojis, slang, and heavy punctuation ("THIS IS TERRIBLE!!! 😡"). **VADER** is specifically built to handle this type of modern internet text. It outputs a `compound` score between -1 and 1.

```python
from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer

analyzer = SentimentIntensityAnalyzer()

# A realistic, messy product review
realistic_review = "The delivery was late... but the product itself is AMAZING!!! 😍"

scores = analyzer.polarity_scores(realistic_review)
print(scores)

# Expected Output: {'neg': 0.0, 'neu': 0.54, 'pos': 0.46, 'compound': 0.812}
```

*Notice how VADER correctly identifies the overall positive sentiment (compound = 0.812) despite the mention of a late delivery, because it understands the weight of "AMAZING!!!" and the 😍 emoji.*

## Scaling up: Adding Sentiment to a DataFrame

In a real business scenario, you aren't analyzing one string; you are analyzing a pandas DataFrame containing tens of thousands of rows. 

```python
import pandas as pd
from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer

# 1. Load your business dataset
df = pd.read_csv("customer_reviews.csv") # Columns: ['Review_ID', 'Product', 'Review_Text']

# 2. Initialize the analyzer
analyzer = SentimentIntensityAnalyzer()

# 3. Create a function to apply to your DataFrame
def get_compound_sentiment(text):
    # Handle missing values
    if pd.isna(text):
        return 0.0
    return analyzer.polarity_scores(str(text))['compound']

# 4. Apply the function to create a new column
df['Sentiment_Score'] = df['Review_Text'].apply(get_compound_sentiment)

# 5. Categorize for the business stakeholders
df['Sentiment_Category'] = pd.cut(df['Sentiment_Score'], 
                                  bins=[-1, -0.05, 0.05, 1], 
                                  labels=['Negative', 'Neutral', 'Positive'])

# Now you can group by product and find the worst performing items!
poor_products = df.groupby('Product')['Sentiment_Score'].mean().sort_values().head(5)
print(poor_products)
```
