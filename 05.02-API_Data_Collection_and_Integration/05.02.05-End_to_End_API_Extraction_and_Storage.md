# End-to-End API Extraction and Storage

## Introduction
This is the capstone of the API Data Collection module. We are moving beyond standalone concepts to build a robust, production-ready script. This script will authenticate with a REST API, navigate through paginated results, respect server rate limits, flatten the nested JSON responses into a structured Pandas DataFrame, and finally load the clean data into both a local CSV file and a MySQL database.

This architecture forms the foundation of modern ETL (Extract, Transform, Load) pipelines, particularly useful for continuous data ingestion tasks like healthcare phase-based processing or e-commerce metric tracking.

---

## The Scenario
Imagine you are querying an external API that provides paginated records (e.g., regional facility metrics). The API requires a Bearer token for authentication and limits responses to 100 records per page. 

We will use VS Code to write a Python script that automates this entire extraction and loading phase.

Ensure your Anaconda environment has the necessary libraries installed. We will use `sqlalchemy` and `pymysql` to handle the MySQL database connection.

## The Complete Capstone Script

Below is the consolidated script. Save this as `api_etl_pipeline.py` in your project workspace.

``` python
import requests
import pandas as pd
import time
import os
from sqlalchemy import create_engine
from dotenv import load_dotenv

# Load environment variables (API Keys and DB Credentials)
load_dotenv()

# --- Configuration ---
API_URL = "https://api.mock-healthcare-data.com/v1/facilities"
API_TOKEN = os.getenv("API_BEARER_TOKEN") # Never hardcode credentials
DB_USER = os.getenv("MYSQL_USER")
DB_PASS = os.getenv("MYSQL_PASSWORD")
DB_HOST = "localhost"
DB_NAME = "analytics_db"

# Setup Headers for Authentication
HEADERS = {
    "Authorization": f"Bearer {API_TOKEN}",
    "Accept": "application/json"
}

def extract_api_data(base_url, headers, max_pages=50):
    """
    Paginates through the API, extracts JSON data, and handles rate limiting.
    """
    all_records = []
    page = 1
    has_more_data = True
    
    print("Starting API Extraction...")
    
    while has_more_data and page <= max_pages:
        # Construct the paginated URL (Assuming query parameter pagination)
        paginated_url = f"{base_url}?page={page}&limit=100"
        
        try:
            response = requests.get(paginated_url, headers=headers)
            
            # Handle rate limits (HTTP 429)
            if response.status_code == 429:
                print("Rate limit hit. Sleeping for 60 seconds...")
                time.sleep(60)
                continue # Retry the same page
                
            response.raise_for_status() # Raise exception for 4xx/5xx errors
            
            data = response.json()
            records = data.get("data", [])
            
            if not records:
                has_more_data = False
                print("No more records found. Extraction complete.")
            else:
                all_records.extend(records)
                print(f"Extracted page {page} ({len(records)} records).")
                page += 1
                
                # Polite scraping: short sleep between requests
                time.sleep(1) 
                
        except requests.exceptions.RequestException as e:
            print(f"An error occurred on page {page}: {e}")
            break # Exit loop safely on critical failure
            
    return all_records

def transform_data(raw_json):
    """
    Flattens the nested JSON and performs basic data type cleaning.
    """
    print("Transforming data...")
    # Flatten nested dictionaries (e.g., 'location' dict inside the record)
    df = pd.json_normalize(raw_json, sep='_')
    
    # Standardise column names (lowercase, replace spaces with underscores)
    df.columns = [col.strip().lower().replace(" ", "_") for col in df.columns]
    
    # Drop completely empty rows or irrelevant metadata columns
    if 'metadata_version' in df.columns:
        df = df.drop(columns=['metadata_version'])
        
    print(f"Transformation complete. DataFrame shape: {df.shape}")
    return df

def load_data(df, table_name):
    """
    Loads the cleaned DataFrame into a local CSV and a MySQL database.
    """
    # 1. Load to Local CSV (Backup / Flat File Storage)
    csv_filename = f"{table_name}_extract.csv"
    df.to_csv(csv_filename, index=False)
    print(f"Data saved locally to {csv_filename}")
    
    # 2. Load to MySQL Database
    print("Connecting to MySQL Database...")
    try:
        # Construct the SQLAlchemy connection string for MySQL
        engine = create_engine(f"mysql+pymysql://{DB_USER}:{DB_PASS}@{DB_HOST}/{DB_NAME}")
        
        # Write records to the database
        # 'replace' drops the table before inserting new values. Use 'append' to add to existing data.
        df.to_sql(name=table_name, con=engine, if_exists='replace', index=False)
        print(f"Successfully loaded {len(df)} records into the '{table_name}' table in MySQL.")
        
    except Exception as e:
        print(f"Database connection or insertion failed: {e}")

# --- Main Execution Block ---
if __name__ == "__main__":
    # Step 1: Extract
    raw_data = extract_api_data(API_URL, HEADERS)
    
    if raw_data:
        # Step 2: Transform
        cleaned_df = transform_data(raw_data)
        
        # Step 3: Load
        load_data(cleaned_df, table_name="facility_metrics")
    else:
        print("No data extracted. Pipeline halted.")
```

## Best Practices to Remember
1. **Modular Code:** Separating the `extract`, `transform`, and `load` logic into dedicated functions makes the script much easier to debug and test. 
2. **Environment Variables:** Never commit `API_BEARER_TOKEN`, `MYSQL_USER`, or `MYSQL_PASSWORD` to your GitHub repositories. Always use a `.env` file.
3. **Idempotency:** When loading data into databases, ensure your script can be run multiple times without causing duplicate data issues. The `if_exists='replace'` argument in Pandas handles this for full-refresh pipelines.

You can now use this architecture to programmatically ingest JSON from any standard REST API, ready to Analyse in Jupyter Lab or query directly via SQL!
