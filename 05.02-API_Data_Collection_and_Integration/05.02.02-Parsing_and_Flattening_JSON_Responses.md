# Parsing and Flattening JSON Responses for Data Analysis

## Introduction
When you successfully call a REST API, the data rarely arrives in a clean, row-and-column format ready for a database or a Tableau dashboard. Instead, it arrives as JSON (JavaScript Object Notation)—a hierarchical, heavily nested format. 

For a Data Analyst, the bridge between raw API extraction and analytical processing in Pandas is the ability to parse, navigate, and intelligently flatten this nested JSON. This module covers how to extract the exact data points you need and transform them into structured, two-dimensional DataFrames.

---

## 1. The Anatomy of API JSON Payloads
In Python, a JSON response translates directly into standard data structures:
* **JSON Objects (`{}`)** become **Python Dictionaries**.
* **JSON Arrays (`[]`)** become **Python Lists**.

A typical API response usually contains "metadata" (like pagination details) and a "payload" (the actual data you want).

``` python
# Example of a raw, nested JSON response from a mock E-Commerce API
api_response = {
    "status": "success",
    "metadata": {
        "total_records": 150,
        "page": 1
    },
    "data": [
        {
            "customer_id": "C001",
            "name": "Aarav",
            "location": {"city": "Indore", "state": "MP"},
            "orders": [
                {"order_id": "101", "amount": 2500.50},
                {"order_id": "102", "amount": 1200.00}
            ]
        },
        {
            "customer_id": "C002",
            "name": "Priya",
            "location": {"city": "Bengaluru", "state": "KA"},
            "orders": [
                {"order_id": "103", "amount": 8500.75}
            ]
        }
    ]
}
```

If you pass this directly into `pd.DataFrame(api_response['data'])`, Pandas will keep the `location` and `orders` columns as raw dictionaries and lists, which is useless for aggregation or SQL insertion.

## 2. Manual Extraction and Defensive Parsing
Before relying on automated tools, it is crucial to know how to navigate the hierarchy manually. This is necessary when you only need a few specific fields and want to avoid loading a massive DataFrame into memory.

When navigating dictionaries in a loop, **always use the `.get()` method** instead of direct bracket notation (`['key']`). APIs are notoriously inconsistent; if a key is missing, bracket notation throws a `KeyError` and crashes your pipeline. `.get()` safely returns `None` (or a default value).

``` python
# Extracting specific data manually into a clean list of dictionaries
cleaned_data = []

for customer in api_response.get("data", []):
    # Defensive parsing using .get()
    cust_id = customer.get("customer_id")
    city = customer.get("location", {}).get("city", "Unknown")
    
    # Handling nested lists safely
    for order in customer.get("orders", []):
        cleaned_data.append({
            "Customer_ID": cust_id,
            "City": city,
            "Order_ID": order.get("order_id"),
            "Amount": order.get("amount", 0.0)
        })

# Now it is safe to convert to a DataFrame
import pandas as pd
df_manual = pd.DataFrame(cleaned_data)
print(df_manual.head())
```

## 3. The Professional Standard: `pd.json_normalize()`
When dealing with complex, highly nested JSON, manual iteration becomes tedious. Pandas provides a powerful utility function called `json_normalize()` designed specifically to flatten semi-structured JSON data into a flat table.

It handles nested dictionaries automatically by concatenating the keys with a dot (e.g., `location.city`).

### Basic Normalization
``` python
# Flattens dictionaries automatically, but leaves nested lists untouched
df_basic = pd.json_normalize(api_response['data'])
# Resulting columns: customer_id, name, orders, location.city, location.state
```

### Advanced Normalization: Unpacking Nested Lists
To completely flatten the data so that every individual order gets its own row (while retaining the customer's top-level information), we use the `record_path` and `meta` arguments.

* `record_path`: The path to the nested list you want to explode into individual rows (e.g., 'orders').
* `meta`: The higher-level fields you want to duplicate alongside each new row (e.g., 'customer_id', and nested fields like ['location', 'city']).

``` python
# Deep flattening: Exploding orders while keeping customer context
df_flat = pd.json_normalize(
    api_response['data'], 
    record_path='orders', 
    meta=[
        'customer_id', 
        'name', 
        ['location', 'city'] # How to target a nested dictionary for metadata
    ],
    errors='ignore' # Prevents crashes if a record is missing a meta key
)

# Renaming columns for standardisation before exporting or database insertion
df_flat.rename(columns={
    'location.city': 'city',
    'amount': 'order_amount'
}, inplace=True)

# Reordering columns for readability
df_flat = df_flat[['customer_id', 'name', 'city', 'order_id', 'order_amount']]
```

## 4. Handling Deeply Nested JSON in VS Code / Jupyter Lab
When building your extraction scripts in VS Code or Jupyter, dealing with massive API payloads can be overwhelming. 

**Pro-Tip for Workflow:**
1. Do not try to write the normalization logic immediately.
2. Dump the first API response to a local JSON file using Python's built-in `json` library.
3. Open the file in your IDE. VS Code has native JSON formatting (Shift + Alt + F) that allows you to collapse and expand branches.
4. Visually identify your `record_path` (the list of items) and your `meta` keys (the parent information) before writing the Pandas code.

``` python
import json

# Saving a sample response to inspect the structure visually
with open('sample_response.json', 'w') as f:
    json.dump(api_response, f, indent=4)
```
