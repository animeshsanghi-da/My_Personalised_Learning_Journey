# API Authentication and Headers: Securing Your Data Extraction

## Introduction
While public APIs are great for practice, real-world business data is locked behind authentication walls. Whether you are pulling customer records from a CRM, financial metrics from a payment gateway, or e-commerce data for an end-to-end analysis, you must prove your identity to the server. 

In this module, we will explore how to securely access restricted endpoints using custom headers, API keys, and Bearer tokens. Crucially, we will also implement environment variables to ensure your private credentials never accidentally end up in your public `animeshsanghi-da` GitHub repositories.

---

## 1. Understanding HTTP Headers
Headers are hidden dictionaries of metadata sent alongside your HTTP requests and responses. They tell the server what kind of data you expect, what software you are using, and, most importantly, who you are.

Often, APIs require a custom `User-Agent` header so the server knows the request is coming from a legitimate script rather than a malicious bot.

``` python
import requests

url = "https://api.example-business.com/v1/market-data"

# Defining custom headers as a Python dictionary
headers = {
    "User-Agent": "DataAnalyticsBot/1.0",
    "Accept": "application/json"
}

response = requests.get(url, headers=headers)
print(response.status_code)
```

## 2. Authenticating with API Keys
An API key is a unique string of characters provided by a service to track and control how the API is being used. Depending on the API's documentation, this key is usually passed in one of two ways:

### Method A: As a Query Parameter
Some APIs expect the key directly in the URL parameters.

``` python
url = "https://api.weather-data.com/v1/current"
params = {
    "location": "Indore",
    "apikey": "YOUR_SECRET_API_KEY"
}

response = requests.get(url, params=params)
```

### Method B: Inside the Headers (More Secure)
Passing the key in the headers is preferred for business applications because URLs (and their parameters) are often logged by servers, which could expose your key.

``` python
url = "https://api.enterprise-data.com/v2/sales"
headers = {
    "x-api-key": "YOUR_SECRET_API_KEY"
}

response = requests.get(url, headers=headers)
```

---

## 3. Authenticating with Bearer Tokens (OAuth)
For highly secure services, you will often use Bearer tokens. These are long, cryptographic strings usually generated dynamically or provided by an OAuth 2.0 authorization flow. 

Bearer tokens are strictly passed via the `Authorization` header.

``` python
url = "https://api.secure-platform.com/v3/customer-profiles"
token = "eyJhbGciOiJIUzI1NiIsInR5c..." # Truncated for example

headers = {
    "Authorization": f"Bearer {token}",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)

if response.status_code == 200:
    data = response.json()
    # Ready to flatten and analyse in Pandas
else:
    print(f"Failed to authenticate: {response.status_code}")
```

## 4. Securing Credentials with Environment Variables
Hardcoding API keys directly into your Jupyter Notebooks or Python scripts is a massive security risk. If you push that code to version control, anyone can steal your credentials. 

To solve this, we use environment variables. This keeps your code public but your keys private on your local Windows machine.

### Step 1: Install `python-dotenv`
Open your VS Code terminal and install the library:
``` bash
pip install python-dotenv
```

### Step 2: Create a `.env` file
In the root directory of your project, create a file simply named `.env`. Add your credentials here:
``` text
# Inside .env file
API_KEY=super_secret_key_12345
BEARER_TOKEN=eyJhbGciOiJIUzI1Ni...
```

### Step 3: Create a `.gitignore` file
Immediately create a `.gitignore` file in the same directory and add `.env` to it. This ensures Git will never track or upload your keys.
``` text
# Inside .gitignore file
.env
__pycache__/
*.ipynb_checkpoints/
```

### Step 4: Load the variables in your script
Now, use the `os` and `dotenv` libraries to securely pull those keys into your script memory at runtime.

``` python
import os
import requests
from dotenv import load_dotenv

# Load the hidden variables from the .env file
load_dotenv()

# Retrieve the key securely
API_KEY = os.getenv("API_KEY")

url = "https://api.enterprise-data.com/v2/sales"
headers = {
    "Authorization": f"Bearer {API_KEY}"
}

response = requests.get(url, headers=headers)
data = response.json()

print("Data extracted securely and ready to analyse!")
```
