## 1. The Business Problem & Data Structure

The objective is to ingest raw user data, clean it, and build two core social media features: "People You May Know" and "Pages You Might Like".

The raw data is provided in JSON format and contains three main components:
- **Users:** Each user has an ID, a name, a list of friend IDs, and a list of liked page IDs. 
- **Pages:** Each page has a unique ID and a name.
- **Connections:** The relational mapping between users, friends, and pages.

**Sample Raw Data (`codebook_data.json`):**

## 2. Task 1: Data Cleaning and Preprocessing

Real-world data is rarely perfect. Looking at our sample dataset, we can identify several issues:
1. User ID 3 has an empty name string. 
2. User ID 4 has duplicate entries in their friends list.
3. User ID 5 is an inactive user with zero friends and zero liked pages.
4. The pages list contains duplicate Page IDs (ID 104 is listed twice).

Let's write a Python script to ingest the JSON and clean these anomalies.

```Python
import json

def load_data(filename):
    with open(filename, "r") as file:
        return json.load(file)

def clean_data(data):
    # 1. Remove users with missing names (using list comprehension & strip)
    data["users"] = [user for user in data["users"] if user["name"].strip()]
    
    # 2. Remove duplicate friends (converting list to a set and back to a list)
    for user in data["users"]:
        user["friends"] = list(set(user["friends"]))
        
    # 3. Remove inactive users (must have either friends OR liked pages)
    data["users"] = [user for user in data["users"] if user["friends"] or user["liked_pages"]]
    
    # 4. Remove duplicate pages using a dictionary (keys must be unique)
    unique_pages = {}
    for page in data["pages"]:
        unique_pages[page["id"]] = page
    data["pages"] = list(unique_pages.values())
    
    return data

# Execution
raw_data = load_data("codebook_data.json")
cleaned_data = clean_data(raw_data)

# Save the cleaned data
with open("cleaned_codebook_data.json", "w") as file:
    json.dump(cleaned_data, file, indent=4)
    
print("Data cleaned successfully!")
```

## 3. Task 2: Building "People You May Know"

Now that our data is structured, we can build a friend recommendation engine.

**The Algorithm Logic:** If User A and User B are not direct friends, but they share mutual friends, we should suggest User B to User A. The priority of the recommendation increases with the number of mutual friends they share.

```Python
def find_people_you_may_know(user_id, data):
    # Map user IDs to a set of their friends for O(1) lookup speeds
    user_friends = {user["id"]: set(user["friends"]) for user in data["users"]}
    
    if user_id not in user_friends:
        return []
        
    direct_friends = user_friends[user_id]
    suggestions = {}
    
    # Loop through the user's direct friends
    for friend in direct_friends:
        # Loop through the friends of those friends (mutual connections)
        for mutual in user_friends[friend]:
            # Ensure the mutual friend isn't the user themselves, and isn't already a direct friend
            if mutual != user_id and mutual not in direct_friends:
                # Tally the mutual connections
                suggestions[mutual] = suggestions.get(mutual, 0) + 1
                
    # Sort suggestions by the highest count of mutual friends
    sorted_suggestions = sorted(suggestions.items(), key=lambda x: x[1], reverse=True)
    
    # Return just the recommended User IDs
    return [uid for uid, score in sorted_suggestions]

# Test the recommendation for Amit (ID: 1)
recommendations = find_people_you_may_know(1, cleaned_data)
print(f"People You May Know for Amit (ID 1): {recommendations}")
```

_Output: `People You May Know for Amit (ID 1): [4]`_. Amit should connect with Sara!.

## 4. Task 3: Building "Pages You Might Like"

The final feature is a content recommendation engine using **collaborative filtering**.

**The Algorithm Logic:** If two users like similar pages, they likely share common interests. We can recommend pages liked by User B to User A, scoring the recommendation based on how many overlapping pages the two users share.


```Python
def find_pages_you_might_like(user_id, data):
    # Map user IDs to a set of their liked pages
    user_pages = {user["id"]: set(user["liked_pages"]) for user in data["users"]}
    
    if user_id not in user_pages:
        return []
        
    user_liked_pages = user_pages[user_id]
    page_suggestions = {}
    
    # Compare against every other user in the network
    for other_user, pages in user_pages.items():
        if other_user != user_id:
            # Find the overlapping pages between the two users
            shared_pages = user_liked_pages.intersection(pages)
            
            # If they share interests, suggest their other liked pages
            for page in pages:
                if page not in user_liked_pages:
                    # The score is the number of shared pages they have in common
                    page_suggestions[page] = page_suggestions.get(page, 0) + len(shared_pages)
                    
    # Sort recommended pages based on the similarity score
    sorted_pages = sorted(page_suggestions.items(), key=lambda x: x[1], reverse=True)
    
    # Return the recommended Page IDs
    return [pid for pid, score in sorted_pages]

# Test the page recommendation for Amit (ID: 1)
page_recs = find_pages_you_might_like(1, cleaned_data)
print(f"Pages You Might Like for Amit (ID 1): {page_recs}")
```

_Output: `Pages You Might Like for Amit (ID 1): [103]`_. This suggests Amit might be interested in the "AI & ML Community" page.
