# Lists and Tuples: Ordered Data Structures in Python

## Overview
In Python, **Lists** and **Tuples** are built-in data structures used to store collections of items. While they share many similarities—such as being **ordered** and allowing duplicate values—they have one major difference: **Lists are mutable** (can be changed), whereas **Tuples are immutable** (cannot be changed after creation).

---

## 1. Python Lists
A list is a container used to store a sequence of various data types. Lists are defined by enclosing elements in square brackets `[]`.

### Creating and Indexing Lists
Lists maintain the order of elements, and each element can be accessed using its index (starting from `0`).

```python
# Creating an empty list
empty_list = []

# Creating a list of a single value
fruit_list = ["Apple"]

# Creating a list of various data types
mixed_list = ["Apple", 3.14, 42, True]

# Accessing elements via indexing (using the mixed_list)
print(mixed_list[0])   # Output: Apple
print(mixed_list[2])   # Output: 42

# Negative indexing starts from the end
print(mixed_list[-1])  # Output: True
```

### List Slicing
You can extract a sub-list (a slice) using the syntax `list[start:stop:step]`.

```python
friends = ["Animesh", "Rohan", "Sam", "Akash", "Divya"]

print(friends[0:3])    # Output: ['Animesh', 'Rohan', 'Sam'] (index 3 is excluded)
print(friends[1:])     # Output: ['Rohan', 'Sam', 'Akash', 'Divya']
print(friends[::-1])   # Output: ['Divya', 'Akash', 'Sam', 'Rohan', 'Animesh'] (Reverses the list)
```

### List Methods
Because lists are mutable, Python provides numerous built-in methods to modify them in place.

```python
n = [1, 8, 7]
```
- ADDING ELEMENTS
```python
# 1. append(value): Adds an element to the end of the list
n.append(45)        # List becomes: [1, 8, 7, 45]

# 2. extend(iterable): Adds all elements from an iterable to the end.
m = [2, 21, 15]
n.extend(m)         # List becomes: [1, 8, 7, 45, 2, 21, 15]

# 3. insert(index, value): Inserts a value at the specified index
n.insert(2, 333)    # List becomes: [1, 8, 333, 7, 45, 2, 21, 15]
```
- REMOVING
```python
# 4. remove(value): Removes the first occurrence of the specified value
n.remove(21)            # List becomes: [1, 8, 333, 7, 45, 2, 15]

# 5. pop(index): Removes and returns the element at the given index. 
# If no index is provided, it removes the last element.
popped_val = n.pop(2)   # Returns: 333. List becomes: [1, 8, 7, 45, 2, 15]

# 6. clear(): Removes ALL elements from the list. (Takes no arguments)
n.clear()               # List becomes: []
```
- MANAGING
```python
n = [1, 8, 7, 2, 21, 15, 45]
# 7. sort(): Sorts the list in ascending order
n.sort()            # List becomes: [1, 2, 7, 8, 15, 21, 45]

# 8. reverse(): Reverses the elements of the list
n.reverse()         # List becomes: [45, 21, 15, 8, 7, 2, 1]

# 9. copy(): Returns a shallow copy of the list. (Takes no arguments)
new_n = n.copy()    # new_n is now: [45, 21, 15, 8, 7, 2, 1]
```
- INDEX, COUNT, and LEN
```python
# 10. index(value): Returns the index of the first matched item
index_of_seven = n.index(7)     # Returns: 4 (Because 7 is at the 4th index in our reversed list)

# 11. count(value): Returns the number of times the specified value appears
count_of_fifteen = n.count(15)  # Returns: 1
```

### Advanced List Concepts

#### Membership Testing
Before searching or removing elements, you can safely check if an item exists inside a list using the `in` and `not in` operators. This returns a boolean value (`True` or `False`).
```Python
names = ["Animesh", "Sam", "Rohan"]

print("Sam" in names)       # Output: True
print("Akash" not in names) # Output: True
```

#### List Comprehensions
List comprehensions provide a shorter, more readable syntax when you want to create a new list based on the values of an existing list.
> **Syntax:** `[expression for item in iterable if condition]`
```Python
# Traditional way using a loop
squares = []
for x in range(1, 6):
    squares.append(x ** 2)
# squares becomes: [1, 4, 9, 16, 25]

# Elegant way using List Comprehension
squares = [x ** 2 for x in range(1, 6)] 
# Output: [1, 4, 9, 16, 25]

# Filtering with conditions (e.g., keeping only even numbers)
evens = [n for n in range(10) if n % 2 == 0]
# Output: [0, 2, 4, 6, 8]
```

### Interoperating with Strings

#### Splitting a String into a List
The `.split()` method is a **string method** that splits a single string into a list of substrings based on a specified delimiter (separator). If no delimiter is specified, it defaults to splitting by spaces.
```Python
s = "Animesh-Rahul-Harry-Rohan-Sohan"
names_list = s.split("-")

print(names_list)
# Output: ['Animesh', 'Rahul', 'Harry', 'Rohan', 'Sohan']
```

#### Joining a List into a String (The Reverse)
The `.join()` method is another **string method** that takes a list of strings and pieces them back together into a single string, using the host string as the connector.
```Python
words = ["Python", "is", "awesome"]

# Join using a single space as a separator
sentence = " ".join(words)
print(sentence) 
# Output: Python is awesome

# Join using a hyphen
hyphenated = "-".join(words)
print(hyphenated) 
# Output: Python-is-awesome
```

## 2. Python Tuples
A tuple is an immutable data type in Python. Once a tuple is defined, you cannot alter, add, or remove items from it. Tuples are defined using parentheses `()`.

### Creating Tuples
```python
# Creating an empty tuple
empty_tuple = ()

# Creating a tuple with multiple elements
my_tuple = (1, 7, 2)

# Implied tuple (parentheses are actually optional here, but recommended for clarity)
implied_tuple = 1, 7, 2

# IMPORTANT: Creating a tuple with a single element requires a trailing comma
single_tuple = (1,)  # Correct
not_a_tuple = (1)    # Incorrect, Python treats this as an integer
```

### Why use Tuples?
* **Safety:** If you have data that should *never* change during the execution of your program (e.g., days of the week, fixed coordinates), use a tuple.
* **Performance:** Tuples are slightly faster and more memory-efficient than lists.
* **Dictionary Keys:** Because tuples are immutable, they are **hashable**. This means a tuple can be used as a key in a dictionary, whereas a list cannot.

### Tuple Methods
Since tuples cannot be modified, they only have two standard built-in methods:

```python
t = (1, 2, 4, 2, 3, 2, 5)

# 1. count(value): Returns the number of times a value occurs in the tuple
print(t.count(2))  # Output: 3

# 2. index(value): Returns the index of the first occurrence of the specified value
print(t.index(4))  # Output: 2
```

### Tuple Packing and Unpacking
Packing is gathering multiple values into a single tuple. Unpacking extracts those values back into variables.
```Python
# Packing
person = ("Animesh", 25, "Data Analyst")

# Standard Unpacking
name, age, profession = person
print(name)      # Output: Animesh

# Extended Unpacking (Using the * operator for leftover elements)
numbers = (1, 2, 3, 4, 5)
first, *middle, last = numbers

print(first)   # Output: 1
print(middle)  # Output: [2, 3, 4]  <- Captures the rest as a list!
print(last)    # Output: 5
```

### The Ultimate Tuple "Gotcha": Mutability Within Immutability
**Warning:** While the tuple _itself_ is immutable, if it contains a **mutable object** (like a list), that inner object can still be modified!
```Python
# A tuple containing a mutable list
treacherous_tuple = (1, 2, [3, 4])

# This will raise a TypeError:
# treacherous_tuple[0] = 99 

# This works perfectly fine!
treacherous_tuple[2].append(5)

print(treacherous_tuple)  # Output: (1, 2, [3, 4, 5])
```

## 3. Lists vs. Tuples Summary

| Feature | Lists | Tuples |
| :--- | :--- | :--- |
| **Syntax** | `[]` | `()` |
| **Mutability** | Mutable (can be changed) | Immutable (cannot be changed) |
| **Memory** | Consumes more memory | More memory efficient |
| **Methods** | Many (`append`, `remove`, etc.) | Few (`count`, `index`) |
| **Use Case** | Dynamic collections of items | Fixed, read-only collections |
