# Regular Expressions (Regex): Advanced Text Pattern Matching

## Introduction
While standard Python string methods (`.split()`, `.replace()`) are useful, they often fall short when dealing with highly unstructured text. Regular Expressions (Regex) provide a powerful syntax for finding, extracting, and replacing complex string patterns. Whether you are parsing server logs, extracting patient IDs in a healthcare ETL script, or cleaning messy product descriptions in e-commerce datasets, Regex is a mandatory skill for advanced data cleaning.

---

## 1. The `re` Module in Python
Python's built-in `re` module allows you to compile and match regular expressions.

```python
import re

# Example: Finding all numbers in a messy string
text = "Revenue for Q3 was $45,000 and Q4 was $52,000."
pattern = r'\d+' # \d matches digits, + matches one or more
numbers = re.findall(pattern, text)
print(numbers) # Output: ['3', '45', '000', '4', '52', '000']
```

*Note: Always use raw strings (`r'pattern'`) for regex in Python to prevent backslashes from being treated as escape characters.*

---

## 2. Core Regex Metacharacters
To build patterns, you need to understand the structural building blocks of Regex:

* `.` : Matches any single character (except newline).
* `\d` : Matches any digit (0-9).
* `\D` : Matches any non-digit.
* `\w` : Matches any alphanumeric character (a-z, A-Z, 0-9, and underscore).
* `\W` : Matches any non-alphanumeric character (e.g., punctuation).
* `\s` : Matches any whitespace (space, tab, newline).
* `\S` : Matches any non-whitespace.
* `+` : Matches 1 or more occurrences of the preceding pattern.
* `*` : Matches 0 or more occurrences.
* `?` : Matches 0 or 1 occurrence (makes the preceding character optional).
* `^` : Matches the start of a string.
* `$` : Matches the end of a string.
* `[]` : Matches any single character within the brackets (e.g., `[aeiou]` matches any vowel).

## 3. Essential `re` Functions for Analysts

### A. `re.search()`
Finds the *first* location where the pattern produces a match.

```python
log_entry = "ERROR 404: Page not found at /products/item-123"
match = re.search(r'ERROR \d{3}', log_entry)

if match:
    print("Found:", match.group()) # Output: ERROR 404
```

### B. `re.sub()`
Substitutes occurrences of a pattern with a replacement string (excellent for data sanitization).

```python
phone_number = "(555) 123-4567"
# Remove everything that is NOT a digit
clean_number = re.sub(r'\D', '', phone_number)
print(clean_number) # Output: 5551234567
```

## 4. Integrating Regex with Pandas
When working in Jupyter Lab or VS Code, you will rarely apply regex to a single string; instead, you will apply it across entire Pandas DataFrames. Pandas string methods (`.str`) have built-in regex support.

### Extracting Data
Imagine a dataset with a mixed column of order IDs and statuses.

```python
import pandas as pd

data = {'raw_data': ['Order#12345_Shipped', 'Order#9876_Pending', 'Invalid_Entry']}
df = pd.DataFrame(data)

# Extract just the numeric Order ID into a new column
df['order_id'] = df['raw_data'].str.extract(r'#(\d+)')
print(df)
```

### Filtering Data with `.str.contains()`
You can filter datasets based on complex text patterns.

```python
# Keep only rows where the text contains 'Shipped' or 'Pending' (case-insensitive)
valid_orders = df[df['raw_data'].str.contains(r'Shipped|Pending', flags=re.IGNORECASE)]
```

## 5. Applied Business Use Cases

### Scenario A: Parsing E-Commerce Data
When handling large datasets (like Brazilian e-commerce records), text fields often contain messy formatting.
* **Goal:** Extract zip codes that must be exactly 5 digits.
* **Pattern:** `r'^\d{5}$'` (Ensures the string starts and ends with exactly 5 digits).

### Scenario B: Healthcare Data Extraction
When building an ETL pipeline to push healthcare metrics to a MySQL database, you may need to validate and extract specific patient or diagnosis codes.
* **Goal:** Extract medical codes that start with a letter followed by 2-3 digits (e.g., "A12", "B345").
* **Pattern:** `r'[A-Z]\d{2,3}'`

## 6. Best Practices and Testing
Regex can quickly become difficult to read. 
1.  **Start Simple:** Build your pattern piece by piece.
2.  **Comment Complex Patterns:** Use `re.VERBOSE` flag to allow spaces and comments inside your regex string.
3.  **Test Iteratively:** Always test your patterns on a small subset of data in your notebook before running them over a 100,000+ row dataset. 

Regex is the bridge between raw, unstructured text and clean, structured data ready for statistical summaries and visualisation.
