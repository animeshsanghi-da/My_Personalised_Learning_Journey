# API Development with Flask and `jsonify`

## Overview
In modern data architecture, serving analytical results, metrics, or machine learning predictions directly to user interfaces requires building lightweight, programmable interfaces. A **RESTful API (Application Programming Interface)** acts as a standardized data contract between your computational backend and external systems. Flask enables data analysts to package Python structures (lists, dictionaries, Pandas DataFrames) into secure HTTP endpoints that exchange data using the industry-standard **JSON (JavaScript Object Notation)** text payload format.

---

## 1. Why `jsonify` Over `json.dumps`?
While Python's native `json.dumps()` serializes a dictionary into a raw JSON string, it does not manage the web communication transport headers. Flask's built-in `jsonify()` utility provides crucial enhancements:
* **MIME-Type Configuration:** It automatically sets the HTTP response header `Content-Type: application/json`. Without this, the consuming client browser treats the response as plain text, requiring manual parsing.
* **HTTP Status Code Binding:** It seamlessly pairs your serialized data structure with relevant server tracking codes (e.g., `200 OK`, `400 Bad Request`, `500 Internal Server Error`).
* **Argument Mapping:** It allows you to pass explicit key-value parameters directly into the function call to form an instant JSON object structure without pre-defining an explicit Python dictionary structure.

---

## 2. API Design Patterns: HTTP Methods for Data Science
An enterprise data API matches incoming user intents to explicit network transport behaviors:
* **GET Requests:** Used to fetch descriptive lookup matrices, summary analytics, pre-computed key performance indicators (KPIs), or target system status. Parameters are appended to the URL query string.
* **POST Requests:** Used to submit secure input payloads to the server (e.g., real-time transaction features or candidate user metrics). The data travels hidden inside the HTTP request body, enabling models to perform real-time pipeline scoring and return structural predictions.

---

## 3. End-to-End Production Blueprint: Serving Analytics & Routing Engines

Below is a production-grade backend API (`server.py`) that implements a `GET` endpoint for tabular statistical summaries and a `POST` endpoint to handle runtime user profiling.

```python
from flask import Flask, jsonify, request
import pandas as pd
import numpy as np

app = Flask(__name__)

# Mock database load mirroring analytics frameworks (e.g., "Coders of Delhi" platform ledger)
raw_engagement_data = {
    "developer_id": [1001, 1002, 1003, 1004],
    "experience_years": [2, 5, 8, 1],
    "commits_count": [140, 450, 890, 30],
    "preferred_stack": ["Python", "JavaScript", "Python", "Java"]
}
df_analytics = pd.DataFrame(raw_engagement_data)

@app.route('/api/v1/metrics/summary', methods=['GET'])
def get_analytical_summary():
    """
    GET Endpoint: Computes descriptive statistical aggregations on runtime records 
    and streams them to downstream user interfaces or business reports.
    """
    try:
        # Generate summary stats and convert to native Python types for JSON serialization compatibility
        total_developers = int(df_analytics['developer_id'].count())
        mean_commits = float(df_analytics['commits_count'].mean())
        top_stack = str(df_analytics['preferred_stack'].mode()[0])
        
        # Build structural tracking payload using direct arguments inside jsonify
        return jsonify(
            status="success",
            data={
                "total_records": total_developers,
                "average_commits": round(mean_commits, 2),
                "dominant_technology": top_stack
            }
        ), 200
        
    except Exception as e:
        return jsonify(status="error", message=str(e)), 500


@app.route('/api/v1/recommend/engine', methods=['POST'])
def run_conditional_routing_engine():
    """
    POST Endpoint: Consumes complex incoming client parameter JSON objects,
    validates fields, runs recommendation logic, and transmits a JSON response.
    """
    # Parse the client-side JSON body block cleanly
    client_payload = request.get_json()
    
    if not client_payload or 'experience_years' not in client_payload or 'primary_skill' not in client_payload:
        return jsonify(
            status="fail", 
            message="Malformed Request Body. Required attributes: 'experience_years' and 'primary_skill'."
        ), 400
        
    try:
        user_exp = float(client_payload['experience_years'])
        user_skill = str(client_payload['primary_skill']).strip().lower()
        
        # Deterministic pipeline routing engine execution (Business/System logic thresholds)
        if user_skill == "python" and user_exp >= 5:
            assigned_tier = "Senior PyData Engineer"
            recommended_learning_track = "LLM Architecture & Distributed Systems"
        elif user_skill == "python" and user_exp < 5:
            assigned_tier = "Junior Python Analyst"
            recommended_learning_track = "Pandas Wrangling & Advanced Database Connectivity"
        else:
            assigned_tier = "General Analytics Track"
            recommended_learning_track = "Foundations of Structured Decision Trees"
            
        # Return structured data response package back upstream
        return jsonify(
            status="success",
            evaluation={
                "inferred_tier": assigned_tier,
                "suggested_curriculum": recommended_learning_track,
                "routing_latency_status": "optimal"
            }
        ), 200
        
    except ValueError:
        return jsonify(status="error", message="Invalid data types provided in input features."), 422
    except Exception as e:
        return jsonify(status="error", message=f"Pipeline Error: {str(e)}"), 500

if __name__ == '__main__':
    # Start web container instance inside local isolated sandbox interface
    app.run(host='127.0.0.1', port=5000, debug=True)
```

## 4. Validating and Consuming the API Programmatically
To ensure your data services integrate correctly within automated ingestion systems, verify data contracts using Python's micro-client `requests` tool:

```python
import requests

# 1. Querying the Aggregated Metrics GET Service
get_response = requests.get('http://127.0.0.1:5000/api/v1/metrics/summary')
print("GET Summary Output Data Layout:")
print(get_response.json())

# 2. Transmitting Features to the POST Conditional Recommendation Router
candidate_features = {
    "experience_years": 6.5,
    "primary_skill": "Python"
}
post_response = requests.post(
    'http://127.0.0.1:5000/api/v1/recommend/engine', 
    json=candidate_features
)
print("\nPOST Engine Prediction Routing Data Layout:")
print(post_response.json())
```
