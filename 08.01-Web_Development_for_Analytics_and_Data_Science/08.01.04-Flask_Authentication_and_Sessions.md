# Securing Flask: Authentication and User Sessions

## Introduction
When transitioning from local Jupyter Lab or VS Code environments to a deployed web application, security becomes a critical priority. Whether you are building an API to serve a predictive machine learning model or a dashboard visualising complex healthcare ETL pipelines, you cannot expose proprietary business metrics to the public internet. 

This module covers how to implement user sessions and route protection in Flask, ensuring that only authorized stakeholders (like business managers or fellow data professionals) can access your data applications.

---

## 1. Core Security Concepts in Flask

Before writing code, it is important to understand the mechanics of web authentication:

* **Statelessness of HTTP:** Every time a user requests a web page, the server treats it as a brand-new interaction. The server does not naturally "remember" that a user just logged in.
* **Sessions:** Flask solves this using `session` objects. A session securely stores information (like a logged-in status) in a cryptographic cookie on the user's browser. When the user requests the next page, the browser sends this cookie, and Flask instantly recognises the authenticated user.
* **Password Hashing:** Storing raw passwords in a database is a critical security flaw. We use hashing algorithms (via `werkzeug.security`) to scramble passwords into irreversible strings.

---

## 2. The `@login_required` Decorator

In Python, a **decorator** is a function that wraps another function to modify its behaviour. In Flask, decorators are essential for authentication. By creating a custom `@login_required` decorator, we can seamlessly protect any route (like an e-commerce data dashboard) just by adding one line of code above the route definition.

---

## 3. Code Implementation

Below is a robust blueprint for an authenticated Flask application. Create an `app.py` file in your project directory and study the structure. 

*(Note: We are using a mock dictionary as a database here, but in a production environment, you would query this from MySQL or a similar relational database).*

```python
from flask import Flask, request, redirect, session, url_for, jsonify
from werkzeug.security import generate_password_hash, check_password_hash
from functools import wraps
import os

app = Flask(__name__)
# Secret key is required to cryptographically sign session cookies
app.secret_key = os.urandom(24) 

# Mock database simulating user credentials for a BI portal
# Username: 'admin', Password: 'password123'
users_db = {
    "admin": generate_password_hash("password123")
}

# -----------------------------------------
# The Security Decorator
# -----------------------------------------
def login_required(f):
    @wraps(f)
    def decorated_function(*args, **kwargs):
        # Check if the user's session exists and is flagged as logged in
        if 'logged_in' not in session:
            return jsonify({"error": "Unauthorized access. Please log in first."}), 401
        return f(*args, **kwargs)
    return decorated_function

# -----------------------------------------
# Authentication Routes
# -----------------------------------------
@app.route('/login', methods=['POST'])
def login():
    # In a real app, data comes from request.form or JSON payload
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')
    
    # 1. Check if user exists
    # 2. Verify the hashed password against the provided password
    if username in users_db and check_password_hash(users_db[username], password):
        # Create the session
        session['logged_in'] = True
        session['username'] = username
        return jsonify({"message": f"Welcome back, {username}. Authentication successful."}), 200
    else:
        return jsonify({"error": "Invalid credentials."}), 401

@app.route('/logout', methods=['POST'])
def logout():
    # Destroy the session data
    session.clear()
    return jsonify({"message": "Successfully logged out."}), 200

# -----------------------------------------
# Secured Business Routes
# -----------------------------------------
@app.route('/api/v1/sales-data', methods=['GET'])
@login_required  # <-- This single line protects the entire function
def get_sales_data():
    # This block will ONLY execute if the session is valid
    secure_data = {
        "status": "success",
        "requested_by": session['username'],
        "metrics": {
            "monthly_recurring_revenue": "$45,000",
            "active_users": 1250
        }
    }
    return jsonify(secure_data), 200

if __name__ == '__main__':
    app.run(debug=True)
```
