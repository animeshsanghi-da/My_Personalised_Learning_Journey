# Extracting and Transforming Data with Python

## 1. The 'E': Extracting Data efficiently

Extraction is about getting data out of a source system without overwhelming your local memory (RAM) or the source server.

### A. Extracting from APIs (Application Programming Interfaces)
Many business tools (CRMs, financial software, government databases) expose data via APIs. The `requests` library is the industry standard for this.

```python
import requests
import pandas as pd

# Define the API endpoint and headers (if authentication is needed)
url = "https://api.example-business-data.com/v1/sales"
headers = {"Authorization": "Bearer YOUR_API_TOKEN"}

# Make the GET request
response = requests.get(url, headers=headers)

# Check if the request was successful (Status Code 200)
if response.status_code == 200:
    data = response.json() # Parse JSON response into a Python dictionary
    
    # Extract the nested data into a Pandas DataFrame
    # Assuming the actual records are inside a 'results' key
    df_raw = pd.json_normalize(data['results']) 
    print("Data extracted successfully!")
else:
    print(f"Failed to extract data. Status Code: {response.status_code}")
```

### B. Extracting Large Flat Files (Chunking)
When dealing with massive datasets (e.g., millions of rows of healthcare records or e-commerce logs), `pd.read_csv()` will crash if it exceeds your system's memory. The solution is **chunking**—processing the data in bite-sized pieces.

```python
# Process a 5GB CSV file 50,000 rows at a time
chunk_size = 50000
processed_chunks = []

for chunk in pd.read_csv("massive_dataset.csv", chunksize=chunk_size):
    # Perform preliminary filtering to reduce memory immediately
    filtered_chunk = chunk[chunk['status'] == 'Active']
    
    # Append the smaller, filtered chunk to our list
    processed_chunks.append(filtered_chunk)

# Concatenate the filtered chunks back into a single DataFrame
df_final = pd.concat(processed_chunks, ignore_index=True)
```

## 2. Handling Memory Efficiently (Data Typing)

Pandas defaults to memory-heavy data types (like `int64` and `float64`). Before applying complex transformations, optimizing your DataFrames is a critical best practice that separates junior analysts from senior professionals.

```python
def optimize_memory(df):
    """Reduces memory usage by downcasting numerical types and converting strings to categories."""
    for col in df.columns:
        col_type = df[col].dtype
        
        if col_type != object:
            # Downcast numeric types
            if str(col_type)[:3] == 'int':
                df[col] = pd.to_numeric(df[col], downcast='integer')
            elif str(col_type)[:5] == 'float':
                df[col] = pd.to_numeric(df[col], downcast='float')
        else:
            # Convert low-cardinality string columns to categorical
            num_unique_values = len(df[col].unique())
            num_total_values = len(df[col])
            if num_unique_values / num_total_values < 0.5:
                df[col] = df[col].astype('category')
                
    return df

df_optimized = optimize_memory(df_final)
```

## 3. The 'T': Complex Transformations with Pandas

Transformation involves applying business logic to the raw data. This prepares the dataset for the final 'Load' phase into a MySQL database or a BI tool like Tableau/Power BI.

### A. Vectorized Conditional Logic
Avoid iterating through rows (like using `iterrows()`). Instead, use NumPy's `where` or `select` for lightning-fast conditional transformations.

```python
import numpy as np

# Create a complex business segmentation based on multiple conditions
conditions = [
    (df_optimized['purchase_amount'] > 1000) & (df_optimized['loyalty_years'] >= 3),
    (df_optimized['purchase_amount'] > 500) & (df_optimized['loyalty_years'] < 3),
    (df_optimized['purchase_amount'] <= 500)
]

choices = ['Platinum_Tier', 'Gold_Tier', 'Silver_Tier']

# Apply conditions
df_optimized['customer_segment'] = np.select(conditions, choices, default='Unknown')
```

### B. Aggregations and Window Functions
Often, you need to transform transactional data into aggregated summaries (e.g., rolling averages or cumulative sums).

```python
# Sort data by date first
df_optimized = df_optimized.sort_values(by=['customer_id', 'transaction_date'])

# Calculate a 3-order rolling average purchase amount per customer
df_optimized['rolling_avg_3_orders'] = (
    df_optimized.groupby('customer_id')['purchase_amount']
    .transform(lambda x: x.rolling(window=3, min_periods=1).mean())
)
```
