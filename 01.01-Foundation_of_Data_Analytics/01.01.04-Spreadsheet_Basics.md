# Spreadsheet Basics: Data Entry, Formatting, and Functions

## Overview
Spreadsheets (such as Microsoft Excel and Google Sheets) are the foundational tools for data analytics. As emphasized in the **Google Data Analytics Professional Certificate**, mastering spreadsheets is essential for the *Prepare*, *Process*, and *Analyse* phases of the data lifecycle. They allow analysts to store, organise, manipulate, and visualise data efficiently.

---

## 1. The Anatomy of a Spreadsheet
Before manipulating data, it is crucial to understand how spreadsheets are structured:
* **Workbook:** The entire file containing one or more spreadsheets.
* **Worksheet (Sheet):** A single tab within a workbook.
* **Columns:** Vertical ranges of data, labeled with letters (A, B, C...). Usually represent **Attributes** or **Variables**.
* **Rows:** Horizontal ranges of data, labeled with numbers (1, 2, 3...). Usually represent individual **Records** or **Observations**.
* **Cell:** The intersection of a row and a column (e.g., `B4`).
> A modern Microsoft Excel worksheet contains **1,048,576 rows (~1 million / 10 lakh)** and **16,384 columns (~16 k)**, giving a total of over 17 billion (1,700 crore) individual cells per sheet

## 2. Data Entry & Best Practices
Clean data analysis starts with proper data entry.
* **Atomic Data:** Each cell should contain only one piece of information (e.g., separate "First Name" and "Last Name" into two columns instead of one "Full Name" column).
* **Headers:** Always use the first row for clear, descriptive column headers. Freeze the top row so headers remain visible when scrolling.
* **Avoid Blank Rows/Columns:** Do not use blank rows or columns to format or separate data, as this breaks sorting, filtering, and pivot tables.
* **Data Validation:** Use data validation rules to restrict what users can enter into a cell (e.g., creating drop-down lists for categories to prevent typos).

#### Cell Referencing Mechanics
Understanding address locking is fundamental to writing reusable, drag-and-drop formulas across columns and rows.
* **Relative Reference (`A1`):** Changes dynamically when copied across rows or columns.
* **Absolute Reference (`$A$1`):** Completely locked. Reference does not change when copied.
* **Mixed Reference (Row Locked) (`A$1`):** Column changes when copied horizontally, but row stays locked at 1 when copied vertically.
* **Mixed Reference (Column Locked) (`$A1`):** Column stays locked at A, but row changes dynamically when copied vertically.

#### Custom Data Validation Rules (Formula-Based)
Beyond simple drop-down lists, custom formulas restrict invalid inputs at the point of data entry:

* **Prevent Duplicate Entries:** Select Range `A2:A100` $\rightarrow$ Data Validation $\rightarrow$ Custom:
```excel
=COUNTIF($A$2:$A$100, A2) <= 1
```

- **Restrict Text to Specific Domain (e.g., Company Emails Only):**
```excel
=ISNUMBER(SEARCH("@company.com", B2))
```

- **Ensure End Date is After Start Date:** Select End Date cell `C2`:
```excel
=C2 > B2
```

## 3. Data Formatting
Formatting changes how data *looks* without changing its underlying *value*. This is vital for readability and accuracy.

### Number Formatting
* **Currency:** Formats numbers with monetary symbols and decimals (e.g., `₹1,200.50`).
* **Percentages:** Multiplies the underlying number by 100 and adds a `%` sign (e.g., `0.25` becomes `25%`).
* **Dates:** Standardizes date formats (e.g., `MM/DD/YYYY` vs `YYYY-MM-DD`). 

### Conditional Formatting
Conditional formatting automatically applies visual styles (colors, bolding, icons) to cells based on their values.
* **Highlighting Outliers:** e.g., Highlight all cells in a "Revenue" column greater than $10,000 in green.
* **Color Scales:** Applies a gradient (e.g., red to green) across a range to visually map low to high values.
* **Finding Duplicates:** Quickly identify duplicate records in a dataset by formatting duplicate values in red.

## 4. Essential Formulas and Functions
A **Formula** is an expression written by the user that calculates a value (e.g., `=A1+B1`). A **Function** is a pre-defined formula built into the spreadsheet software (e.g., `=SUM(A1:B1)`).

### Basic Math & Aggregation
```excel
=SUM(A1:A10)       // Adds all values in the specified range
=AVERAGE(B1:B10)   // Calculates the mathematical mean
=COUNT(C1:C10)     // Counts the number of cells containing numerical data
=COUNTA(D1:D10)    // Counts the number of non-empty cells (includes text)
=MAX(E1:E10)       // Finds the highest value in the range
=MIN(F1:F10)       // Finds the lowest value in the range
```

### Logical Functions
Logical functions allow you to evaluate conditions and make decisions within the dataset.
```excel
=IF(logical_expression, value_if_true, [value_if_false])
// Example: =IF(A2 > 100, "High", "Low")
// Returns "High" if the value in A2 is greater than 100; otherwise, returns "Low".

=IFS(logical_expression1, value_if_true1, [logical_expression2, value_if_true2, ...])
// Example: =IFS(A2 >= 90, "Tier 1", A2 >= 70, "Tier 2", TRUE, "Tier 3")
// Evaluates multiple conditions sequentially and returns the value for the first TRUE condition, using TRUE at the end as a default fallback.

=COUNTIF(range, criterion)
// Example: =COUNTIF(B2:B20, "Completed")
// Counts how many times the word "Completed" appears in the specified range.

=COUNTIFS(criteria_range1, criterion1, [criteria_range2, criterion2], ...)
// Example: =COUNTIFS(B2:B100, "Completed", C2:C100, ">100")
// Counts rows where Status is "Completed" AND Value > 100 (multiple criteria).

=SUMIF(criteria_range, criterion, [sum_range])
// Example: =SUMIF(B2:B100, "Sales", C2:C100)
// Sums values in C if the department in B is "Sales".

=SUMIFS(sum_range, criteria_range1, criterion1, [criteria_range2, criterion2, ...])
// Example: =SUMIFS(C2:C100, B2:B100, "Sales", A2:A100, ">2023-01-01")
// Sums values in range C2:C100 if the department in B2:B100 is "Sales" AND the date in A2:A100 is after Jan 1, 2023.

=AVERAGEIF(range, criteria, [average_range])
// Example: =AVERAGEIF(B2:B20, "Data", C2:C20)
// Calculates the average of values in C2:C20 where the corresponding department in B2:B20 equals "Data".

=AVERAGEIFS(average_range, criteria_range1, criterion1, [criteria_range2, criterion2, ...])
// Example: =AVERAGEIFS(HR[Salary], HR[Department], "Data")
// Calculates the average salary from the HR[Salary] column for rows where the HR[Department] equals "Data".

=IFERROR(value, value_if_error)
// Example: =IFERROR(XLOOKUP(A2, B:B, C:C), "Missing Data")
// Evaluates the formula (XLOOKUP) and returns "Missing Data" if an error (such as #N/A or #VALUE!) occurs.
```

### Lookup and Reference Functions
Used to merge data from different tables or sheets.
```excel
=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])
// Example: =XLOOKUP("E145", A2:A100, C2:C100, "Not Found")
// Searches for employee ID "E145" in range A2:A100.
// When found, it returns the matching value from range C2:C100. "Not Found" is returned if no match exists.

=VLOOKUP(search_key, range, index, [is_sorted])
// Example: =VLOOKUP("E145", A2:D100, 3, FALSE)
// Searches for employee ID "E145" in the first column of range A2:D100. 
// When found, it returns the value in the 3rd column of that row. FALSE ensures an exact match.

=HLOOKUP(search_key, range, row_index, [is_sorted]) 
// Example: =HLOOKUP("Q3_Sales", A1:Z10, 3, FALSE) 
// Searches for "Q3_Sales" horizontally in the first row of range A1:Z10. 
// When found, it returns the value in the 3rd row of that column. FALSE ensures an exact match.

=INDEX(return_range, MATCH(lookup_value, lookup_range, [match_type]))
// Example: =INDEX(C2:C100, MATCH("E145", A2:A100, 0))
// Uses MATCH to find the exact row position of employee ID "E145" in column A (A2:A100), 
// then uses INDEX to retrieve the value from that corresponding row in column C (C2:C100).

// Note: XLOOKUP (in newer Excel versions) or INDEX/MATCH are often preferred over VLOOKUP for better performance and flexibility.
```

### Text Manipulation Functions (Data Cleaning)
These are heavily used in the "Process" (cleaning) phase.
```excel
// Text Formatting & Combination
=CONCATENATE(A2, " ", B2)   // Combines the text from A2 and B2 with a space in between.
=TRIM(C2)                   // Removes leading, trailing, and repeated spaces from text.
=UPPER(D2)                  // Converts text to completely UPPERCASE.
=PROPER(E2)                 // Capitalizes the first letter of each word.

// Basic Text Extraction & Length
=LEFT(F2, 4)       // Extracts the first 4 characters from the left side of a string.
=MID(F2, 3, 5)     // Extracts a specific number of characters (5) 
				// starting at a designated position (3rd character).
=RIGHT(F2, 4)      // Extracts the last 4 characters from the right side of a string.
=LEN(G2)           // Returns the total number of characters in a string.

// Modern Text Extraction (Excel 365 / 2021+)
=TEXTAFTER(F2, "@", 2)      // Dynamically extracts all text occurring after a 
	                    //specific delimiter or character (everything AFTER the 2nd @).
=TEXTBEFORE(F2, "@", -1)    // Dynamically extracts all text occurring BEFORE a
						// specific delimiter (everything BEFORE the last @).

// Dynamic Text Extraction (Classic "LEN Trick")
=RIGHT(A2, LEN(A2) - SEARCH("@", A2))        // The LEN Trick: To dynamically pull everything after a specific point in legacy Excel, analysts combine RIGHT with LEN (total cell length) minus SEARCH/FIND (position of the target character).

// Dynamic Text Extraction (Classic "LEFT + SEARCH") 
=LEFT(A2, SEARCH("@", A2) - 1)               // The Legacy Trick: Finds the character position with SEARCH, subtracts 1 (to exclude the character itself), and pulls from the LEFT.

// Dynamic Text Extraction (Classic "LEN Trick")
=RIGHT(A2, LEN(A2) - SEARCH("@", A2))        // The LEN Trick: To dynamically pull everything after a specific point in legacy Excel, analysts combine RIGHT with LEN (total cell length) minus SEARCH/FIND (position of the target character).
```

### Dynamic Arrays (Modern Data Slicing)
Automatically spills dynamic results across rows without writing repetitive formulas.
```Excel
=UNIQUE(Sales[Category])
// Generates a dynamic, deduplicated list of unique categories.

=FILTER(Sales[Customer], Sales[Amount] > 500, "None")
// Dynamically filters records based on criteria.

=SORT(UNIQUE(Orders[Country]))
// Returns an alphabetized list of unique values.
```

### Date & Time Analytics
Essential for calculating tenure, cohort analysis, and standardizing time periods.
```Excel
// Current Date & Time (Volatile Functions - Recalculate on every sheet change)
=TODAY()           // Returns the current system date (e.g., 2026-08-22). Updates automatically.
=NOW()             // Returns the current system date AND time (e.g., 2026-08-22 10:47 AM).

// Component Extraction (Isolate specific parts of a date or time stamp)
=YEAR(A2)          // Returns the 4-digit year (e.g., 2026) from a date in A2.
=MONTH(A2)         // Returns the month number (1 to 12) from a date in A2.
=DAY(A2)           // Returns the day of the month (1 to 31) from a date in A2.
=WEEKDAY(A2, [return_type]) 
                   // Returns the day of the week as a number (1 = Sun to 7 = Sat by default).
                   // Useful for identifying weekend vs. weekday trends.
=WEEKNUM(A2)       // Returns the week number of the year (1 to 52).

=HOUR(A2)          // Extracts the hour (0 to 23) from a timestamp in A2.
=MINUTE(A2)        // Extracts the minutes (0 to 59) from a timestamp in A2.
=SECOND(A2)        // Extracts the seconds (0 to 59) from a timestamp in A2.

// Date & Time Construction (Building valid dates from separate numeric columns)
=DATE(year, month, day)   
                   // Assembles discrete year, month, and day values into a valid spreadsheet date.
                   // Example: =DATE(2026, 8, 22) -> 2026-08-22
=TIME(hour, minute, second) 
                   // Assembles discrete time components into a valid spreadsheet time value.
                   // Example: =TIME(14, 30, 0) -> 2:30 PM

// Practical Real-World Combinations
=TODAY() - A2      // Calculates elapsed days between date in A2 and today.
=INT(NOW() - A2)   // Calculates exact number of whole days passed since a past timestamp in A2.
=WEEKDAY(TODAY()) = 1 // Logic test returning TRUE if today is Sunday (great for Conditional Formatting).

// EOMONTH: Calculates the LAST day of a month (offset by N months)
=EOMONTH(A2, 0)   // If A2 is 15-Jan-2026 -> Returns 31-Jan-2026 (End of current month)
=EOMONTH(A2, 1)   // If A2 is 15-Jan-2026 -> Returns 28-Feb-2026 (End of NEXT month)
=EOMONTH(A2, -1)  // If A2 is 15-Jan-2026 -> Returns 31-Dec-2025 (End of PREVIOUS month)

// EDATE: Moves N months forward/backward on the EXACT SAME day of the month
=EDATE(A2, -1)    // If A2 is 15-Jan-2026 -> Returns 15-Dec-2025 (1 month back for MoM analysis)
=EDATE(A2, 1)     // If A2 is 15-Jan-2026 -> Returns 15-Feb-2026 (1 month ahead)
=EDATE(A2, -12)   // If A2 is 15-Jan-2026 -> Returns 15-Jan-2025 (12 months back for YoY analysis)

// DATEDIF: Calculates elapsed time between two dates ("Y" = Years, "M" = Months, "D" = Days)
=DATEDIF(A2, TODAY(), "Y")  // If A2 is 15-Jan-2020 -> Returns 6 (Calculates tenure/age in complete years)
=DATEDIF(A2, B2, "M")       // If A2 is 15-Jan-2026 and B2 is 15-Aug-2026 -> Returns 7 (Calculates total complete MONTHS)
=DATEDIF(A2, B2, "D")       // If A2 is 15-Jan-2026 and B2 is 25-Jan-2026 -> Returns 10 (Calculates total elapsed DAYS)
```

### Advanced Analytical Workhorses
```excel
// SUMPRODUCT: Multiplies corresponding components in given arrays and returns the sum of products.
=SUMPRODUCT(B2:B10, C2:C10)                 // Calculates total revenue without a helper column (Quantity * Price)
=SUMPRODUCT(B2:B10, C2:C10) / SUM(C2:C10)   // Calculates Weighted Average Rate/Price

// OFFSET: Returns a reference to a range that is a specified number of rows/cols from a starting cell.
=OFFSET(A1, 3, 2)                           // Moves down 3 rows, right 2 columns from A1 -> Returns value in C4.
=SUM(OFFSET(A1, 1, 0, 5, 1))                // Dynamically sums a range of 5 rows starting 1 row below A1.

// INDIRECT: Converts a text string into a valid cell reference (great for dynamic sheet switching).
=INDIRECT("'" & B1 & "'!A1")                // Pulls value from Cell A1 of whichever sheet name is typed in cell B1.

// PYTHON IN EXCEL (=PY): Native Python engine directly inside cells (Excel 365).
=PY(
  df = xl("A1:C100", headers=True)
  df.describe()
)                                           // Generates native pandas dataframe summary statistics directly in the grid.
```

## 5. Data Manipulation Tools
Beyond functions, spreadsheets offer powerful built-in tools for data analysis:
* **Sorting:** Ordering data alphabetically, numerically, or chronologically (A-Z, Z-A). Always ensure you expand the selection to sort entire rows, not just a single column.
* **Filtering:** Temporarily hiding rows that do not meet specific criteria (e.g., viewing only records where `Status = 'Pending'`).
* **Pivot Tables:** The most powerful tool in a spreadsheet. Pivot tables allow you to summarize, group, and aggregate large datasets dynamically without writing complex formulas.

## 6. Shortcuts for Data Analysis

#### Pivot Table Shortcuts
- **Alt + N + V**: Create a new Pivot Table.
- **Alt + J + T + G**: Group selected items in a Pivot Table.
- **Alt + J + T + U**: Ungroup grouped Pivot Table fields.
- **Alt + A + C**: Clear all filters on the current Pivot Table.
- **Alt + J + T + I**: Open the Pivot Table Field Settings dialog box.
- **Alt + J + T + R**: Refresh the active Pivot Table data source.
- **Ctrl + Shift + "+"**: Insert a calculated field or item into the table.

#### Data Analysis Shortcuts
- **Alt + A + T**: Turn data filters on or off instantly.
- **Alt + A + S + S**: Open the Advanced Sort dialog box.
- **Alt + A + M**: Open the Remove Duplicates tool.
- **Alt + A + E**: Open the Convert Text to Columns Wizard.
- **Alt + D + P**: Open the legacy PivotTable and PivotChart Wizard.
- **Ctrl + Q**: Open the Quick Analysis tool for instant charts, totals, and formatting.

#### Charting & Visualization
- **Alt + F1**: Create and embed a default bar chart on the current worksheet.
- **F11**: Create a default bar chart on a brand new sheet automatically.
- **Ctrl + L / Ctrl + T**: Convert a standard data selection into an official Excel Table.
- **Alt + A + G + G**: Group selected rows or columns together.
- **Alt + A + U + U**: Ungroup selected rows or columns.
